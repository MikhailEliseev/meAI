# Phase 31: Human UAT Checklist

**Цель:** Проверить визуальное качество, анимации, серверную интеграцию и «вау-эффект» редизайна HTML-отчётов.

Все 29 unit-тестов пройдены, 20/20 must-have truth верифицированы кодом. Эти 6 пунктов требуют живого тестирования в браузере/на сервере.

---

## 1. Theme Toggle + localStorage

**Как проверить:**
1. Сгенерируй отчёт через Hermes (например, сессия `nachalo-clinica`)
2. Открой публичную ссылку в Chrome
3. Нажми кнопку переключения темы (🌓 в навбаре)

**Ожидаемый результат:**
- Мгновенное переключение light ↔ dark без мигания
- При перезагрузке страницы тема сохраняется (localStorage)
- При первом открытии — нет вспышки неправильной темы (blocking script в `<head>` работает)

---

## 2. Ripple Ring Animations

**Как проверить:**
1. Открой отчёт в Chrome на десктопе
2. Посмотри на фон страницы
3. Открой DevTools → Responsive mode → iPhone SE (375px)

**Ожидаемый результат:**
- 6 статичных колец видны как полупрозрачные круги в разных позициях
- 8 пульсирующих колец анимируются плавно с разной скоростью (6s–9s) и задержками
- Кольца не мешают читаемости текста
- На мобильном (`<768px`) кольца исчезают

---

## 3. Navigation Scroll Behavior

**Как проверить:**
1. Открой отчёт с полным набором секций
2. Поочерёдно нажми каждый пункт навигации

**Ожидаемый результат:**
- Плавный скролл к соответствующей секции (`scroll-behavior: smooth`)
- Навбар остаётся зафиксированным сверху при скролле
- Glass backdrop (blur) виден поверх контента
- Ссылки ведут на правильные секции (нет битых якорей)

---

## 4. Mobile Responsiveness

**Как проверить:**
1. Открой DevTools → Responsive mode
2. Проверь на 768px, 480px, 375px

**Ожидаемый результат:**
- 768px: hero h1 уменьшается до 32px, grid-ы схлопываются в 1fr, нав-ссылки скрыты
- 480px: container padding уменьшен
- Все ширины: ripple rings скрыты, контент читаемый, нет горизонтального скролла

## 6. «Wow Effect» — Визуальное сравнение с ИПХиК.html

**Как проверить:**
1. Открой сгенерированный AIM-отчёт и файл `ИПХиК (1).html` рядом
2. Сравни визуальное качество по критериям:

**Ожидаемый результат:**
- [ ] Dual theme создаёт два разных визуальных характера (light — чистый, dark — драматичный)
- [ ] Playfair Display в заголовках выглядит элегантно и редакционно
- [ ] Inter в основном тексте читается чисто
- [ ] Ripple rings добавляют глубину фону, не отвлекая от контента
- [ ] Карточки (`.card`) хорошо spaced, легко сканируются
- [ ] Нет ощущения «generic template» — отчёт выглядит премиально

**Критерий прохождения:** Отчёт не стыдно показать клиенту. Дизайн воспринимается как кастомный, а не шаблонный.
