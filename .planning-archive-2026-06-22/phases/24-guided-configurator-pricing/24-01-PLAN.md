CategoryType = Literal["base", "recommended", "optional", "next_stage"]

```

- У всех клиник: «Аудит + стратегия» → БАЗА

- Контент < 10 страниц: «Блог» → ОПЦИОНАЛЬНО

    """
    
    from dataclasses import dataclass, field
    from typing import Literal
    
    CategoryType = Literal["base", "recommended", "optional", "next_stage"]
    
    @dataclass
    class ServiceItem:
        id: str
        name: str
        category: CategoryType
        price: int
        price_note: str | None = None
        deferred_reason: str | None = None
        selected: bool = True

    ]
    
    class ServiceCategorizer:
        """Категоризирует услуги на основе данных prescan."""
        
        def categorize(self, prescan_data: dict) -> list[ServiceItem]:
            ...
        
        def _apply_seo_rules(self, services: list[ServiceItem], data: dict) -> None:
            ...
        
        def _apply_ads_rules(self, services: list[ServiceItem], data: dict) -> None:
            ...
        
        def _apply_content_rules(self, services: list[ServiceItem], data: dict) -> None:
            ...
        
        def _apply_social_rules(self, services: list[ServiceItem], data: dict) -> None:
            ...
        
        def _apply_revenue_rules(self, services: list[ServiceItem], data: dict) -> None:
            ...
    ```

    **Логика методов (псевдокод, реализуй на Python):**

    `categorize(prescan_data: dict) -> list[ServiceItem]`:
    1. Клонируй DEFAULT_SERVICES (deep copy каждого ServiceItem)
    2. Вызови последовательно: `_apply_seo_rules`, `_apply_ads_rules`, `_apply_content_rules`, `_apply_social_rules`, `_apply_revenue_rules`
    3. Верни список

    `_apply_seo_rules(services, data)`:
    - Найди сервис `seo_rebuild`
    - Если `seo_score < 40` ИЛИ `has_sitemap == False` ИЛИ `has_structured_data == False` → category = "recommended", selected = True
    - Иначе если `seo_score >= 60` → category = "optional", selected = False
    - Иначе (40-59) → category = "recommended", selected = True

    `_apply_ads_rules(services, data)`:
    - Найди сервис `yandex_direct`
    - Если `has_ads == False` ИЛИ нет данных о рекламных кампаниях → category = "recommended", selected = True
    - Если `has_ads == True` → category = "optional", selected = False

    `_apply_content_rules(services, data)`:
    - Найди сервис `content_blog`
    - Если `total_pages < 10` → category = "optional", selected = False (мало контента = блог опционален)
    - Если `total_pages >= 10` → category = "optional", selected = True (есть база — блог усилит)

    `_apply_social_rules(services, data)`:
    - Найди сервис `social_media`
    - Если `social_links` пустые ИЛИ все значения null/None → category = "next_stage", locked = True, deferred_reason = "Соцсети не ведутся. Сначала закрываем поиск — соцсети на этапе 2."
    - Если есть активные соцсети → category = "optional", locked = False, selected = False

    `_apply_revenue_rules(services, data)`:
    - Если `revenue_year` присутствует И `competitor_avg_revenue` присутствует:
      - Вычисли gap: `(competitor_avg_revenue - revenue_year) / revenue_year`
      - Если gap >= 0.2 (20%+ разрыв) → все recommended сервисы → selected = True, для каждого recommended добавить в deferred_reason упоминание о разрыве: «Разрыв с конкурентами: {gap*100:.0f}% — рекомендуется усилить»
    - Если competitor_avg_revenue отсутствует → пропустить

    **Важно:** `_apply_revenue_rules` НЕ меняет категории, только усиливает selected для recommended.
