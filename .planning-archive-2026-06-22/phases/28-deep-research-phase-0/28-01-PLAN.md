3. Отправить на классификацию: `python3 /root/bin/deep-research-merge.py {client} --classify-only`

Tier-dependent research depth:
- **Tier 1 (star — д.м.н., профессор, заслуженный врач РФ, автор методик):** 7-10 поисков на врача
- **Tier 2 (core — к.м.н., гл.врач, руководитель отделения, стаж 15+):** 5 поисков на врача
- **Tier 3 (team — остальные):** 2-3 поиска на врача

## Security Notes

- deep-research-merge.py принимает JSON от LLM через stdin — зона недоверия. Весь входной JSON валидируется на структуру (clinic dict + doctors list с обязательным full_name) перед записью.
- SKILL.md инструктирует LLM НЕ писать JSON напрямую — всегда через merge.py. Это предотвращает JSON corruption и key hallucination (~7% ошибок при прямом LLM-генерировании JSON).
- Исследовательские данные — только из публичных источников (prodoctorov.ru, elibrary.ru, СМИ). Никакого доступа к закрытым медицинским базам.
