Add four analysis methods to CIOrchestrator class. These are rule-based methods that work on a ComparisonMatrix-like object (or FakeMatrix from tests). The matrix object has `.competitors` (list of dicts) and `.client` (dict with "features" and "missing" keys).

Competitor dicts use these keys: name, url, website.features (list), website.missing (list), website.pricing_visible (bool), seo.score (int 0-100), financials.latest_revenue (int), gm_rating (float), positioning (str).

**Method 1: _extract_tactics_from_matrix(self, matrix) -> list[StealWorthyTactic]**

Algorithm:
1. Import _tactic_impact_effort from aim.services.ci_marketing_analysis
2. Get client missing features from matrix.client.get("missing", [])
3. For each competitor, for each feature they have that the client is missing:
   - Call _tactic_impact_effort(feature) to get (impact, effort)
   - Create StealWorthyTactic with source_competitor, tactic_description, expected_impact, estimated_effort
4. Also detect SEO exploit tactic: if any competitor has SEO score < 60, create a tactic to exploit that
5. Also detect pricing tactic: if any competitor lacks pricing visibility but client doesn't, create pricing transparency tactic
6. Sort: High impact first, then Medium, then Low. Within same impact, Low effort before Medium before High
7. Cap at max 8 tactics
8. Return list of StealWorthyTactic

**Method 2: _extract_swot_from_matrix(self, matrix) -> dict**

Returns dict: {"strengths": [...], "weaknesses": [...], "opportunities": [...], "threats": [...]}

Algorithm:
- Strengths: client features that no competitor has. If client has features like "чат", add them. Default: "локальный рынок", "специализация"
- Weaknesses: features competitors have that the client is missing. Default: "отсутствие ключевых фич сайта"
- Opportunities: gaps in competitor offerings. If competitor has weak SEO (<60), add SEO opportunity. If competitor lacks pricing visibility, add pricing opportunity. Default: "SEO-оптимизация"
- Threats: strong competitor advantages. If competitor has high rating, add threat. If competitor has high revenue, add threat. Default: "конкуренция с сильными игроками"

All quadrants capped at max 5 items. Empty matrix returns defaults: strengths includes "локальный рынок", opportunities is non-empty.

**Method 3: _top_rec_from_matrix(self, matrix) -> str**

Algorithm:
1. If matrix.competitors is empty: return "Соберите данные о конкурентах для получения рекомендаций."
2. Find competitor with weakest SEO score (min seo.score). If no SEO scores, pick first competitor.
3. Return: f"Главная возможность — обойти **{name}** по SEO: у них {score}/100, исправьте ошибки которые мы нашли на их сайте, и вы выше."

**Method 4: _generate_analysis_summary(self, matrix, swot: dict, tactics: list, rec: str, wow: dict) -> str**

Generates markdown with these sections:
1. "# Обзор конкурентной среды" — intro paragraph with competitor count
2. "## По конкурентам" — per-competitor details (name, URL, ratings, SEO score)
3. "## SWOT-анализ" — strengths/weaknesses/opportunities/threats as bullet lists
4. "## Что можно внедрить" — skip if tactics is empty list
5. "## Прогноз по пациентам" — skip if wow dict is empty/falsy
6. "## Главная рекомендация" — the rec string

Include competitor names from matrix. For empty matrix, return: "Не удалось найти конкурентов для анализа."

```python
class CiMarketingAnalyzer:
    """Thin backward-compatible proxy — delegates to CIOrchestrator._run_quick_analysis()."""

    def __init__(self, timeout: float = 10.0):
        self.timeout = timeout

    async def analyze(
        self,
        url: str,
        specialization: str = "",
        city: str = "",
        services: list[str] | None = None,
        competitors: list | None = None,
        client_revenue: int | None = None,
        client_rating: float | None = None,
        on_progress=None,
    ) -> CiAnalysisResult:
        import time as _time
        from meai.events.event_bus import EventBus
        from aim.subagents.competitive_intel.orchestrator.ci_orchestrator import CIOrchestrator

        start = _time.monotonic()

        # Extract URLs from competitor objects (supports str, object with .url/.website, dict)
        named_urls = []
        for c in (competitors or []):
            if isinstance(c, str):
                named_urls.append(c)
            elif hasattr(c, 'url'):
                named_urls.append(c.url)
            elif hasattr(c, 'website'):
                named_urls.append(c.website)
            elif isinstance(c, dict):
                named_urls.append(c.get("url", c.get("website", "")))
            else:
                named_urls.append(str(c))

        event_bus = EventBus()
        await event_bus.initialize()

        try:
            orch = CIOrchestrator(
                agent_id=f"ci-proxy-{id(event_bus)}",
                event_bus=event_bus,
            )

            if on_progress:
                async def progress_cb(phase, status, msg):
                    try:
                        await on_progress(status, msg, "")
                    except Exception:
                        pass
            else:
                progress_cb = None

            result = await orch._run_quick_analysis(
                task_data={
                    "url": url,
                    "competitors": named_urls,
                    "niche": specialization,
                    "geo": city,
                    "tier": "quick",
                    "task_id": f"quick-{id(event_bus)}",
                },
                correlation_id=f"ci-quick-{id(event_bus)}",
            )

            elapsed = _time.monotonic() - start

            return CiAnalysisResult(
                chat_summary="",
                feature_matrix={},
                pricing_comparison={},
                positioning_map={},
                swot_per_competitor=[],
                steal_worthy_tactics=[],
                top_recommendation="",
                scraped_at=datetime.now(timezone.utc).isoformat(),
                analysis_duration_seconds=elapsed,
                tier="quick",
                findings=result.get("findings", {}),
                phases_executed=result.get("phases_executed", []),
            )

        except Exception as e:
            logger.exception("CiMarketingAnalyzer proxy failed")
            return CiAnalysisResult(
                chat_summary=f"Не удалось провести анализ: {e}",
                error=str(e),
                analysis_duration_seconds=_time.monotonic() - start,
            )
        finally:
            await event_bus.close()
```
