**Error handling pattern (identical across all tools):**
```python
try:
    async with httpx.AsyncClient(timeout=REQUEST_TIMEOUT) as client:
        response = await client.post(f"{AIM_API_BASE}/api/...", json={...})
        response.raise_for_status()
        data = response.json()
        return json.dumps(data, ensure_ascii=False, indent=2)
except httpx.HTTPStatusError as e:
    return json.dumps({"error": "AIM API returned an error", "status": e.response.status_code, "detail": str(e)})
except httpx.RequestError as e:
    return json.dumps({"error": "Cannot reach AIM API", "detail": str(e)})
except Exception as e:
    return json.dumps({"error": "Unexpected error in tool handler", "detail": str(e)})
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Hermes tool handler → AIM API (internal Docker network) | Tool handlers construct HTTP requests to AIM API. Parameters come from LLM tool calls (Hermes-agent controlled), not directly from end-user input. |
| AIM API → Tool response → LLM → User | Tool response data flows through Hermes agent loop. LLM may summarize/modify before showing to user. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-03 | Spoofing | All tools | mitigate | Tool handlers call AIM API via internal Docker network (http://app:8000). No external URLs. URL not constructed from user input — base URL is a constant, path templates are hardcoded. |
| T-15-04 | Tampering | collect_contact | mitigate | collect_contact handler validates contact_type enum (telegram/email/phone only). contact_value is stored as-is — validation happens at AIM API layer. |
| T-15-05 | Information Disclosure | show_all_leads | mitigate | show_all_leads is registered but access control is at AIM API layer (the endpoint should reject non-admin requests). Hermes mode system (D-26, D-28) provides additional layer — ADMIN mode required for lead access. |
| T-15-06 | Denial of Service | All tools | mitigate | REQUEST_TIMEOUT=30.0s prevents hanging requests. max_iterations=15 in AIAgent constructor limits tool calls per conversation. Hermes agent loop prevents infinite tool calling. |
| T-15-07 | Elevation of Privilege | show_all_leads, show_project_status | mitigate | Tool handlers do NOT implement their own auth — they rely on AIM API endpoints to enforce access control. Hermes mode (PRESALE/ACTIVE/ADMIN) controls which toolset is enabled. |
</threat_model>
