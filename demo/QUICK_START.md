

## 🔧 Troubleshooting

### Проблема: HTML report не открывается

**Решение:**
```bash
# Проверь путь
ls -la demo/стоматология-смайл/report.html

# Открой вручную
open demo/стоматология-смайл/report.html
```

### Проблема: Тест падает с ошибкой

**Решение:**
```bash
# Проверь виртуальное окружение
source venv/bin/activate

# Проверь зависимости
pip install -r requirements.txt

# Запусти снова
python scripts/test_end_to_end.py
```

### Проблема: HTML report выглядит некрасиво

**Решение:**
- Открой в современном браузере (Chrome, Firefox, Safari)
- Не открывай в IE или старых версиях браузеров

### Проблема: Нужно изменить брендинг

**Решение:**
1. Открой `src/meai/reports/html_generator.py`
2. Найди секцию `<style>`
3. Измени цвета:
   - `#667eea` → твой primary color
   - `#764ba2` → твой secondary color
4. Измени footer:
   - "AIM Agency" → твоё название
   - "iamaim.ru" → твой сайт
