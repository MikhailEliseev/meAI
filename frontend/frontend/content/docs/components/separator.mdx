# Separator Component

Visually separate or divide content sections with horizontal or vertical lines.

## Basic Usage

```tsx
import { Separator } from '@/components/ui/separator'

function Example() {
  return (
    <div>
      <p>Content above</p>
      <Separator />
      <p>Content below</p>
    </div>
  )
}
```

## Orientation

```tsx
// Horizontal (default)
<Separator orientation="horizontal" />

// Vertical
<div className="flex h-20 items-center">
  <span>Left</span>
  <Separator orientation="vertical" className="mx-4" />
  <span>Right</span>
</div>
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Separator direction |
| `decorative` | `boolean` | `true` | Whether separator is decorative |
| `className` | `string` | - | Additional CSS classes |

## Best Practices

1. **Use sparingly** - Too many separators create visual clutter
2. **Consistent spacing** - Maintain uniform spacing around separators
3. **Semantic grouping** - Use to separate logical content sections
4. **Consider alternatives** - Sometimes whitespace is better than a line
5. **Accessibility** - Use `decorative={false}` for meaningful separators

## Accessibility

```tsx
// Decorative separator (default)
<Separator decorative />

// Semantic separator
<Separator decorative={false} aria-label="Section divider" />
```

## Testing

```typescript
import { render } from '@testing-library/react'
import { Separator } from './separator'

describe('Separator', () => {
  it('renders horizontal separator', () => {
    const { container } = render(<Separator />)
    const separator = container.querySelector('[data-orientation="horizontal"]')
    expect(separator).toBeInTheDocument()
  })

  it('renders vertical separator', () => {
    const { container } = render(<Separator orientation="vertical" />)
    const separator = container.querySelector('[data-orientation="vertical"]')
    expect(separator).toBeInTheDocument()
  })
})
```
