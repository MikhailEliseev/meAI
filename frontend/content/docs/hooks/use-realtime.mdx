# useRealtime Hook

Subscribe to real-time updates from Supabase Realtime for live data synchronization.

## Usage

```tsx
import { useRealtime } from '@/hooks/useRealtime'

function MyComponent() {
  const { status, error } = useRealtime({
    table: 'metrics',
    onInsert: (payload) => {
      console.log('New metric:', payload.new)
    },
    onUpdate: (payload) => {
      console.log('Updated metric:', payload.new)
    },
    onDelete: (payload) => {
      console.log('Deleted metric:', payload.old)
    },
  })

  return <div>Status: {status}</div>
}
```

## Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `table` | `string` | Yes | Table name to subscribe to |
| `filter` | `string` | No | Filter expression (e.g., `project_id=eq.123`) |
| `onInsert` | `(payload) => void` | No | Callback for INSERT events |
| `onUpdate` | `(payload) => void` | No | Callback for UPDATE events |
| `onDelete` | `(payload) => void` | No | Callback for DELETE events |
| `enabled` | `boolean` | No | Enable/disable subscription (default: `true`) |

## Return Value

| Property | Type | Description |
|----------|------|-------------|
| `status` | `'connecting' \| 'connected' \| 'disconnected' \| 'error'` | Connection status |
| `error` | `Error \| null` | Error object if connection failed |
| `reconnect` | `() => void` | Manual reconnect function |

## Examples

### Basic Subscription

```tsx
function MetricsMonitor() {
  const { status } = useRealtime({
    table: 'metrics',
    onInsert: (payload) => {
      toast.success(`New metric: ${payload.new.value}`)
    },
  })

  return <ConnectionStatus status={status} />
}
```

### With Filter

```tsx
function ProjectMetrics({ projectId }: { projectId: string }) {
  const { status } = useRealtime({
    table: 'metrics',
    filter: `project_id=eq.${projectId}`,
    onInsert: (payload) => {
      // Only receives metrics for this project
      updateMetrics(payload.new)
    },
  })

  return <div>Monitoring project {projectId}</div>
}
```

### With State Updates

```tsx
function LiveMetrics() {
  const [metrics, setMetrics] = useState<Metric[]>([])

  useRealtime({
    table: 'metrics',
    onInsert: (payload) => {
      setMetrics((prev) => [...prev, payload.new])
    },
    onUpdate: (payload) => {
      setMetrics((prev) =>
        prev.map((m) => (m.id === payload.new.id ? payload.new : m))
      )
    },
    onDelete: (payload) => {
      setMetrics((prev) => prev.filter((m) => m.id !== payload.old.id))
    },
  })

  return <MetricsList metrics={metrics} />
}
```

### Conditional Subscription

```tsx
function ConditionalRealtime({ enabled }: { enabled: boolean }) {
  useRealtime({
    table: 'metrics',
    enabled, // Only subscribe when enabled
    onInsert: (payload) => {
      console.log('New metric:', payload.new)
    },
  })

  return <div>Realtime: {enabled ? 'ON' : 'OFF'}</div>
}
```

### Error Handling

```tsx
function RealtimeWithErrorHandling() {
  const { status, error, reconnect } = useRealtime({
    table: 'metrics',
    onInsert: (payload) => {
      console.log('New metric:', payload.new)
    },
  })

  if (status === 'error') {
    return (
      <div>
        <p>Connection error: {error?.message}</p>
        <button onClick={reconnect}>Reconnect</button>
      </div>
    )
  }

  return <div>Status: {status}</div>
}
```

### Multiple Subscriptions

```tsx
function MultipleSubscriptions() {
  // Subscribe to metrics
  useRealtime({
    table: 'metrics',
    onInsert: (payload) => {
      console.log('New metric:', payload.new)
    },
  })

  // Subscribe to projects
  useRealtime({
    table: 'projects',
    onUpdate: (payload) => {
      console.log('Updated project:', payload.new)
    },
  })

  return <div>Monitoring multiple tables</div>
}
```

## Payload Structure

### INSERT Event

```typescript
{
  eventType: 'INSERT',
  new: {
    id: '123',
    value: 100,
    timestamp: '2024-01-01T00:00:00Z',
    // ... other fields
  },
  old: {},
  schema: 'public',
  table: 'metrics',
}
```

### UPDATE Event

```typescript
{
  eventType: 'UPDATE',
  new: {
    id: '123',
    value: 150, // Updated value
    timestamp: '2024-01-01T00:00:00Z',
  },
  old: {
    id: '123',
    value: 100, // Previous value
    timestamp: '2024-01-01T00:00:00Z',
  },
  schema: 'public',
  table: 'metrics',
}
```

### DELETE Event

```typescript
{
  eventType: 'DELETE',
  new: {},
  old: {
    id: '123',
    value: 100,
    timestamp: '2024-01-01T00:00:00Z',
  },
  schema: 'public',
  table: 'metrics',
}
```

## Connection States

### Connecting
Initial state when establishing connection:
```tsx
if (status === 'connecting') {
  return <Spinner />
}
```

### Connected
Successfully connected and receiving updates:
```tsx
if (status === 'connected') {
  return <Badge variant="success">Live</Badge>
}
```

### Disconnected
Connection lost, will auto-reconnect:
```tsx
if (status === 'disconnected') {
  return <Badge variant="warning">Reconnecting...</Badge>
}
```

### Error
Connection failed, manual reconnect needed:
```tsx
if (status === 'error') {
  return <Button onClick={reconnect}>Reconnect</Button>
}
```

## Best Practices

1. **Filter at source** - Use filter parameter to reduce bandwidth
2. **Debounce updates** - Debounce state updates to avoid UI thrashing
3. **Handle errors** - Always handle error state and provide reconnect
4. **Clean up** - Hook automatically cleans up on unmount
5. **Conditional subscription** - Use `enabled` prop to control subscription

## Performance Tips

- Use `filter` to reduce data transfer
- Debounce state updates (300ms recommended)
- Memoize callbacks to prevent re-subscriptions
- Limit number of simultaneous subscriptions

## Troubleshooting

### Connection keeps dropping
- Check network stability
- Verify Supabase project status
- Check browser console for errors

### Not receiving updates
- Verify table name is correct
- Check filter expression syntax
- Ensure Realtime is enabled in Supabase

### High memory usage
- Limit subscription scope with filters
- Debounce state updates
- Clean up old data periodically
