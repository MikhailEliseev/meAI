# MetricsChart

A responsive line chart component for visualizing metric trends with real-time updates.

## Usage

```tsx
import { MetricsChart } from '@/components/dashboard/MetricsChart'

function MyChart() {
  const data = [
    { timestamp: '2024-01-01', value: 100 },
    { timestamp: '2024-01-02', value: 150 },
    { timestamp: '2024-01-03', value: 120 },
  ]

  return (
    <MetricsChart
      data={data}
      metricType="traffic"
      title="Website Traffic"
    />
  )
}
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `data` | `Metric[]` | required | Array of metric data points |
| `metricType` | `MetricType` | required | Type of metric to display |
| `title` | `string` | required | Chart title |
| `height` | `number` | `300` | Chart height in pixels |
| `showGrid` | `boolean` | `true` | Show grid lines |
| `showLegend` | `boolean` | `true` | Show legend |
| `animate` | `boolean` | `true` | Enable animations |

## Real-Time Updates

Use with `useMetrics` hook for real-time updates:

```tsx
import { useMetrics } from '@/hooks/useMetrics'
import { MetricsChart } from '@/components/dashboard/MetricsChart'

function RealtimeChart() {
  const { data, isLoading } = useMetrics({
    projectId: 'project-123',
    metricType: 'traffic',
  })

  if (isLoading) return <div>Loading...</div>

  return (
    <MetricsChart
      data={data}
      metricType="traffic"
      title="Real-Time Traffic"
    />
  )
}
```

## Examples

### Multiple Metrics

```tsx
function MultiMetricChart() {
  return (
    <div className="grid gap-4 md:grid-cols-2">
      <MetricsChart
        data={trafficData}
        metricType="traffic"
        title="Traffic"
      />
      <MetricsChart
        data={conversionData}
        metricType="conversions"
        title="Conversions"
      />
    </div>
  )
}
```

### With Date Range

```tsx
function ChartWithDateRange() {
  const [dateRange, setDateRange] = useState([startDate, endDate])

  const { data } = useMetrics({
    projectId: 'project-123',
    metricType: 'traffic',
    dateRange,
  })

  return (
    <>
      <DateRangePicker value={dateRange} onChange={setDateRange} />
      <MetricsChart
        data={data}
        metricType="traffic"
        title="Traffic"
      />
    </>
  )
}
```
