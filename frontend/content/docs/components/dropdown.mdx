# Dropdown Menu Component

A dropdown menu component for displaying a list of actions or navigation items.

## Basic Usage

```tsx
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuTrigger,
} from '@/components/ui/dropdown-menu'

export function Example() {
  return (
    <DropdownMenu>
      <DropdownMenuTrigger asChild>
        <Button variant="outline">Open Menu</Button>
      </DropdownMenuTrigger>
      <DropdownMenuContent>
        <DropdownMenuItem>Profile</DropdownMenuItem>
        <DropdownMenuItem>Settings</DropdownMenuItem>
        <DropdownMenuItem>Logout</DropdownMenuItem>
      </DropdownMenuContent>
    </DropdownMenu>
  )
}
```

          checked={showActivityBar}

          Activity Bar

## Composition

```tsx
<DropdownMenu>
  {/* Trigger - Opens menu */}
  <DropdownMenuTrigger asChild>
    <Button>Open</Button>
  </DropdownMenuTrigger>
  
  {/* Content - Menu items */}
  <DropdownMenuContent>
    
    {/* Label - Section header */}
    <DropdownMenuLabel>Section</DropdownMenuLabel>
    
    {/* Separator - Visual divider */}
    <DropdownMenuSeparator />
    
    {/* Item - Clickable option */}
    <DropdownMenuItem>Item</DropdownMenuItem>
    
    {/* Checkbox Item - Toggle option */}
    <DropdownMenuCheckboxItem checked={true}>
      Checkbox
    </DropdownMenuCheckboxItem>
    
    {/* Radio Group - Single selection */}
    <DropdownMenuRadioGroup value="value">
      <DropdownMenuRadioItem value="value">
        Radio
      </DropdownMenuRadioItem>
    </DropdownMenuRadioGroup>
    
    {/* Sub Menu - Nested menu */}
    <DropdownMenuSub>
      <DropdownMenuSubTrigger>More</DropdownMenuSubTrigger>
      <DropdownMenuSubContent>
        <DropdownMenuItem>Sub Item</DropdownMenuItem>
      </DropdownMenuSubContent>
    </DropdownMenuSub>
    
  </DropdownMenuContent>
</DropdownMenu>
```

## Props

### DropdownMenu

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `open` | `boolean` | - | Controlled open state |
| `onOpenChange` | `(open: boolean) => void` | - | Open state change handler |
| `defaultOpen` | `boolean` | `false` | Uncontrolled default open state |

### DropdownMenuContent

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `align` | `'start' \| 'center' \| 'end'` | `'center'` | Alignment relative to trigger |
| `sideOffset` | `number` | `0` | Distance from trigger |
| `className` | `string` | - | Additional CSS classes |

## Accessibility

- Keyboard navigation (Arrow keys, Enter, Escape)
- Focus management
- ARIA attributes for screen readers
- Closes on outside click
- Closes on Escape key
- Proper role attributes

## Best Practices

1. **Clear labels** - Use descriptive text for menu items
2. **Group related items** - Use separators to organize
3. **Destructive actions** - Place at bottom with visual distinction
4. **Keyboard shortcuts** - Show shortcuts for common actions
5. **Icons** - Use icons consistently for better recognition
6. **Mobile-friendly** - Ensure touch targets are large enough
