# Dashboard Components

Real-time dashboard components for visualizing metrics and performance data.

## MetricsDashboard

Main dashboard component that displays metrics with real-time updates.

### Usage

```tsx
import { MetricsDashboard } from '@/components/dashboard/MetricsDashboard'

export default function DashboardPage() {
  return <MetricsDashboard projectId="project-123" />
}
```

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `projectId` | `string` | required | Project ID to filter metrics |
| `autoRefresh` | `boolean` | `true` | Enable auto-refresh |
| `refreshInterval` | `number` | `30000` | Refresh interval in ms |

### Features

- **Real-time Updates**: WebSocket connection for live data
- **Auto-refresh**: Configurable refresh interval
- **Metric Selection**: Choose which metrics to display
- **Date Range**: Filter by date range
- **Responsive**: Mobile-friendly layout

### Example

```tsx
<MetricsDashboard
  projectId="project-123"
  autoRefresh={true}
  refreshInterval={30000}
/>
```

## MetricsChart

Line chart component for visualizing metric trends.

### Usage

```tsx
import { MetricsChart } from '@/components/dashboard/MetricsChart'

function MyChart() {
  const data = [
    { timestamp: '2024-01-01', value: 100 },
    { timestamp: '2024-01-02', value: 150 },
  ]

  return (
    <MetricsChart
      data={data}
      metricType="traffic"
      title="Website Traffic"
    />
  )
}
```

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `data` | `Metric[]` | required | Array of metric data points |
| `metricType` | `MetricType` | required | Type of metric to display |
| `title` | `string` | required | Chart title |
| `height` | `number` | `300` | Chart height in pixels |

### Metric Types

- `traffic`: Website traffic
- `conversions`: Conversion rate
- `revenue`: Revenue
- `engagement`: User engagement

## ConnectionStatus

Visual indicator for WebSocket connection status.

### Usage

```tsx

function MyComponent() {
  return <ConnectionStatus />
}
```

### States

- **Connecting**: Yellow indicator, "Connecting..."
- **Connected**: Green indicator, "Connected"
- **Disconnected**: Red indicator, "Disconnected"
- **Error**: Red indicator, "Connection Error"

### Example

```tsx
<div className="flex items-center gap-2">
  <ConnectionStatus />
  <span>Real-time updates</span>
</div>
```

## useMetrics Hook

Custom hook for fetching metrics with real-time updates.

### Usage

```tsx
import { useMetrics } from '@/hooks/useMetrics'

function MyComponent() {
  const { data, isLoading, error, refetch } = useMetrics({
    projectId: 'project-123',
    metricType: 'traffic',
    dateRange: [startDate, endDate],
  })

  if (isLoading) return <div>Loading...</div>
  if (error) return <div>Error: {error.message}</div>

  return <div>{data.length} metrics loaded</div>
}
```

### Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `projectId` | `string` | Yes | Project ID |
| `metricType` | `MetricType` | Yes | Metric type |
| `dateRange` | `[Date, Date]` | No | Date range filter |

### Returns

| Property | Type | Description |
|----------|------|-------------|
| `data` | `Metric[]` | Array of metrics |
| `isLoading` | `boolean` | Loading state |
| `error` | `Error \| null` | Error object |
| `refetch` | `() => void` | Manual refetch function |

## Best Practices

### Performance

1. **Limit Data Points**: Display max 100 data points per chart
2. **Debounce Updates**: Debounce real-time updates to avoid UI thrashing
3. **Lazy Loading**: Load charts only when visible

```tsx
import { useInView } from 'react-intersection-observer'

function LazyChart() {
  const { ref, inView } = useInView({ triggerOnce: true })

  return (
    <div ref={ref}>
      {inView && <MetricsChart data={data} />}
    </div>
  )
}
```

### Error Handling

Always handle connection errors gracefully:

```tsx
function DashboardWithErrorHandling() {
  const { status, reconnect } = useRealtime({
    table: 'metrics',
    onInsert: handleInsert,
  })

  if (status === 'error') {
    return (
      <div>
        <p>Connection lost</p>
        <button onClick={reconnect}>Reconnect</button>
      </div>
    )
  }

  return <MetricsDashboard />
}
```

### Accessibility

Ensure charts are accessible:

```tsx
<MetricsChart
  data={data}
  title="Website Traffic"
  aria-label="Line chart showing website traffic over time"
/>
```
