# Quick Start

This guide will help you get started with the platform in just a few minutes.

## Your First Project

### Step 1: Create a New Project

After installation, create your first project:

```bash
npm run create-project
```

Follow the interactive prompts to configure your project.

### Step 2: Explore the Dashboard

Navigate to the dashboard at [http://localhost:3000/dashboard](http://localhost:3000/dashboard).

Key features:
- **Metrics Overview**: Real-time performance metrics
- **Activity Feed**: Recent team activity
- **Quick Actions**: Common tasks and shortcuts

### Step 3: Add Your First Component

Create a new component:

```tsx
// components/MyComponent.tsx
export function MyComponent() {
  return (
    <div className="p-4 bg-white rounded-lg shadow">
      <h2 className="text-xl font-bold">Hello World</h2>
      <p>Your first component is ready!</p>
    </div>
  )
}
```

### Step 4: Enable Real-Time Features

Configure Supabase Realtime in your component:

```tsx
import { useRealtime } from '@/hooks/useRealtime'

export function RealtimeComponent() {
  useRealtime({
    table: 'your_table',
    onInsert: (payload) => {
      console.log('New record:', payload)
    },
  })

  return <div>Real-time updates enabled!</div>
}
```

## Common Tasks

### Adding a New Page

Create a new page in the `app` directory:

```tsx
// app/my-page/page.tsx
export default function MyPage() {
  return (
    <div>
      <h1>My New Page</h1>
    </div>
  )
}
```

### Fetching Data

Use TanStack Query for data fetching:

```tsx
import { useQuery } from '@tanstack/react-query'

export function DataComponent() {
  const { data, isLoading } = useQuery({
    queryKey: ['myData'],
    queryFn: async () => {
      const response = await fetch('/api/data')
      return response.json()
    },
  })

  if (isLoading) return <div>Loading...</div>

  return <div>{JSON.stringify(data)}</div>
}
```

### Managing State

Use Zustand for global state:

```tsx
import { create } from 'zustand'

interface AppState {
  count: number
  increment: () => void
}

export const useAppStore = create<AppState>((set) => ({
  count: 0,
  increment: () => set((state) => ({ count: state.count + 1 })),
}))
```
