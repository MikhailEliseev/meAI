# Configuration

Learn how to configure your application with environment variables and settings.

## Environment Variables

Create a `.env.local` file in the root of your project:

```bash
# Database
DATABASE_URL=postgresql://user:password@localhost:5432/mydb

# Authentication
NEXTAUTH_URL=http://localhost:3000
NEXTAUTH_SECRET=your-secret-key

# API Keys
OPENAI_API_KEY=sk-...
STRIPE_SECRET_KEY=sk_test_...

# Feature Flags
ENABLE_ANALYTICS=true
ENABLE_REALTIME=true
```

## Configuration File

Create a `config.ts` file for application settings:

```typescript
export const config = {
  app: {
    name: 'My App',
    url: process.env.NEXT_PUBLIC_APP_URL || 'http://localhost:3000',
  },
  features: {
    analytics: process.env.ENABLE_ANALYTICS === 'true',
    realtime: process.env.ENABLE_REALTIME === 'true',
  },
  api: {
    timeout: 30000,
    retries: 3,
  },
}
```

## Database Configuration

Configure your database connection:

```typescript
import { createClient } from '@supabase/supabase-js'

export const supabase = createClient(
  process.env.NEXT_PUBLIC_SUPABASE_URL!,
  process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!
)
```

## Type Safety

Use Zod for environment variable validation:

```typescript
import { z } from 'zod'

const envSchema = z.object({
  DATABASE_URL: z.string().url(),
  NEXTAUTH_SECRET: z.string().min(32),
  OPENAI_API_KEY: z.string().startsWith('sk-'),
})

export const env = envSchema.parse(process.env)
```

## Best Practices

1. **Never commit secrets** - Use `.env.local` and add to `.gitignore`
2. **Validate early** - Check environment variables at startup
3. **Use type safety** - Validate with Zod or similar
4. **Document variables** - Keep `.env.example` up to date
5. **Separate environments** - Use different values for dev/staging/prod
