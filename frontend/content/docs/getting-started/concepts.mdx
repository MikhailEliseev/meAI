# Core Concepts

Learn the fundamental concepts that power the platform.

## Architecture Overview

The platform is built on a modern stack:

- **Next.js 14+**: React framework with App Router
- **TypeScript**: Type-safe development
- **Supabase**: Backend-as-a-Service with real-time capabilities
- **TanStack Query**: Server state management
- **Zustand**: Client state management

## Real-Time Updates

### How It Works

Real-time updates are powered by Supabase Realtime, which uses WebSockets to push changes from the database to your application instantly.

```tsx
import { useRealtime } from '@/hooks/useRealtime'

function MyComponent() {
  const { status, isConnected } = useRealtime({
    table: 'tasks',
    filter: 'project_id=eq.123',
    onInsert: (payload) => {
      console.log('New task:', payload)
    },
    onUpdate: (payload) => {
      console.log('Task updated:', payload)
    },
    onDelete: (payload) => {
      console.log('Task deleted:', payload)
    },
  })

  return <div>Status: {status}</div>
}
```

### Connection Management

The `useRealtime` hook automatically handles:

- **Auto-reconnection**: Exponential backoff (3s → 30s max)
- **Connection status**: connecting/connected/disconnected/error
- **Cleanup**: Automatic unsubscribe on unmount

## State Management

### Server State (TanStack Query)

Use TanStack Query for data fetching and caching:

```tsx
import { useQuery, useMutation } from '@tanstack/react-query'

function TaskList() {
  // Fetch data
  const { data, isLoading } = useQuery({
    queryKey: ['tasks'],
    queryFn: fetchTasks,
  })

  // Mutate data
  const mutation = useMutation({
    mutationFn: createTask,
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ['tasks'] })
    },
  })

  return <div>{/* UI */}</div>
}
```

### Client State (Zustand)

Use Zustand for UI state and preferences:

```tsx
import { create } from 'zustand'
import { persist } from 'zustand/middleware'

interface DashboardState {
  selectedMetrics: string[]
  dateRange: [Date, Date]
  setSelectedMetrics: (metrics: string[]) => void
}

export const useDashboardStore = create<DashboardState>()(
  persist(
    (set) => ({
      selectedMetrics: ['traffic', 'conversions'],
      dateRange: [new Date(), new Date()],
      setSelectedMetrics: (metrics) => set({ selectedMetrics: metrics }),
    }),
    {
      name: 'dashboard-storage',
    }
  )
)
```

## Component Patterns

### Server Components

Use Server Components for static content and data fetching:

```tsx
// app/posts/page.tsx
export default async function PostsPage() {
  const posts = await fetchPosts()

  return (
    <div>
      {posts.map((post) => (
        <PostCard key={post.id} post={post} />
      ))}
    </div>
  )
}
```

### Client Components

Use Client Components for interactivity:

```tsx
'use client'

import { useState } from 'react'

export function InteractiveComponent() {
  const [count, setCount] = useState(0)

  return (
    <button onClick={() => setCount(count + 1)}>
      Count: {count}
    </button>
  )
}
```

## Data Flow

### Optimistic Updates

Update UI immediately, then sync with server:

```tsx
const mutation = useMutation({
  mutationFn: updateTask,
  onMutate: async (newTask) => {
    // Cancel outgoing refetches
    await queryClient.cancelQueries({ queryKey: ['tasks'] })

    // Snapshot previous value
    const previousTasks = queryClient.getQueryData(['tasks'])

    // Optimistically update
    queryClient.setQueryData(['tasks'], (old) => [...old, newTask])

    return { previousTasks }
  },
  onError: (err, newTask, context) => {
    // Rollback on error
    queryClient.setQueryData(['tasks'], context.previousTasks)
  },
})
```

### Real-Time Sync

Combine real-time updates with optimistic updates:

```tsx
function TaskList() {
  const { data } = useQuery({ queryKey: ['tasks'], queryFn: fetchTasks })

  useRealtime({
    table: 'tasks',
    onInsert: (payload) => {
      queryClient.setQueryData(['tasks'], (old) => [...old, payload])
    },
  })

  return <div>{/* UI */}</div>
}
```

## Performance

### Static Generation

Pre-render pages at build time:

```tsx
export async function generateStaticParams() {
  const posts = await fetchPosts()
  return posts.map((post) => ({ slug: post.slug }))
}
```

### Caching

TanStack Query automatically caches data:

```tsx
const { data } = useQuery({
  queryKey: ['tasks'],
  queryFn: fetchTasks,
  staleTime: 5 * 60 * 1000, // 5 minutes
  cacheTime: 10 * 60 * 1000, // 10 minutes
})
```
