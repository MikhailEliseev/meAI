# 🎯 Шпаргалка: Как использовать meAI

**Последнее обновление:** 2026-05-03 19:35 GMT+3

---

## 🚀 Самый быстрый способ

Напиши в Claude Code (этот чат):

```
/architect [твой вопрос]
```

**Примеры:**

```
/architect Какую нишу выбрать первой?
/architect Создай SEO агента
/architect Запусти AIM Agency
```

---

## 📊 Что происходит

```
ТЫ → /architect → ARCHITECT → решение → ТЫ → "Да" → РЕАЛИЗАЦИЯ
```

---

## 💡 Типы вопросов

### ✅ Хорошие (стратегические):
- Какую нишу выбрать?
- С чего начать?
- Какую цену ставить?
- Создай агента X

### ❌ Плохие (тактические):
- Как написать код? (это для Claude Code)
- Где баг? (это для отладки)
