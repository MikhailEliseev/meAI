# Бриф: Budget Optimizer Agent

**Дата:** 2026-05-10  
**Приоритет:** P1  
**Родительский Magister:** Ads Magister

## Назначение

Автоматическая оптимизация бюджетов рекламных кампаний на основе данных о производительности. Агент анализирует метрики (ROI, CPA, конверсии), принимает решения об оптимальном распределении бюджета и автоматически применяет изменения.

## Контекст и специфика

**Медицинский маркетинг:**
- Сезонные паттерны (грипп зимой, аллергии весной, косметология перед летом)
- LTV оптимизация (пациенты возвращаются, важен lifetime value)
- Geo-специфичное бюджетирование (разные регионы = разная стоимость привлечения)

**Автономность:**
- Полная автономность — агент сам принимает решения и применяет изменения
- Не требует подтверждения для каждого изменения
- Работает в рамках заданных ограничений (min/max бюджет, пороги ROI)

## Интеграции

**Входные данные:**
- Метрики производительности от Performance Monitor Agent
- Данные кампаний от Campaign Manager Agent
- Аналитика от Analytics Agent (ROI, LTV, сезонность)

**Выходные данные:**
- Обновлённые бюджеты кампаний (для Campaign Manager)
- Рекомендации по перераспределению (для Ads Magister)
- Отчёты об оптимизации (для Analytics)

**Связанные агенты:**
- Campaign Manager Agent — получает обновлённые бюджеты
- Performance Monitor Agent — источник метрик
- Analytics Agent — источник аналитики и получатель отчётов

**Внешние API:**
- Яндекс.Директ API (P0) — изменение бюджетов кампаний
- VK Ads API (P1) — изменение бюджетов кампаний
- myTarget API (P2) — изменение бюджетов кампаний
- Telegram Ads API (P2) — изменение бюджетов кампаний
- Дзен API (P2) — изменение бюджетов кампаний

## Приоритеты исследования

### 🔴 КРИТИЧНО (обязательно глубоко изучить)

1. **Bid optimization algorithms**
   - Алгоритмы оптимизации ставок (CPC, CPA, ROAS)
   - Стратегии назначения ставок (Manual, Target CPA, Maximize Conversions, Target ROAS)
   - Факторы Quality Score и их влияние на стоимость
   - Автоматические vs ручные стратегии (когда что использовать)
   - Медицинская специфика (ограничения, compliance)

2. **Budget allocation strategies**
   - Методы распределения бюджета между кампаниями
   - Приоритизация на основе ROI, конверсий, LTV
   - Geo-специфичное распределение (разные регионы)
   - Сезонное распределение (паттерны спроса)
   - Ограничения и пороги (min/max бюджет на кампанию)

3. **Budget pacing algorithms**
   - Алгоритмы равномерного расходования бюджета
   - Предотвращение преждевременного исчерпания
   - Адаптация к изменениям производительности
   - Дневные/недельные/месячные лимиты
   - Медицинская специфика (сезонность, LTV)

### 🟡 ВАЖНО (изучить, но не так глубоко)

1. **ROI optimization techniques**
   - Методы максимизации ROI
   - Балансировка между объёмом и эффективностью
   - LTV учёт для медицинского маркетинга
   - Прогнозирование ROI на основе исторических данных

2. **Performance metrics and thresholds**
   - Ключевые метрики (ROI, CPA, конверсии, Quality Score)
   - Пороговые значения для принятия решений
   - Бенчмарки для медицинского маркетинга
   - Частота проверки и обновления

3. **Multi-platform budget management**
   - Особенности бюджетирования на разных платформах
   - API для изменения бюджетов (Яндекс, VK, myTarget, Telegram, Дзен)
   - Ограничения и лимиты API
   - Синхронизация изменений между платформами

### 🟢 ОПЦИОНАЛЬНО (можно пропустить или поверхностно)

1. **Machine learning for budget prediction**
   - ML модели для прогнозирования оптимальных бюджетов
   - Обучение на исторических данных
   - Автоматическая адаптация стратегий

2. **A/B testing for budget strategies**
   - Тестирование разных стратегий распределения

## Стратегии оптимизации

**Выбранные стратегии (из интервью):**

1. **Bid optimization** — оптимизация ставок на основе производительности
2. **Budget pacing** — равномерное расходование бюджета
3. **ROI optimization** — максимизация возврата инвестиций

**Не выбрано (но может быть добавлено позже):**
- Budget reallocation — перераспределение между кампаниями (частично покрыто через Budget allocation)
- Dayparting optimization — оптимизация по времени суток

## Метрики успеха

**Из интервью:**
- ROI improvement — улучшение возврата инвестиций
- Conversion rate increase — рост конверсий
- CPA reduction — снижение стоимости привлечения

**Дополнительные метрики:**
- Quality Score improvement — рост качества кампаний
- Budget utilization — эффективность использования бюджета
- LTV optimization — оптимизация lifetime value пациентов
