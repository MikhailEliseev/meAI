## Назначение

**Keyword Research Agent** — агент для подбора ключевых слов для SEO-оптимизации медицинских сайтов. Анализирует поисковые запросы, отслеживает позиции сайта и даёт рекомендации по использованию ключевых слов для оптимизации контента.

**Основные задачи:**
- Подбор релевантных ключевых слов для медицинских услуг
- Анализ частотности, конкуренции, коммерческого интента
- Кластеризация ключевых слов по темам и страницам
- Отслеживание позиций сайта в поисковых системах
- Учёт медицинской специфики и законодательства РФ

## Контекст и специфика

### Медицинская специфика (КРИТИЧНО)

1. **Законодательство РФ (ФЗ-38, ФЗ-323)**
   - Запрещённые формулировки в рекламе медицинских услуг
   - Ограничения на гарантии результата ("100% излечение", "гарантируем")
   - Запрет на сравнительную рекламу ("лучшая клиника", "самый опытный врач")
   - Требования к упоминанию лицензий и противопоказаний

2. **Низкая частотность запросов**
   - Медицинские запросы обычно низкочастотные (10-1000 показов/месяц)
   - Высокая конверсия при низкой частотности (2-5% vs 0.5-1% в e-commerce)
   - Длинные хвосты (long-tail) критичны для медицинского SEO
   - Фокус на качестве трафика, а не на объёме

3. **Региональность**
   - Медицинские услуги привязаны к локации клиники
   - Обязательный учёт региона в ключевых словах ("стоматология москва", "мрт спб")
   - Разная частотность по регионам (Москва vs регионы)
   - Локальный поиск критичен (Google Maps, Яндекс.Карты)

4. **Профессиональная терминология**
   - Пациенты используют бытовые термины ("болит зуб")
   - Врачи используют медицинские термины ("пульпит", "периодонтит")
   - Необходимо покрывать оба типа запросов
   - МКБ-10 коды для точного таргетинга

## Интеграции

### Входные данные

**От SEO Magister:**
- URL сайта для анализа
- Целевой регион (город, область)
- Список конкурентов (опционально)
- Seed keywords (начальные ключевые слова)

**От Competitor Analysis Agent:**
- Ключевые слова конкурентов
- Позиции конкурентов по ключевым словам
- Органический трафик конкурентов

**От пользователя (через AskUserQuestion):**
- API токены (Яндекс.Вордстат, Google Keyword Planner, Метрика, Analytics)
- Целевые услуги/специализации клиники
- Бюджет на платные инструменты (Ahrefs, Semrush, SE Ranking)

### Выходные данные

**Для Content Optimization Agent:**
- Список ключевых слов с метриками (частотность, конкуренция, CPC)
- Кластеры ключевых слов по темам
- Рекомендации по использованию (Title, H1, Description, текст)
- Приоритизация (высокий/средний/низкий потенциал)

**Для Technical SEO Agent:**
- Структура сайта под ключевые слова (какие страницы создать)
- URL-структура для новых страниц
- Внутренняя перелинковка по ключевым словам

**Для SEO Magister:**
- Отчёт о подобранных ключевых словах
- Метрики качества (coverage, relevance, potential traffic)
- Рекомендации по SEO-стратегии

### Связанные агенты

1. **Competitor Analysis Agent** (P1) — получать данные о ключевых словах конкурентов
2. **Content Optimization Agent** (P1) — передавать подобранные ключевые слова
3. **Technical SEO Agent** (P1) — координировать техническую оптимизацию
4. **GEO Agent** (P1) — параллельная оптимизация под AI-поиск (ChatGPT, Perplexity)

### Внешние API

**Обязательные:**
- Яндекс.Вордстат API — частотность запросов в Яндексе
- Google Keyword Planner API — частотность запросов в Google
- Яндекс.Метрика API — реальный трафик сайта
- Google Analytics API — реальный трафик сайта

**Опциональные (платные):**
- Ahrefs API — анализ конкурентов, keyword difficulty ($99-999/месяц)
- Semrush API — конкурентный анализ ($119-449/месяц)
- SE Ranking API — мониторинг позиций ($39-189/месяц)
- TopVisor API — автоматический сбор позиций (от 500₽/месяц)

## Приоритеты исследования

### 🔴 КРИТИЧНО (обязательно глубоко изучить)

1. **Методы подбора ключевых слов для медицинской тематики**
   - Seed keyword expansion (расширение начальных ключевых слов)
   - Long-tail keyword research (поиск длинных хвостов)
   - Question-based keywords ("как лечить", "что делать если")
   - Локальные модификаторы (город, район, метро)

2. **API и инструменты для keyword research**
   - Яндекс.Вордстат API (документация, лимиты, цены)
   - Google Keyword Planner API (документация, лимиты, цены)
   - Ahrefs API (возможности, цены, альтернативы)
   - Semrush API (возможности, цены, альтернативы)
   - SE Ranking API (возможности, цены, альтернативы)

3. **Алгоритмы кластеризации ключевых слов**
   - Semantic clustering (семантическая кластеризация)
   - SERP-based clustering (кластеризация по выдаче)
   - Intent-based clustering (кластеризация по интенту)
   - Автоматическая vs ручная кластеризация

4. **Метрики оценки качества ключевых слов**
   - KEI (Keyword Effectiveness Index) = (Search Volume)² / Competition
   - Keyword Difficulty (сложность ранжирования)
   - Search Intent (информационный/коммерческий/навигационный)
   - CPC (Cost Per Click) как индикатор коммерческости
   - Seasonal trends (сезонность запросов)

5. **Законодательство РФ о медицинской рекламе**
   - ФЗ-38 "О рекламе" (статья 24 о медицинской рекламе)
   - ФЗ-323 "Об основах охраны здоровья граждан"
   - Запрещённые формулировки и гарантии
   - Требования к упоминанию лицензий
   - Штрафы за нарушения (для понимания рисков)

### 🟡 ВАЖНО (изучить, но не так глубоко)

1. **Конкурентный анализ ключевых слов**
   - Методы анализа конкурентов (Ahrefs, Semrush)

   - Content gap analysis (какие темы не покрыты)

2. **Мониторинг позиций**
   - Автоматический сбор позиций (TopVisor, SE Ranking)
   - Частота обновления позиций

3. **Интеграция с аналитикой**
