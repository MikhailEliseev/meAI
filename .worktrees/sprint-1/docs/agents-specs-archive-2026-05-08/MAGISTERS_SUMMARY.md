## 📋 ВСЕ 9 MAGISTERS

### 1. SEO MAGISTER ⭐⭐⭐
**Файл:** `SEO_MAGISTER_SPEC.md`

**Роль:** SEO стратегия и оптимизация

**Ключевые особенности:**
- GEO Orchestrator (оптимизация под нейросети)
- Medical Fact-Checker Agent (обязательно!)
- Глубина анализа: только FULL (качество > скорость)
- Источники знаний: Clipper + Inbox + Gatekeeper

**Критерии успеха:**
- Рост позиций, трафика, заявок
- Снижение CAC
- Рост конверсии из органики

---

### 2. CONTENT MAGISTER ⭐⭐⭐
**Файл:** `CONTENT_MAGISTER_SPEC.md`

**Роль:** Смысл контента для всех носителей

**Ключевые особенности:**
- Content = СМЫСЛ (не формат!)
- Чёткие инструкции для КАЖДОГО типа контента
- Tone of Voice от Brand Magister
- Medical Fact-Checker Subagent
- Два режима: строгий (начало) → расслабленный (доверие)

**Subagents по типам:**
- Reels, SEO, Blog, YouTube, Email, Telegram/VK, Landing, Banner, Call Center, Leaflet
- Editor, Fact-Checker, SEO Optimizer

**Критерии успеха:**
- Контент генерирует продажи
- Соответствие Tone of Voice
- Медицинская точность

- Квас-квасная аналитика (деньги с каждого объявления)
- Тестирование гипотез (основа перформанса!)
- Автоматическая корректировка (ОБЯЗАТЕЛЬНА!)
- Динамическая оптимизация бюджета

**Платформы:**
- Яндекс Директ (основная)
- VK Реклама
- Telegram Ads

**Критерии успеха:**
- Снижение CPA
- Рост конверсии
- Положительный ROI

### 4. SOCIAL MAGISTER ⭐⭐⭐
**Файл:** `SOCIAL_MAGISTER_SPEC.md`

**Роль:** Полноценный SMM + тренд-вотчинг

**Ключевые особенности:**
- Тренд-вотчинг ⭐⭐⭐ ОДИН ИЗ САМЫХ СИЛЬНЫХ БЛОКОВ
- Процесс: Apify → Скрапинг → Анализ виральности → Транскрибация → Адаптация
- Piratex.ai (анализ виральных роликов по кадрам)
- AI Sales Admin Agent (Продажник-Администратор 24/7)
- Два типа негатива: продуктивный (собирать) vs деструктивный (фильтровать)

**Соцсети:**
- Instagram ⭐⭐⭐ (основной в эстетической медицине)
- Telegram, VK, YouTube, TikTok, Дзен, VC.ru, Threads, ОК

**Критерий успеха:** ДЕНЬГИ (продажи с канала, не охваты!)

### 5. ANALYTICS MAGISTER ⭐⭐⭐⭐⭐
**Файл:** `ANALYTICS_MAGISTER_SPEC.md`

**Роль:** Data-driven центр принятия решений

**Ключевые особенности:**
- От него зависит ВСЁ (критически важный компонент)
- Собирает данные со ВСЕХ микроагентов и источников
- Data Reconciliation Agent (сверка данных, поиск истины) ⭐⭐⭐
- Competitor Analysis Agent (еженедельный мониторинг)
- Имплементация данных для бизнеса (понятно владельцу)

**Частота:**
- Сбор данных: ежедневно (каждое утро за предыдущий день)
- Анализ: еженедельно
- Мониторинг конкурентов: еженедельно

**Источники:**
- GA, Metrica, Keys.so, Direct API, VK Ads API
- Webmaster Tools, CallTouch, Roistat
- Apify (конкуренты), Репутационные сервисы

**Критерии успеха:**
- Все решения на основе данных
- Корреляция действий → результаты
- Предсказание трендов

### 6. INTELLIGENCE MAGISTER ⭐⭐⭐⭐
**Файл:** `INTELLIGENCE_MAGISTER_SPEC.md`

**Роль:** Разведка внешнего мира

**Три направления:**

1. **Competitive Intelligence** (конкурентная разведка)
   - Что делают конкуренты
   - Предиктивный слой (предугадывать действия)
   - Перехват лидов (факапы конкурентов)

2. **Market Intelligence** (рыночная разведка)
   - Тренды рынка
   - Инфлюенсеры и лидеры мнений
   - Рынок медицины (аппараты, препараты, рост)

3. **Opportunity Intelligence** (разведка возможностей)
   - Новые технологии, платформы, методы
   - AI тренды
   - Зарубежный опыт

**Большой рой CI субагентов:**
- Tech, Content, Social, Ads, Price, Reputation
- Media Monitor, Telegram Channel Monitor, Comment Analyzer
- Predictive, Lead Interceptor

**Критерии успеха:**
- Знаем о конкурентах больше, чем они о себе
- Перехватываем возможности
- Предугадываем тренды

### 7. BRAND MAGISTER ⭐⭐⭐⭐⭐
**Файл:** `BRAND_MAGISTER_SPEC.md`

**Роль:** Стратег бренда

**Ключевые функции:**

1. **Двойной CustDev** ⭐⭐⭐⭐⭐
   - **Синтетический:** Advanced JTBD Platform (165+ аватаров, готов!)
   - **Реальный:** Транскрибация звонков, комментарии, обратная связь

2. **Tone of Voice** ⭐⭐⭐⭐⭐
   - Деликатный ToV на основе реального языка пациентов
   - Обновление: ежеквартально
   - Передача: Content Magister + Social Magister

3. **Визуальный анализ** ⭐⭐⭐⭐⭐ НОВОЕ!
   - **Статический:** Скриншоты (Playwright) + анализ (Claude Vision)
   - **Динамический:** Yandex Webvisor (тепловые карты, критические точки)
   - Visual Brand Analyzer Agent

4. **Позиционирование**
   - Отстройка от конкурентов vs мимикрия
   - Построение сильного бренда

**Критерии успеха:**
- Узнаваемость бренда
- Соответствие ToV во всех каналах
- Сильное позиционирование

### 9. REPUTATION MAGISTER ⭐⭐⭐
**Файл:** `REPUTATION_MAGISTER_SPEC.md`

**Роль:** Репутационный разведчик + Менеджер репутации

**Ключевые особенности:**
- Два направления: разведка конкурентов + управление нашей репутацией
- Social Chat Agent (бот на OpenClaw, 24/7, самообучающийся)
- NPS: синтетический (анализ фона) + реальный (опросы)
- Baseline метрики на setup + динамика месяц от месяца
- Работа с негативом: продуктивный vs деструктивный
- Скорость реагирования < 2 часов
- Мониторинг конкурентов еженедельно

**Источники:**
- Яндекс.Карты, Google Reviews, 2GIS, Zoon, ПроДокторов, Напоправку
- Медиалогия (API), Telegram (Telemetr)

**Критерии успеха:**
- Рост рейтинга, снижение негатива
- 90%+ автоответов
- Знаем о факапах конкурентов раньше всех

## 🔗 СВЯЗИ МЕЖДУ MAGISTERS

- Получает данные от ВСЕХ Magisters
- Агрегирует и анализирует
- Показывает корреляции
- Передаёт инсайты обратно

- Передаёт Tone of Voice
- Передаёт позиционирование
- Передаёт визуальный стиль

- Передаёт Tone of Voice
- Передаёт визуальный стиль

- Передаёт данные о конкурентах
- Передаёт рыночные тренды

- Передаёт упоминания в СМИ

- Передаёт инсайты из негатива (что улучшить)

- Запрашивает сценарии для Reels, постов

- Запрашивает SEO-оптимизированный контент

### Ads Magister → Content Magister:
- Запрашивает креативы для рекламы

### AI Magister → ВСЕ Magisters:
- Проектирует AI-агентов для каждого
- Обучает и оптимизирует

## 🎯 КЛЮЧЕВЫЕ ПРИНЦИПЫ

### 1. Complete Before Next Rule
Доводим до 100% перед переходом к следующей задаче.

### 2. Quality Over Speed Rule
Качество важнее скорости. Всегда.

### 3. Mock Data Rule
Никаких mock данных в production коде.

### 4. Роль Magisters
- ❌ НЕ исполняют задачи сами
- ✅ Обучают Orchestrators и Subagents
- ✅ Следят за качеством работы своего направления
- ✅ Получают знания от Teacher Agent

### 5. Медицинская специфика
- Medical Fact-Checker Agent (обязательно!)
- Два режима: строгий (начало) → расслабленный (доверие)
- Академические источники
- Утверждение у доктора
- Законодательство РФ

### 6. Data-driven подход
Все решения на основе метрик, не предположений.

### 7. Принцип гибкости
Система адаптируется на основе опыта проектов.

## 📊 ПРИОРИТЕТЫ РЕАЛИЗАЦИИ

### Фаза 1: Критичные компоненты (P0)

**Обязательно для запуска:**
1. **Operator** — управление проектами

**Почему:** Без этих компонентов система не работает.

---

### Фаза 2: Основные каналы (P1)

**Для генерации лидов:**
5. **SEO Magister** — органический трафик
6. **Ads Magister** — платный трафик
7. **Social Magister** — SMM и тренд-вотчинг

**Почему:** Основные каналы привлечения клиентов.

---

### Фаза 3: Разведка и репутация (P2)

**Для конкурентного преимущества:**
8. **Intelligence Magister** — разведка конкурентов и рынка
9. **Reputation Magister** — управление репутацией

**Почему:** Дают конкурентное преимущество, но не критичны для запуска.

---

### Фаза 4: AI-оптимизация (P3)

**Для масштабирования:**
10. **AI Magister** — оптимизация AI-систем

**Почему:** Нужен, когда система уже работает и нужно масштабировать.
