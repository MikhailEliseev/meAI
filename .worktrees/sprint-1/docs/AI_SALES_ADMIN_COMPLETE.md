## 🎯 Ключевые особенности агента

### Роль
**AI Sales Admin Agent** — виртуальный администратор клиники 24/7, который мониторит все каналы коммуникации, отвечает по протоколам и использует структурированную базу знаний из Obsidian Vault.

### Уникальная ценность
- **24/7 доступность** — клиенты пишут в любое время
- **Мгновенный ответ** — < 30 секунд (конкуренты отвечают часами)
- **Омниканальность** — один агент на все каналы (Telegram, Instagram, VK, WhatsApp, сайт)
- **Суперэкспертиза** — знает всё о продуктах/ценах/врачах
- **Квалификация лидов** — превращает холодных в квали-лидов
- **152-ФЗ compliance** — соблюдает закон о персональных данных

### Критичность
⭐⭐⭐⭐ **P1 (Важный)** — без AI Sales Admin клиника теряет лидов из-за медленных ответов, нет квалификации, менеджеры перегружены.

## 🔧 Технические детали

### Алгоритм работы (8 шагов)
1. Получение сообщения (Telegram/Instagram/VK/WhatsApp/сайт)
2. Создание/обновление лида в CRM (сразу, даже незначительные коммуникации)
3. Быстрый ответ (< 30 секунд)
4. Квалификация лида (потребность, срочность, готовность)
5. Ответ на вопросы (из базы знаний Obsidian)
6. Запись на консультацию (интеграция с календарём)
7. Эскалация менеджеру (если необходимо)
8. Сохранение истории (CRM + Obsidian)

### Каналы коммуникации
- **Telegram** — Telegram Bot API
- **Instagram** — Instagram Graph API (Direct)
- **VK** — VK API (сообщения сообщества)
- **WhatsApp** — WhatsApp Business API
- **Сайт** — Website Chat API (Jivo, Carrot quest)

### База знаний
- **Obsidian Vault** — структурированная база знаний (продукты, цены, врачи, FAQ)
- **Мониторинг сайта** — WordPress REST API / Bitrix24 REST API (автоматическое обновление)
- **Медицинские источники** — Perplexity API (для сложных вопросов)

### Особенности
- **152-ФЗ compliance** — медицинские данные → немедленная эскалация менеджеру
- **Протокол неадекватного поведения** — предупреждение → эскалация → блокировка
- **Setup под каждый проект** — квалификация, ToV, правила эскалации настраиваются индивидуально
- **Deployment на сервере 24/7** — не локально, круглосуточная доступность
- **Изоляция проектов** — каждый проект = отдельный агент с отдельной базой знаний
- **Голосовое общение** — Assembly AI + OpenAI GPT-4o-mini + fallback на китайские модели

## 🚨 Специфичные ошибки

**API_UNAVAILABLE:**
- API канала недоступен (Telegram/Instagram/VK down)
- Retry 3 раза → логировать → уведомить администратора

**CRM_CONNECTION_ERROR:**
- CRM не отвечает
- Retry 3 раза → сохранить в Obsidian → синхронизировать позже

**OPENAI_API_ERROR:**
- OpenAI API недоступен
- Fallback на DeepSeek / Qwen → шаблонные ответы (FAQ)

**KNOWLEDGE_BASE_OUTDATED:**
- База знаний устарела (цены изменились)
- Предупредить пациента → обновить базу → эскалация менеджеру

**INAPPROPRIATE_BEHAVIOR:**
- Неадекватное поведение пациента (мат, угрозы, спам)
- Протокол: предупреждение → эскалация → блокировка

**MEDICAL_DATA_REQUEST (КРИТИЧНО):**
- Пациент просит медицинские данные (152-ФЗ)
- Немедленная эскалация менеджеру (без попыток ответить)
- Логирование для аудита 152-ФЗ

**COMPLEX_QUESTION:**
- Вопрос слишком сложный (агент не знает ответа)
- Честно признать → эскалация менеджеру → логировать для улучшения базы
