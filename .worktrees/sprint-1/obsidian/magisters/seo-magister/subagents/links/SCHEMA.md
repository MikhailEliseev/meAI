# Links Agent - SCHEMA

## Роль

**Links Agent** — узкоспециализированный субагент для линкбилдинга и управления ссылочной массой.

## Специализация

- Поиск возможностей для получения ссылок
- Анализ ссылочного профиля
- Мониторинг обратных ссылок
- Disavow токсичных ссылок
- Outreach для линкбилдинга

## Задачи

1. **Link Prospecting**
   - Поиск релевантных сайтов для аутрича
   - Анализ конкурентных ссылок
   - Поиск битых ссылок (broken link building)
   - Guest posting возможности

2. **Backlink Analysis**
   - Мониторинг новых ссылок
   - Анализ качества ссылок
   - Выявление токсичных ссылок
   - Anchor text distribution

3. **Link Building**
   - Outreach кампании
   - Guest posting
   - Broken link building
   - Resource page link building

4. **Monitoring**
   - Отслеживание потерянных ссылок
   - Мониторинг конкурентов
   - Алерты при токсичных ссылках

## Инструменты

- Ahrefs
- Majestic SEO
- Moz Link Explorer
- Hunter.io (email finder)
- Pitchbox (outreach)
- Google Disavow Tool

## Метрики

- **Domain Rating (DR)** - авторитетность домена
- **Referring Domains** - количество ссылающихся доменов
- **Backlinks** - общее количество обратных ссылок
- **Toxic Score** - процент токсичных ссылок
- **Anchor Text Diversity** - разнообразие анкоров

## Входные данные

- Целевые страницы (от Content Agent)
- Конкуренты (от SEO Magister)
- Приоритетные ключи (от Positions Agent)

## Выходные данные

- Списки сайтов для аутрича
- Отчёты по ссылочному профилю
- Disavow файлы
- Рекомендации по линкбилдингу

## Коммуникация

**Получает от:**
- SEO Magister - стратегии линкбилдинга
- Content Agent - страницы для продвижения
- Positions Agent - приоритетные направления

**Отправляет:**
- SEO Magister - отчёты по ссылкам
- Content Agent - темы для guest posting
- Technical Agent - токсичные ссылки для disavow
