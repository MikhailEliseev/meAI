# Claude Design для создания сайтов - Практический гайд

## Ключевой инсайт

**Раньше:** 100,000₽ за сайт от специалистов  
**Сейчас:** 0₽ за 1 час в Claude Design

## Что такое Claude Design

**Claude Design** - новый инструмент от Anthropic для создания:
- Сайтов
- Презентаций
- Графики
- Макетов
- Изображений для соцсетей

**Статус:** Неофициальный релиз (в разработке, будет улучшаться)

## Workflow создания сайта

### 1. Design System (Брендбук)

**Что включает:**
- Фирменные цвета
- Логотипы
- Шрифты
- Элементы дизайна
- Примеры иконок

**Время создания:** 15 минут (автоматически)

**Преимущество:** Можно загружать несколько систем и переключаться между проектами

### 2. Три платформы с готовыми дизайн-системами

**Платформа 1:** 70+ готовых шаблонов
- Apple, Ferrari, Lamborghini, Nvidia, Claude и др.

**Платформа 2:** Обширная подборка
- Готовые бренд-платформы
- Шаблоны сайтов и приложений

**Платформа 3:** Копирование любого сайта
- Вставляешь ссылку → получаешь дизайн-систему
- Работает с ЛЮБЫМ сайтом

### 3. Техническое задание

**Важно:** Создавать ТЗ в обычном чате Claude, НЕ в Design
- Экономит лимиты Design
- Можно детально проработать структуру
- Claude исправит ошибки и описки

**Лайфхак:** Избегать AI-стиля
- ❌ Фиолетовые градиенты на белом/чёрном
- ❌ Шрифты Inter или Roboto
- ✅ Своя палитра цветов

### 4. Генерация дизайна

**Модель:** Opus 4.7 (или последняя версия)

**Процесс:**
1. Загрузить ТЗ в Claude Design
2. Добавить фото/материалы
3. Запустить генерацию
4. Получить первую версию

### 5. Ручные правки

**Новая фича:** Редактирование прямо в Design
- Менять текст
- Править переносы
- Двигать элементы
- Менять цвета
- Рисовать стрелки для перемещения

**Как раньше:** Так работал с дизайнером

### 6. Экспорт и доработка

**Форматы экспорта:**
- HTML
- Прямой экспорт в Claude Code

**Дальнейшая работа:**
- Claude Cowork для вёрстки
- Адаптация для ПК/планшет/мобилка
- Добавление анимаций

## Экономика лимитов

**Ключевое преимущество:**

```
Claude Design лимиты ≠ Claude основные лимиты
```

**Стратегия:**
1. **Design лимиты:** Структура, тексты, элементы
2. **Основные лимиты:** Вёрстка, адаптация, код

**Результат:** Экономия основных лимитов

## Фильтр от AI-текстов

**Проблема:** Claude пишет "AI-шные" тексты

**Решение:** Файл с 27 фильтрами
- Убирает намёки на AI
- Делает текст человечным
- Обязательно использовать!

## Анимации и интерактив

**Сервис с шаблонами:** Большое количество готовых решений
- Копируешь промпт/код
- Вставляешь в Cowork
- Объясняешь на человеческом языке

**Предупреждение:** Не перегружать!
- Каждая анимация = тяжелее сайт
- Увеличивается время загрузки
- Использовать с умом

## Результат

**Время:** ~1 час работы

- Минималистичный дизайн
- Интерактивные элементы

- Быстрая загрузка
