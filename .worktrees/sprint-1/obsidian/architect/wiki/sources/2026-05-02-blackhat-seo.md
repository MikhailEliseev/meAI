# BlackHat SEO для iGaming - Анализ методов

## Ключевые инсайты

### 1. Вирусный трафик (Viral Traffic Manipulation)

**Суть метода:**
- Загнать 5-10k живых людей на сайт за 1 час
- Google видит хайп → сайт взлетает на +30-50 позиций за 2-3 часа
- Держится 1-2 дня, потом повторить
- **Критично:** только живые люди, не боты

**Почему работает:**
- Google бот во Флориде отслеживает вирусные всплески
- Система думает, что контент стал популярным в соцсетях
- Алгоритм временно поднимает позиции

**Ограничения:**
- Нельзя делать >6 месяцев подряд (Google пересчитывает метрики)
- Лучше всего для сезонных событий (чемпионаты, турниры)
- Стратегия: "подержался неделю, собрал сливки, вырубил"

### 2. Китайский метод реюза дропдоменов

**Инсайд от команды из Гонконга:**

1. Берут дроп-домен
2. Сразу реюзают (выбрасывают весь веб-архив)
3. Заливают 10 страниц с гемблой
4. Наваливают 5000 ссылок с анкорами за 2 дня
5. Быстро индексируют через баг с Lazada (маркетплейс)

**Результат:**
- 50/50 шанс: либо бан, либо мгновенный ранжинг по гемблу
- Альтернатива: приклеить к Википедии gambling, потом отклеить

**Срабатывание:** 40-60% (40% не в твою пользу)

### 3. AI-агенты для автоматизации

**Что автоматизировать:**

1. **Генерация сайтов:**
   - Скрейпинг дизайна (например, с 1win)
   - Создание структуры по SEO
   - Генерация контента
   - Заливка на CloudFlare Pages
   - Время: 7-8 минут на 50-60 страниц

2. **Управление позициями:**
   - Агент видит позиции в Google
   - Автоматически закупает вирусный трафик при падении
   - Держит сайт в топе без участия человека

3. **Линкбилдинг:**
   - Агенты переписываются с индусами ("Hello sir links")
   - Договариваются о размещении автоматически

### 4. Стратегия массового запуска

**Подход:**
- Запустить 100 новорегов (exact match domains)
- Выживает 7-10 сайтов
- Из них 3 топперформера
- С ними работать дальше

**Экономика:**
- Линкбилдинг: $200-500 на сайт
- 20 сайтов × $500 = $10,000 на запуск
- Дропдомены: инфляция ~100% за 2 года ($300-400 → $1500-2000)

### 5. Типы сайтов под iGaming

**Монобренды:**
- Главный запрос: "onewin login" (не просто "onewin casino")
- Страницы: login, registration, бонусы, популярные игры
- Слоты: название + бонусы + стратегии

**Ревюшники:**
- Большой домен с обзорами казино
- Нужны качественные ссылки (outreach, гостевые посты)
- Старт от $200k

**Слотовые сайты:**
- Либо хайповый слот (высокая конкуренция)
- Либо инсайды (знать, какие бренды запустятся)

## Технологические решения

### CloudFlare Pages
- Статические HTML-страницы
- Нет хостинга, нет сервера
- Невозможно взломать (нет бэкенда)
- Бесплатно на базовом плане
- Встроенная DDoS-защита

### Bing для США
- 800 млн поисков/месяц
- Богатая аудитория (штат Вашингтон = 40% трафика)
- 2-3 недели до топ-1
- Стабильные позиции
- Подходит для sweepstakes/social casino

### SEO для LLM
- Оптимизация под ChatGPT, Perplexity, Gemini
- Добавить сайт в Bing Webmaster Tools → индексация для ChatGPT
- Google AI Overviews = тот же индекс Google
- Если нет в индексе Google → нет в ответе LLM

- Строить активы (дропдомены = новая недвижимость)
- Не держать все деньги в одной корзине
