# Deep Research Vault Schema

**Назначение:** Хранение истории всех deep-research исследований для переиспользования и анализа стоимости.

---

## Структура vault

```
deep-research/
├── raw/                    # Исходные отчёты исследований
│   └── YYYY-MM-DD-topic/   # Папка на исследование
│       ├── report.md       # Основной отчёт
│       ├── sources.jsonl   # Источники
│       ├── evidence.jsonl  # Доказательства
│       └── manifest.json   # Метаданные (токены, время, режим)
├── wiki/                   # Структурированное знание
│   ├── index.md           # Каталог всех исследований
│   ├── log.md             # Хронология операций
│   ├── topics/            # Исследования по темам
│   ├── statistics/        # Статистика использования
│   └── reuse/             # Переиспользованные данные
└── decisions/             # Решения об оптимизации
    └── cost-optimization.md
```

---

## Операции

### 1. Ingest (после каждого deep-research)

**Вход:** Отчёт из `~/Documents/[Topic]_Research_[YYYYMMDD]/`

**Действия:**
1. Копировать отчёт в `raw/YYYY-MM-DD-topic/`
2. Извлечь метаданные (токены, время, режим) в `manifest.json`
3. Создать страницу в `wiki/topics/[topic].md` с summary
4. Обновить `wiki/index.md` и `wiki/log.md`
5. Обновить статистику в `wiki/statistics/usage.md`

**Выход:** Структурированная запись исследования

### 2. Query (поиск похожих исследований)

**Вход:** Тема нового агента

**Действия:**
1. Поиск в `wiki/topics/` по ключевым словам
2. Проверка `wiki/reuse/` на переиспользованные данные
3. Возврат релевантных исследований

**Выход:** Список похожих исследований для переиспользования

### 3. Lint (проверка здоровья)

**Проверки:**
- Все ли исследования из `raw/` обработаны в `wiki/`?
- Актуальна ли статистика в `wiki/statistics/`?
- Есть ли orphan файлы?

## Метаданные исследования (manifest.json)

```json
{
  "topic": "Blog Content Creation для медицинского маркетинга",
  "date": "2026-05-10",
  "mode": "standard",
  "duration_minutes": 8,
  "tokens": {
    "input": 65000,
    "output": 18000,
    "total": 83000
  },
  "cost_usd": 0.52,
  "sources_count": 12,
  "report_size_kb": 45,
  "used_for": ["Blog Content Agent"],
  "reused_by": []
}
```

---

## Статистика (wiki/statistics/usage.md)

**Отслеживаем:**
- Общее количество исследований
- Общая стоимость (токены + $)
- Среднее время исследования
- Топ-5 самых дорогих исследований
- Топ-5 самых переиспользованных исследований
- Экономия от переиспользования

---

## Правила

1. **Каждое deep-research → Ingest**
   - Сразу после завершения исследования
   - Не откладывать на потом

2. **Query перед новым исследованием**
   - Проверить, есть ли похожие темы
   - Переиспользовать данные, если возможно

3. **Lint раз в неделю**
   - Проверка консистентности
   - Обновление статистики

4. **Решения об оптимизации → decisions/**
   - Когда стоимость превышает порог
   - Когда нужно выбрать режим (standard vs deep)
