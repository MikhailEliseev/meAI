## Phase Goal

**As a** admin (Michael), **I want to** measure how many tools and report sections v4 actually produces today, **so that** Phase 2 can target a concrete baseline instead of a guessed "30% coverage".

<objective>
Measure two baselines from live server sessions:

1. **Tool coverage (RES-02):** Of 40+ tools registered for the LLM, how many does the LLM actually call in a typical v4 presale run? Average across 3-5 recent sessions.
2. **Section coverage (RES-03):** Of 10 reference sections from ИПХиК (2).html, how many actually appear in v4 HTML reports? Average across 3-5 recent reports.

Purpose: These baselines become the "before" numbers. Phase 2's 3-pass orchestrator must beat them. Without measurement, "30% coverage" is a guess — Phase 2 success criteria (≥80% checklist coverage) needs a measured starting point.

Output: `.planning/phases/01-research-diagnosis/evidence/coverage-baseline.md` with per-session tool counts, per-report section mappings, and averaged baselines.
</objective>
