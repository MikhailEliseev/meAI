## Phase Goal (MVP)

**As a** presale client in a cosmetology or plastic surgery niche,
**I want to** be sure that even if the LLM mistakenly marks item 5 as "filled" without actually calling Instagram, the runtime catches it and forces coverage=FAIL,
**so that** the report's QC badge accurately reflects Instagram coverage for my critical niche.

## User Story (Vertical Slice)

After this plan, for `iphk.ru` (plastic surgery, instagram-critical=true):
- Pass 1 runs, Pass 2 evaluates items
- After Pass 2 calc_coverage, `_apply_niche_conditional_coverage(report, "plastic_surgery")` runs:
  - If item 5 is "missing" or absent → forces `report.status = "FAIL"`, logs "QC HARD FAIL override"
  - If item 5 is "filled" → no override
- Pass 3 runs, final calc_coverage, helper runs again
- Final coverage report in `state.collected_data["coverage_report_final"]` reflects the override

For a dental clinic (non-critical):
- After Pass 2 calc_coverage, helper drops item 5 from total (total=14), populates `report.not_applicable_items` with item 5 entry
- Final coverage report has `total_items=14` and `not_applicable_items=[{id:5, ...}]`
- Plan 03-05 HTML renders this with ⚪ icon and gray styling

    def _apply_niche_conditional_coverage(
        report: CoverageReport, niche: str,
    ) -> CoverageReport:
        """Apply niche-conditional logic to a CoverageReport (Phase 3 / D-05 + D-08).

        Three branches:
        - Critical niche (plastic_surgery, cosmetology): hard-FAIL override —
          if item 5 is missing or absent, force status='FAIL' regardless of
          filled count.
        - Non-critical niche: drop item 5 from total (14 vs 15), populate
          not_applicable_items with item 5 entry, filter missing_items to
          exclude id==5, recompute coverage_pct.
        - Unknown niche: return report unchanged (safe fallback).
        """
        from app.orchestrator.qc_checklist import (
            is_niche_instagram_critical, applicable_items, PASS_THRESHOLD,
        )

        if niche == "unknown":
            logger.debug(
                "Niche conditional: niche=unknown — returning report unchanged "
                "(safe fallback)"
            )
            return report

        if is_niche_instagram_critical(niche):
            # Hard-FAIL override (D-05)
            item5_statuses = [
                it.get("status") for it in (
                    # coverage_report does not carry gap_report items directly;
                    # we infer from missing_items + filled_items
                    [{"id": m.get("id"), "status": "missing"} for m in report.missing_items]
                    + [{"id": p.get("id"), "status": "partial"} for p in report.partial_items]
                )
                if it.get("id") == 5
            ]
            item5_missing = (
                5 in [m.get("id") for m in report.missing_items]
                or 5 not in report.filled_items
            )
            # Item 5 is "filled" iff id 5 in filled_items and not in missing_items
            item5_filled = (
                5 in report.filled_items
                and 5 not in [m.get("id") for m in report.missing_items]
            )
            if not item5_filled:
                report.status = "FAIL"
                # Ensure item 5 appears in missing_items (synthetic if absent)
                if 5 not in [m.get("id") for m in report.missing_items]:
                    report.missing_items.append({
                        "id": 5,
                        "name": "Instagram analysis for cosmetology/plastic",
                        "reason": "Instagram-critical niche but run_instagram_content not called in Pass 1",
                        "detail": "",
                    })
                logger.warning(
                    "QC HARD FAIL override: niche=%s is Instagram-critical but "
                    "item 5 missing — forcing coverage=FAIL (filled=%d/15)",
                    niche, len(report.filled_items),
                )
            else:
                logger.info(
                    "Niche conditional: niche=%s critical, item 5 filled — no override",
                    niche,
                )
            return report

        # Non-critical niche — conditional total (D-08)
        applicable_total = len(applicable_items(niche))  # 14 for non-critical
        not_applicable_entries = []
        # Item 5 is the only conditional item (per Plan 03-03 Task 1)
        if 5 not in [a["id"] for a in applicable_items(niche)]:
            not_applicable_entries.append({
                "id": 5,
                "name": "Instagram analysis for cosmetology/plastic",
                "reason": f"not_applicable for non-critical niche ({niche})",
            })

        # Filter missing_items to exclude id==5
        filtered_missing = [
            m for m in report.missing_items if m.get("id") != 5
        ]
        # Recompute coverage with new total
        filled_count = len(report.filled_items)
        new_pct = filled_count / applicable_total if applicable_total else 0.0
        new_status = "PASS" if new_pct >= PASS_THRESHOLD else "FAIL"

        report.total_items = applicable_total
        report.missing_items = filtered_missing
        report.not_applicable_items = not_applicable_entries
        report.coverage_pct = new_pct
        report.status = new_status

        logger.info(
            "QC niche-conditional: niche=%s, applicable_total=%d (item 5 dropped), "
            "coverage=%.1f%% — %s",
            niche, applicable_total, new_pct * 100, new_status,
        )
        return report
