## Контекст

После Wave 1 (Q1-Q5: данные в контекст LLM, temperature, consistency) и Wave 2 (W1-W3: G5/G6/G8) 
добавлены две новые секции в ответ Hermes: **🖥️ Сайт** (технический аудит + что улучшить) и 
**📱 Соцсети** (анализ присутствия vs конкуренты + что развивать). Также построена продающая 
часть отчёта (рекомендации услуг AIM с ценами).

Phase 15 = **тройное тестирование** для верификации, что всё работает стабильно.

## Методология тройного тестирования

### Раунд 1: Базовый (3 клиники, разные профили)
- **implantkrd** (стоматология, сеть) — уже протестирована, базовый случай
- **yutskovskaya** (косметология) — другая специализация
- **delight** (клиника) — третий тип

**Критерий PASS:** каждая клиника ≥ 70% по G1 и G6, G3 и G7 = pass.

### Раунд 2: Стабильность (те же 3 клиники, повтор)
- Те же 3 клиники, новый прогон
- Сравнение G1/G6/G3/G7 между раундами
- **Критерий PASS:** разброс G1 < 15%, G6 < 20% между раундами. G3/G7 стабильно pass.

### Раунд 3: Обобщение (2 новые + 1 знакомая)
- **erasmile** (новая)
- **olymp** (новая)
- **implantkrd** (знакомая, контрольная)

**Критерий PASS:** ≥ 2 из 3 клиник ≥ 70% G1 и G6. Новые клиники не «падают».

### Общий вердикт
- **PASS:** все 3 раунда выполнены, ≥ 70% клиник проходят пороги во всех раундах
- **FAIL:** любой раунд < 50% клиник проходят → анализ причины → фикс → повтор

## Метрики (G1-G8)

| ID | Что меряет | Порог PASS |
|----|-----------|------------|
| G1 | Grounding (точность чисел) | ≥ 70% |
| G3 | Clean output (нет мусора) | pass |
| G6 | Coverage (полнота данных) | ≥ 60% |
| G7 | Consistency (нет противоречий) | pass |
| G8 | Fabricated (нет выдумок) | fabricated = 0 |

## Дополнительно: проверка новых секций

Для КАЖДОЙ клиники проверить:
- [ ] Секция **🖥️ Сайт** присутствует и содержит ≥ 2 конкретных проблемы
- [ ] Секция **📱 Соцсети** присутствует и сравнивает с конкурентами
- [ ] Продающая часть (рекомендации услуг) в отчёте
- [ ] Нет сырых `:::` директив в отчёте

## Acceptance Criteria

- [ ] Раунд 1: 3/3 клиник ≥ пороги G1/G6, G3/G7 pass
- [ ] Раунд 2: разброс между раундами в пределах допуска
- [ ] Раунд 3: ≥ 2/3 клиник ≥ пороги, новые клиники стабильны
- [ ] Новые секции (Сайт/Соцсети) присутствуют на всех кейсах
- [ ] Продающая часть в опубликованных отчётах
- [ ] Финальный вердикт PASS
