**Add two new methods:**

### `async def prescan_staged(self, url: str, progress_callback=None, force_refresh: bool = False) -> dict:`

The main staged pipeline entry point. Returns a dict with all 3 stages' data (not a PrescanResult — that's for backward compat).

Flow:
1. **Cache check:** If `not force_refresh`, try `GET /api/company-profiles/by-url?url={url}`. If `found: true`, return cached profile immediately — skip all stages.
2. **Run stages sequentially:**
   - Stage 1 → `_stage_1_financials(url)` — gather; call progress_callback(1, "Финансовый хук", summary, False)
   - Stage 2 → `_stage_2_deep(url, stage_1_data)` — gather; call progress_callback(2, "Под капотом", summary, False)
   - Stage 3 → `_stage_3_market(url, stage_1_data, stage_2_data)` — gather; call progress_callback(3, "Рынок", summary, True)
3. **Merge results** into `profile_data` dict: `{"stage_1": {...}, "stage_2": {...}, "stage_3": {...}}`
4. **Persist to cache:** `POST /api/company-profiles/upsert` with `{url, inn (from stage_1), profile_data}`
5. **Return** the full profile_data dict

progress_callback signature: `async callback(stage_number: int, stage_name: str, summary: dict, is_final: bool)`

```python
@router.post("/prescan-staged", status_code=status.HTTP_200_OK)
async def run_prescan_staged(body: StagedPrescanRequest):
    """Run 3-stage ultra-deep prescan with progressive results.
    
    Stages:
      1. Финансовый хук (20-30 sec) — revenue, profit, legal entity
      2. Под капотом (40-60 sec) — licenses, founders, deep SEO, reviews, social
      3. Рынок (60-90+ sec) — Yandex/Google Maps, competitors, content audit
    
    Each stage fires a progress callback that can be consumed by Hermes.
    Results are cached in company_profiles for instant repeat queries.
    """
    import time
    
    orchestrator = PrescanOrchestrator()
    t0 = time.monotonic()
    stages_completed = []
    
    async def progress_callback(stage_number: int, stage_name: str, summary: dict, is_final: bool) -> None:
        stages_completed.append({
            "stage": stage_number,
            "name": stage_name,
            "summary": summary,
            "is_final": is_final,
            "timestamp": time.monotonic() - t0,
        })
        logger.info("prescan_staged: stage %d/%s complete in %.1fs",
                     stage_number, stage_name, time.monotonic() - t0)
    
    try:
        result = await orchestrator.prescan_staged(
            body.url,
            progress_callback=progress_callback,
            force_refresh=body.force_refresh,
        )
        
        elapsed = time.monotonic() - t0
        return JSONResponse(content={
            "success": True,
            "url": body.url,
            "elapsed_seconds": round(elapsed, 1),
            "stages": stages_completed,
            "profile_data": result,
            "errors": result.get("_errors", []) if isinstance(result, dict) else [],
        })
    except Exception as e:
        logger.exception("prescan_staged_failed")
        return JSONResponse(
            status_code=status.HTTP_500_INTERNAL_SERVER_ERROR,
            content={
                "success": False,
                "url": body.url,
                "error": str(e),
            },
        )
    finally:
        await orchestrator.close()
```
