**Vault Manager:**
```python
class HermesKnowledgeVault:
    async def ingest_execution(self, event: Event) -> str  # EventBus передаёт объект Event (dataclass)
    async def extract_patterns(self, execution_id: str) -> list[str]  # raw → wiki (LLM)
    async def store_learning(self, domain: str, knowledge: dict)  # → wiki/learnings/
    async def codify_rule(self, pattern_name: str)  # wiki → decisions (validation)
    async def query_context(self, domain: str, action: str) -> dict  # search across wiki/
    async def get_status(self) -> dict  # stats
```

### Task 1.2: EventBus Listener — Hermes подписывается на CI-события

**Файл изменить:** `AIM/hermes/app/main.py`

**Добавить:**
```python
from meai.events.event_bus import EventBus
from hermes.knowledge.vault import HermesKnowledgeVault

# Startup
@app.on_event("startup")
async def on_startup():
    # ... existing ...
    event_bus = EventBus(database_url=os.getenv("DATABASE_URL"))
    await event_bus.initialize()
    vault = HermesKnowledgeVault()
    
    # Subscribe to CI execution events
    event_bus.subscribe("ci.execution.completed", vault.ingest_execution)
    event_bus.subscribe("ci.agent.completed", vault.ingest_agent_result)
```

**Типы событий:**
- `ci.execution.started` — начался CI-анализ (источник, ниша, гео)
- `ci.agent.completed` — агент завершил работу (результат)
- `ci.execution.completed` — полный анализ завершён (сводка)

### Task 1.4: Knowledge API Endpoints

**Endpoints:**
```python

  → {"patterns": [...], "rules": [...], "learnings": [...]}

POST /api/knowledge/learn
  Body: {"execution_id": "evt-abc123"}
  → Запускает LLM-ingest: raw → wiki (извлечение паттернов)
  → {"pattern": "...", "extracted_at": "..."}

GET /api/knowledge/search?q=keyword&domain=seo
  → Поиск по всем знаниям (raw + wiki + decisions)
  → {"results": [...]}
```

### Task 1.5: LLM Ingest — raw → wiki (Pattern Extraction)

**Файл создать:** `AIM/hermes/knowledge/ingest.py`

**Логика:**
1. Читает raw/executions/{id}.json
2. Отправляет в LLM (через OmniRoute/DeepSeek): "Извлеки паттерны из этого execution-результата"
3. Сохраняет извлечённые паттерны в wiki/patterns/
4. Обновляет index.md

**Prompt для LLM:**
```
Ты — Knowledge Extraction Agent. Проанализируй результат CI-анализа и извлеки:
1. Что сработало хорошо (successful patterns)
2. Что можно улучшить (improvement opportunities)
3. Неожиданные находки (surprising findings)
4. Конкретные цифры и метрики

Формат: Markdown, каждая секция с заголовком ##
```
