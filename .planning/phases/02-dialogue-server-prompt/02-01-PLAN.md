<decisions_implemented>
Заблокированные решения из 02-CONTEXT.md:
- LLM: сырой `openai` Python SDK (НЕ hermes-agent). `AsyncClient(base_url=OMNIROUTE_URL, api_key=OMNIROUTE_AUTH)`, model `deepseek-chat`, `stream=True`.
- SSE: точные имена событий из бэкапа main.py:554-561 — `text-delta` (поле `textDelta`), `finish` (поле `session_id`), `error`. Формат: `data: {json}\n\n`.
- SQLite: сырой `sqlite3` (НЕ SQLAlchemy), WAL mode, файл `/opt/data/sessions.db`. Синхронные вызовы через `asyncio.to_thread`.
- Схема: `messages (id INTEGER PK, session_id TEXT, role TEXT, content TEXT, created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP)`, индекс на `session_id`.
- Per-session: in-memory dict `session_id → asyncio.Lock`, предотвращает race condition на историю; разные session_id не блокируют друг друга (исправление бага DIALOG-05).
- Промпт: отдельный модуль `app/prompts/dialogue.py`, SYSTEM_PROMPT — адаптация раздела 5 спеки (без упоминания тулов, которые появятся в Phase 3).
- session_id: client-supplied (как в старом hermes). Если не передан — генерируется UUID.
- Старый сервис hermes НЕ трогаем. /health и /tools/find-competitors из Phase 1 сохраняются.
