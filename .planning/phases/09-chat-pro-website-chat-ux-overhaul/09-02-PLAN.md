# Plan 09-02: Wow-Commentary Generation

**Phase:** 9 (Chat Pro — Website Chat UX Overhaul)
**Effort:** M
**Risk:** Low

## Objective

Enable LLM to generate contextual business insights after each tool execution, delivered as chat messages with severity indicators. The LLM uses collected data to produce wow-comments like "Ого, главная страница не оптимизирована — теряете пациентов на первых секундах загрузки" or "У конкурента доктор с 500K подписчиков — серьёзное преимущество".

**Purpose:** Transform dry data collection into a live consulting experience where Hermes reacts to findings with business-focused commentary.

**Output:** LLM prompt engineering + new SSE event type + backend integration in tool handlers

Per D-07: LLM generates wow-comments after each successful tool call using collected data
Per D-08: New SSE event type `{"type": "wow-comment", "insight": "...", "severity": "info|warning|critical"}`
Per D-09: Business language (INT-03 from Phase 5) — not technical jargon
Per D-10: Severity mapping — info (✅ positive), warning (📍 growth point), critical (🔴 critical gap)
Per D-11: Wow-comments = separate message bubbles (not floating status)
Per D-12: Tone = marketing manager working with client (not robot/formal report)

    ```python
    def push_wow_comment(insight: str, severity: str = "info") -> None:
        """Push a wow-comment event (LLM-generated business insight).

        Args:
            insight: Business insight text (2-4 sentences)
            severity: "info" (positive), "warning" (growth point), "critical" (gap)

        Thread-safe, works from any tool handler.
        """
        logger.info("[wow-comment] [%s] %s", severity, insight[:100])

        # Validate severity
        if severity not in ("info", "warning", "critical"):
            logger.warning("Invalid severity '%s', defaulting to 'info'", severity)
            severity = "info"

        # SSE queue
        q = _tool_progress_queue
        if q is None:
            return
        event = {"type": "wow-comment", "insight": insight, "severity": severity}
        loop = _main_event_loop
        if loop is None:
            try:
                loop = asyncio.get_running_loop()
            except RuntimeError:
                return
        loop.call_soon_threadsafe(q.put_nowait, event)
    ```
