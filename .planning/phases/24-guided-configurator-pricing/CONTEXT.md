# Phase 24: Guided Configurator Pricing — CONTEXT

**Дата:** 2026-06-03
**Источник:** Brainstorming по ценообразованию (3 сессии)
**Спецификация:** `docs/superpowers/specs/2026-06-03-guided-configurator-design.md`

## Что было до

Phase 22 (Hermes First Communication Flow) реализовал 7-шаговый PRESALE flow:
1. Приветствие → 2. Prescan → 3. Картина → 4. Конкуренты → 5. CI-анализ → 6. Отчёт → 7. Контакты

Phase 23 (Ultra-Deep Prescan) строит 3-стадийный prescan пайплайн (в процессе).

**Проблема:** Блок 5 КП (Цена) использует 3-уровневую модель (Базовый/Оптимальный/Максимальный). Это отвергнуто — клиенты не хотят быть частью воронки, они хотят решение под себя.

## Что меняется

### 1. Ценообразование: 3 уровня → 4 категории (LEGO-конструктор)

| Категория | Механика |
|---|---|
| БАЗА (зелёный) | Заблокирована. Без этого нельзя. |
| РЕКОМЕНДОВАНО (золотой) | Предотмечена. Можно снять с предупреждением. |
| ОПЦИОНАЛЬНО (серый) | Не отмечена. Можно добавить. |
| СЛЕДУЮЩИЙ ЭТАП (синий) | Заблокирована. Milestone 2. С пояснением. |

Категории определяются автоматически на основе prescan + CI-анализа.

### 2. Presale-диалог: финальный шаг — выжимка в чате + ссылка на КП

Hermes НЕ пишет КП в чат. Вместо этого:
- Короткая выжимка: 3 пункта что делать + цена + результат
- Ссылка на полный HTML-КП
- Handoff на Михаила: «Для более детального обсуждения — поговорите с Михаилом»

### 3. Конфигуратор в блоке 10 КП

Форма с чекбоксами, категориями, пересчётом итога в реальном времени.
Поле контактов + кнопка «Получить расчёт и уточнить детали».

### 4. Интенсивность — наша экспертиза

Конфигуратор бинарный (берём/не берём). Интенсивность (2-3 статьи/нед) — наша рекомендация.

## Что требует изменений

### Файлы на изменение:

1. **QUALITY.md** — блок 5: «Нарративное обоснование» вместо «Цена 3 уровня»; блок 10: «Конфигуратор» вместо «Контакты/CTA»
2. **SOUL.md** — правило 23: заменить 3 уровня на 4 категории; добавить правило про выжимку в чате
3. **Hermes PRESALE prompt** (`agent_wrapper.py`) — шаг 6: выжимка + ссылка вместо КП в чате; шаг 7: handoff на Михаила
4. **HTML-КП генератор** — блок 5: нарратив ПОЧЕМУ; блок 10: форма-конструктор с JS
5. **ServiceCategorizer** (новый) — правила категоризации услуг на основе prescan

### Что НЕ делаем (MVP):
- Разные LEGO-модели под типы клиник → BACKLOG.md
- Слайдеры/количество для услуг
- Интерактивный конфигуратор в чате
