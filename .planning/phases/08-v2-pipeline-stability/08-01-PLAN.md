# Plan 08-01: V2 Pipeline — стабильность и покрытие

**Goal:** Сделать v2 пайплайн детерминированным: 3 последовательных запуска IPHK → каждый раз ≥5 конкурентов. Retry, overfetch, кэш singleton, дедуп логирование.

## must_haves

**truths:**
- 3 последовательных запуска IPHK → каждый раз ≥5 конкурентов в результате
- Perplexity retry срабатывает при пустом результате (видно в логах)
- BfoNalogClient — singleton, кэш переживает между запросами
- Повторный IPHK за <5с (кэш-хиты bo.nalog)
- Результат не содержит двух записей с одинаковым ИНН

```python
def _dedup_by_inn(self, competitors):
    # ... existing code ...
    duplicates = len(competitors) - len(seen_inns) - len(no_inn)
    if duplicates > 0:
        logger.info("dedup_by_inn: removed %d duplicates (same INN)", duplicates)
        # Log which brands were merged
        for inn, comp in seen_inns.items():
            same_inn = [c for c in competitors if c.profile.inn == inn]
            if len(same_inn) > 1:
                names = [c.profile.brand_name for c in same_inn]
                logger.info("dedup_merged: inn=%s brands=%s", inn, names)
    return list(seen_inns.values()) + no_inn
```
