## What This Is

**Гермес v2** — интерактивная переработка AI-ассистента маркетингового агентства AIM (`iamaim.ru`). Замена жёсткого 13-фазного автономного pipeline (17 минут → один большой отчёт) на диалоговую модель: **база → умные кнопки → инструменты по запросу**.

Новый контейнер `aim-hermes-v2` с `glm-5.2` через Z.AI-шлюз + нативный tool-calling. Старый `aim-hermes` выключаем, оставляем для отката.

## Core Value

**Одна вещь, которая должна работать:** клиент присылает сайт клиники → за **≤2 минуты** получает базовую разведку (рынок + конкуренты с выручкой) с кнопками → по запросу запускает нужные инструменты → собирает отчёт. Вместо 17-минутного «пожарного шланга».

## Context

### Текущая система (что меняем)
- Контейнер `aim-hermes`: чат + 13-фазный pipeline (`engine.py` 2059 строк) + Telegram-бот
- Чат-модель `deepseek-chat` через Z.AI-шлюз, **нативный** tool-calling (через `hermes-agent==0.14.0`)
- Чат Theme-версии (`AIM/theme/chat/src/`) встроен в WordPress, виден клиентам на главной
- Тулзы: ~10 ключевых; **3 тонких прокси** к `aim-app:8000` + **7 толстых** (Perplexity/Apify/Firecrawl/Playwright/WP-DB напрямую)

### Что остаётся без изменений
- Контейнер `aim-app:8000` — вся тяжёлая логика конкурентов/SEO
- Next.js-чат `/chat-test` — тестовый, не наш
- Telegram-бот — остаётся на старом `aim-hermes`, миграция позже
- Клиентские env-ключи (Perplexity, Apify, Firecrawl, Z.AI)

### Маршрут деплоя
Локально (`~/Desktop/Dev/meAI_1/AIM/hermes-v2/`) → `rsync` на сервер → `docker compose build hermes-v2` → `up -d hermes-v2`. nginx переключаем последним. Старый `aim-hermes` — откат в любой момент.
