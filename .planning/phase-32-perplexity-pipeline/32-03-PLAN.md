| Tool registration | Module-level registry.register() calls execute at import time. Only trusted modules should be imported. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-32-13 | Denial of Service | Tool registration | accept | Module import at startup — if a tool module crashes on import, FastAPI fails to start (fail-fast). No runtime DoS risk. |
