<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Local → Polish server (ssh + docker) | Deployment commands cross network boundary — SSH key required |
| .env.production | Contains secrets (PERPLEXITY_API_KEY, DB passwords) — must not be committed to git |
| Docker image transfer | `docker save | ssh aim "docker load"` transfers images over SSH — images contain no secrets (env vars injected at runtime) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-32-15 | Information Disclosure | .env.production | mitigate | PERPLEXITY_API_KEY added to .env.production which is gitignored; never commit actual key values |
| T-32-16 | Denial of Service | Docker build | accept | Build happens locally, deployment is a controlled operation — no external DoS vector |
| T-32-17 | Elevation of Privilege | ssh aim commands | accept | SSH key authentication required; commands run as the same user that owns the deployment |
</threat_model>
