Ключевые инновации

🎓

Hierarchical Learning

Teacher Agent распределяет знания магистрам, обрабатывает feedback, улучшает стратегию обучения.

🛡️

Gatekeeper

7 проверок качества: size, language, structure, source reliability, fact-checking, relevance, duplicates.

📚

LLM Wiki Pattern

Паттерн Andrej Karpathy: raw sources → wiki (8 категорий) → decisions. 3 операции: Ingest, Query, Lint.

🔍

Hybrid Search

3-layer поиск: Local Cache (1-5ms) → Teacher/Qdrant (50-200ms) → Researcher (2-10s).

📊

Experience Learning

Система обучения на опыте: ExperienceTracker, QualityUpdater, DeprecationManager, LearningAnalytics.

🎯

Competitive Intelligence

20+ субагентов для глубокого анализа конкурентов: технологии, контент, финансы, репутация, стратегии.
