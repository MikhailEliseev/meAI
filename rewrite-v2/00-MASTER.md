## 🎯 TL;DR (одной строкой каждый)

**Суть:** AIM — AI-аналитик для медицинских клиник. URL клиники → 5-8 минут → красивый отчёт-разбор рынка, конкурентов, слабых мест. Без продаж, без слова "пресейл".

**Наследие:** 16 Docker-контейнеров, 67 tools, 152 файла мёртвого кода, PostgreSQL сломан, 3 разных генератора HTML отчётов, дизайн-система не применена полностью. Работает: чат, DeepSeek, регистрация инструментов, key rotation.

**Цель:** Минималистичная архитектура: 4 контейнера (Hermes + WordPress + MariaDB + Nginx), 1 LLM-оркестратор, 1 пайплайн (13 фаз), 1 генератор отчётов (полная дизайн-система), 1 способ публикации.

**Дизайн:** Двойная (light + dark), glassmorphism, Art Deco gold (#c9a96e) на dark, монументально-чёрный на light, Playfair Display + Jost, без шапки сайта на scout-страницах, переключатель темы в углу.

**Критерий успеха:** Михаил вбивает URL тестовой клиники → через 8 минут открывает `https://iamaim.ru/{8-char-slug}` → видит красивый отчёт со всеми секциями, переключателем темы, CTA. Без экранирования, без обрезки, без "потерянной фазы".

## 🚨 Принципы работы (ОБЯЗАТЕЛЬНЫ для команды)

1. **Trust Level: ZERO.** Любое утверждение разработчика = факт из измерения. Не "я думаю", не "вероятно". Бэкап + rollback + smoke tests перед каждым изменением.
2. **Без слова "пресейл".** User-facing тексты не содержат: пресейл, КП, коммерческое предложение, купить, заказать. LLM тон = эксперт-аналитик, НЕ продавец.
3. **Только коммерческая медицина.** Никаких государственных клиник (ГАУЗ, ГБУЗ, МУЗ). Только ООО, АО, ЗАО, ИП.
4. **Минимум кода.** Если можно не писать — не писать. Если можно удалить — удалить. Никакого "универсального" кода для будущих фич.
5. **Документация прежде кода.** Каждый компонент начинается с того что он ДОЛЖЕН делать. Не "посмотрим как выйдет".
6. **Реальные данные.** Никаких mock данных в production коде. Только в `tests/`.

## ⚠️ Что НЕ делать никогда (для команды)

1. ❌ **Не добавлять новые tools** пока существующие не работают стабильно
2. ❌ **Не возвращать HeadroomGuard, мультиагентность, backend CRM** — это distractions
3. ❌ **Не использовать слово "пресейл"** в user-facing текстах
4. ❌ **Не деплоить без auto-commit-deploy.sh** и без smoke test
5. ❌ **Не доверять SESSION.md / .current-task** — они врут (см. `refactor-analysis/07-DIVERGENCE-FROM-DOCS.md`)
6. ❌ **Не использовать mb_strlen там где нужен strlen** (и наоборот) — было много багов
7. ❌ **Не вставлять HTML в wp_posts без page template** — WordPress применит wpautop и испортит
8. ❌ **Не использовать шрифт Inter** в отчётах — canonical = Jost + Playfair Display
9. ❌ **Не делать заголовок "AIM Scout"** — название "AIM Research" или просто название клиники
10. ❌ **Не использовать чёрный текст на чёрном фоне** в dark mode (только Art Deco gold на dark)
