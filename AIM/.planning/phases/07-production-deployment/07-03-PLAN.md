### Task 1: Configure Structured Logging (15 min)

**Action:** Set up production-grade structured logging with structlog.

**Configuration File:** `AIM/src/aim/config/logging.py`

```python
import structlog
import logging
from pathlib import Path

def configure_logging(environment: str = "production"):
    """Configure structured logging for production"""
    
    # Create logs directory
    log_dir = Path("logs")
    log_dir.mkdir(exist_ok=True)
    
    # Configure standard library logging
    logging.basicConfig(
        format="%(message)s",
        level=logging.INFO if environment == "production" else logging.DEBUG,
        handlers=[
            logging.FileHandler(log_dir / "app.log"),
            logging.StreamHandler(),
        ]
    )
    
    # Configure structlog
    structlog.configure(
        processors=[
            structlog.contextvars.merge_contextvars,
            structlog.processors.add_log_level,
            structlog.processors.TimeStamper(fmt="iso"),
            structlog.processors.StackInfoRenderer(),
            structlog.processors.format_exc_info,
            structlog.processors.JSONRenderer() if environment == "production" 
            else structlog.dev.ConsoleRenderer(),
        ],
        wrapper_class=structlog.make_filtering_bound_logger(logging.INFO),
        context_class=dict,
        logger_factory=structlog.PrintLoggerFactory(),
        cache_logger_on_first_use=True,
    )
    
    return structlog.get_logger()
```

**Log Levels:**
- **ERROR:** Critical failures requiring immediate attention
- **WARNING:** Issues that should be investigated
- **INFO:** Important business events (API calls, task completions)
- **DEBUG:** Detailed diagnostic information (development only)

**Steps:**
1. Create `AIM/src/aim/config/logging.py`
2. Configure structlog with JSON output for production
3. Add log rotation (daily, keep 30 days)
4. Test logging in all components
5. Update `main.py` to initialize logging

### Task 2: Set Up Prometheus Metrics (15 min)

**Action:** Add Prometheus metrics collection to FastAPI application.

**Dependencies:**
```bash
pip install prometheus-client prometheus-fastapi-instrumentator
```

**Instrumentation:** `AIM/src/aim/main.py`

```python
from fastapi import FastAPI
from prometheus_client import Counter, Histogram, Gauge
from prometheus_fastapi_instrumentator import Instrumentator

app = FastAPI(title="AIM Agency API")

# Custom metrics
api_requests_total = Counter(
    "aim_api_requests_total",
    "Total API requests",
    ["method", "endpoint", "status"]
)

api_request_duration = Histogram(
    "aim_api_request_duration_seconds",
    "API request duration",
    ["method", "endpoint"]
)

active_tasks = Gauge(
    "aim_active_tasks",
    "Number of active tasks",
    ["magister", "subagent"]
)

api_errors_total = Counter(
    "aim_api_errors_total",
    "Total API errors",
    ["endpoint", "error_type"]
)

# Instrument FastAPI
Instrumentator().instrument(app).expose(app, endpoint="/metrics")

@app.middleware("http")
async def track_metrics(request, call_next):
    """Track custom metrics for each request"""
    method = request.method
    endpoint = request.url.path
    
    with api_request_duration.labels(method=method, endpoint=endpoint).time():
        response = await call_next(request)
    
    api_requests_total.labels(
        method=method,
        endpoint=endpoint,
        status=response.status_code
    ).inc()
    
    if response.status_code >= 400:
        api_errors_total.labels(
            endpoint=endpoint,
            error_type=f"{response.status_code}"
        ).inc()
    
    return response
```

**Metrics to Track:**
- Request rate (requests/second)
- Request duration (p50, p95, p99)
- Error rate (errors/second)
- Active tasks by magister/subagent
- API call costs (SEMrush, Ahrefs)
- Database query duration
- Cache hit rate

**Steps:**
1. Install prometheus-client and instrumentator
2. Add metrics to `main.py`
3. Expose `/metrics` endpoint
4. Add custom business metrics
5. Test metrics endpoint

**Output:** Prometheus metrics exposed at `/metrics`

**Validation:**
```bash

# aim_api_requests_total{method="GET",endpoint="/health",status="200"} 42
# aim_api_request_duration_seconds_bucket{method="GET",endpoint="/api/keywords",le="0.5"} 100
```

```yaml
  prometheus:
    image: prom/prometheus:latest
    container_name: aim-prometheus
    restart: unless-stopped
    ports:
      - "9090:9090"
    volumes:
      - ./prometheus.yml:/etc/prometheus/prometheus.yml:ro

      - '--config.file=/etc/prometheus/prometheus.yml'
      - '--storage.tsdb.path=/prometheus'
      - '--storage.tsdb.retention.time=30d'
    networks:
      - aim-network

  prometheus-data:
```

**Prometheus Configuration:** `prometheus.yml`

```yaml
global:
  scrape_interval: 15s
  evaluation_interval: 15s

      - targets: ['app:8000']
    metrics_path: '/metrics'
    
  - job_name: 'prometheus'
    static_configs:
      - targets: ['localhost:9090']
```

### Task 5: Configure Alerting Rules (10 min)

**Action:** Set up alerting for critical issues.

**Alert Rules:** `prometheus-alerts.yml`

```yaml
groups:
  - name: aim_alerts
    interval: 30s
    rules:
      # High error rate
      - alert: HighErrorRate
        expr: rate(aim_api_errors_total[5m]) > 0.1
        for: 5m
        labels:
          severity: critical
        annotations:
          summary: "High error rate detected"
          description: "Error rate is {{ $value }} errors/second"
      
      # Slow API responses
      - alert: SlowAPIResponses
        expr: histogram_quantile(0.95, rate(aim_api_request_duration_seconds_bucket[5m])) > 2
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "API responses are slow"
          description: "P95 latency is {{ $value }} seconds"
      
      # Service down
      - alert: ServiceDown
        expr: up{job="aim-api"} == 0
        for: 1m
        labels:
          severity: critical
        annotations:
          summary: "AIM API is down"
          description: "Service has been down for more than 1 minute"
      
      # High API costs
      - alert: HighAPICosts
        expr: rate(aim_api_cost_usd_total[1h]) > 5
        for: 10m
        labels:
          severity: warning
        annotations:
          summary: "High API costs detected"
          description: "API costs are ${{ $value }}/hour"
      
      # Database connection issues
      - alert: DatabaseConnectionFailed
        expr: aim_database_connection_errors_total > 0
        for: 2m
        labels:
          severity: critical
        annotations:
          summary: "Database connection failed"
          description: "Cannot connect to database"
```

**Update prometheus.yml:**
```yaml
rule_files:
  - 'prometheus-alerts.yml'

alerting:
  alertmanagers:
    - static_configs:
        - targets: ['localhost:9093']  # Alertmanager (optional)
```

**Steps:**
1. Create `prometheus-alerts.yml`
2. Update `prometheus.yml` with rule_files
3. Restart Prometheus: `docker-compose restart prometheus`
4. Check alerts in Prometheus UI (Alerts tab)
5. Test alerts by triggering conditions
