# Plan 07-01: Environment Configuration

## Objective

Set up production environment with all required configurations, API keys, database, and secrets management.

## Tasks

### Task 1: Create Production Environment File (15 min)

**Action:** Create `.env.production` with production-ready settings.

**Steps:**
1. Copy `.env.example` to `.env.production`
2. Set `ENVIRONMENT=production`
3. Configure logging level (`LOG_LEVEL=INFO`)
4. Set database URL (production SQLite or PostgreSQL)
5. Configure cache settings (Redis for production)
6. Set rate limiting parameters
7. Configure CORS origins (iamaim.ru domain)

**Output:** `.env.production` file

**Validation:**
```bash
# Check file exists and has correct permissions
ls -la .env.production
chmod 600 .env.production  # Secure permissions
```

---

### Task 2: Configure API Keys (20 min)

**Action:** Add all API keys to production environment.

**API Keys Required:**
1. **SEMrush API** (`SEMRUSH_API_KEY`)
   - Get from: https://www.semrush.com/api-analytics/
   - Cost: $0.01 per request
   - Rate limit: 10 req/s

2. **Ahrefs API** (`AHREFS_API_KEY`)
   - Get from: https://ahrefs.com/api
   - Cost: $0.02 per request
   - Rate limit: 5 req/s

3. **Google Analytics 4** (`GA4_PROPERTY_ID`, `GA4_SERVICE_ACCOUNT_JSON`)
   - Get from: https://console.cloud.google.com/
   - Service account with Analytics API access
   - Free tier available

4. **Yandex Metrica** (`YANDEX_METRICA_TOKEN`)
   - Get from: https://oauth.yandex.ru/
   - OAuth 2.0 token
   - Free tier available

5. **PageSpeed Insights** (`PAGESPEED_API_KEY`)
   - Get from: https://console.cloud.google.com/
   - 25,000 requests/day free
   - Rate limit: 1 req/s

6. **Yandex Direct** (`YANDEX_DIRECT_TOKEN`)
   - Get from: https://oauth.yandex.ru/
   - OAuth 2.0 token
   - Free tier available

**Steps:**
1. Request API keys from user (use AskUserQuestion)
2. Add keys to `.env.production`
3. Validate each key with test request
4. Document key sources and limits

**Output:** All API keys configured and validated

**Validation:**
```bash
# Run validation script
python scripts/validate_api_keys.py --env production
```

---

### Task 3: Set Up Production Database (15 min)

**Action:** Initialize production database with schema.

**Options:**
- **SQLite** (simple, file-based, good for MVP)
- **PostgreSQL** (scalable, production-grade)

**Steps for SQLite:**
1. Create `data/production/` directory
2. Set `DATABASE_URL=sqlite+aiosqlite:///./data/production/aim.db`
3. Run migrations: `alembic upgrade head`
4. Verify tables created

**Steps for PostgreSQL:**
1. Install PostgreSQL
2. Create database: `createdb aim_production`
3. Set `DATABASE_URL=postgresql+asyncpg://user:pass@localhost/aim_production`
4. Run migrations: `alembic upgrade head`
5. Verify tables created

**Output:** Production database initialized

**Validation:**
```bash
# Check database connection
python -c "from AIM.src.aim.config.settings import get_settings; import asyncio; asyncio.run(get_settings().test_db_connection())"
```

### Task 4: Configure Secrets Management (10 min)

**Action:** Set up secure secrets management.

**Options:**
1. **Environment Variables** (simple, good for MVP)
2. **HashiCorp Vault** (enterprise-grade)
3. **AWS Secrets Manager** (cloud-native)

**For MVP (Environment Variables):**
1. Store `.env.production` outside git (add to `.gitignore`)
2. Set file permissions: `chmod 600 .env.production`
3. Document secret rotation procedures
4. Create backup of secrets (encrypted)

**Steps:**
1. Verify `.env.production` in `.gitignore`
2. Set secure file permissions
3. Create encrypted backup: `gpg -c .env.production`
4. Document secret locations

**Output:** Secrets secured and documented

**Validation:**
```bash
# Check .env.production not in git
git check-ignore .env.production  # Should output: .env.production

# Check file permissions
ls -la .env.production  # Should show: -rw------- (600)
```

### Task 5: Run Environment Validation Script (5 min)

**Action:** Validate all environment settings.

**Script:** `scripts/validate_environment.py`

**Checks:**
- All required environment variables present
- API keys valid (test requests)
- Database connection successful
- Cache connection successful (if Redis)
- File permissions correct
- No secrets in git

**Steps:**
1. Run validation script
2. Fix any issues found
3. Re-run until all checks pass
4. Save validation report

**Output:** Validation report (all checks passing)

**Validation:**
```bash
python scripts/validate_environment.py --env production --report validation_report.txt
echo $?  # Should return 0 (success)
```
