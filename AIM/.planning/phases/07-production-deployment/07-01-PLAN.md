# Plan 07-01: Environment Configuration

## Objective

Set up production environment with all required configuration, API keys, database, and secrets management.

## Tasks

### Task 1: Create Production Environment File (15 min)

**Action:** Create `.env.production` with all required environment variables.

**Template:**
```bash
# Application
ENVIRONMENT=production
DEBUG=false
LOG_LEVEL=INFO
SECRET_KEY=<generate-secure-key>

# Database
DATABASE_URL=sqlite+aiosqlite:///./data/production/aim.db
# Or PostgreSQL: postgresql+asyncpg://user:pass@localhost/aim_prod

# API Keys (to be filled in Task 2)
SEMRUSH_API_KEY=
AHREFS_API_KEY=
GOOGLE_ANALYTICS_KEY=
YANDEX_METRICA_TOKEN=
YANDEX_DIRECT_TOKEN=
OPENAI_API_KEY=

# API Limits
MAX_COST_USD=5.0
MIN_KEYWORDS=100
MIN_VOLUME=10

# Caching
REDIS_URL=redis://redis:6379/0
CACHE_TTL=3600

# Rate Limiting
RATE_LIMIT_CAPACITY=10
RATE_LIMIT_REFILL=1.0

# Monitoring
PROMETHEUS_PORT=9090
GRAFANA_PORT=3000

# Server
HOST=0.0.0.0
PORT=8000
WORKERS=4

# Domain
DOMAIN=iamaim.ru
SSL_ENABLED=true
```

**Steps:**
1. Copy `.env.example` to `.env.production`
2. Generate secure SECRET_KEY: `openssl rand -hex 32`
3. Set ENVIRONMENT=production, DEBUG=false
4. Configure database URL (SQLite or PostgreSQL)
5. Leave API keys empty (filled in Task 2)
6. Review all settings

**Output:** `.env.production` file created

**Validation:**
```bash
# Check file exists
test -f .env.production && echo "✓ File exists"

# Check required variables present
grep -q "ENVIRONMENT=production" .env.production && echo "✓ Environment set"
grep -q "SECRET_KEY=" .env.production && echo "✓ Secret key present"
grep -q "DATABASE_URL=" .env.production && echo "✓ Database URL set"
```

### Task 2: Configure API Keys (20 min)

**Action:** Obtain and configure all 6 required API keys.

1. **SEMrush API Key**
   - Sign up: https://www.semrush.com/api-analytics/

   - Permissions: metrika:read
   - Add to `.env.production`: `YANDEX_METRICA_TOKEN=your_token_here`

5. **Yandex Direct Token**
   - Get token: https://oauth.yandex.ru/
   - Permissions: direct:api
   - Add to `.env.production`: `YANDEX_DIRECT_TOKEN=your_token_here`

6. **OpenAI API Key**
   - Get key: https://platform.openai.com/api-keys
   - Add to `.env.production`: `OPENAI_API_KEY=sk-...`

```bash
# Create database and user

CREATE DATABASE aim_prod;
CREATE USER aim_user WITH PASSWORD 'secure_password';
GRANT ALL PRIVILEGES ON DATABASE aim_prod TO aim_user;
EOF

# Update .env.production
# DATABASE_URL=postgresql+asyncpg://aim_user:secure_password@localhost/aim_prod

# Run migrations
alembic upgrade head
```

**Steps:**
1. Choose database option (SQLite or PostgreSQL)

### Task 5: Run Environment Validation (5 min)

**Action:** Execute validation script to verify all configuration correct.

**Validation Script:** `scripts/validate_environment.py`

```python
#!/usr/bin/env python3
"""
Environment validation script for AIM production deployment.
Checks all required configuration, API keys, database, and dependencies.
"""
import os
import sys
import asyncio
from pathlib import Path
from typing import List, Tuple

# Color codes for output
GREEN = "\033[92m"
RED = "\033[91m"
YELLOW = "\033[93m"
RESET = "\033[0m"

def check_env_file() -> bool:
    """Check .env.production exists and is readable"""
    env_file = Path(".env.production")
    if not env_file.exists():
        print(f"{RED}✗{RESET} .env.production not found")
        return False
    if not os.access(env_file, os.R_OK):
        print(f"{RED}✗{RESET} .env.production not readable")
        return False
    print(f"{GREEN}✓{RESET} .env.production exists and readable")
    return True

def check_required_vars() -> bool:
    """Check all required environment variables present"""
    required_vars = [
        "ENVIRONMENT",
        "SECRET_KEY",
        "DATABASE_URL",
        "SEMRUSH_API_KEY",
        "OPENAI_API_KEY",
    ]
    
    missing = []
    for var in required_vars:
        if not os.getenv(var):
            missing.append(var)
    
    if missing:
        print(f"{RED}✗{RESET} Missing variables: {', '.join(missing)}")
        return False
    
    print(f"{GREEN}✓{RESET} All required variables present")
    return True

def check_environment_mode() -> bool:
    """Check ENVIRONMENT=production and DEBUG=false"""
    env = os.getenv("ENVIRONMENT")
    debug = os.getenv("DEBUG", "false").lower()
    
    if env != "production":
        print(f"{RED}✗{RESET} ENVIRONMENT must be 'production', got '{env}'")
        return False
    
    if debug != "false":
        print(f"{YELLOW}⚠{RESET} DEBUG should be 'false' in production, got '{debug}'")
    
    print(f"{GREEN}✓{RESET} Environment mode correct")
    return True

async def check_database() -> bool:
    """Check database connection"""
    try:
        from AIM.src.aim.storage.database import get_db_session
        async with get_db_session() as session:
            await session.execute("SELECT 1")
        print(f"{GREEN}✓{RESET} Database connection successful")
        return True
    except Exception as e:
        print(f"{RED}✗{RESET} Database connection failed: {e}")
        return False

async def check_api_keys() -> bool:
    """Test API keys with simple requests"""
    results = []
    
    # SEMrush
    try:
        import httpx
        api_key = os.getenv("SEMRUSH_API_KEY")
        async with httpx.AsyncClient() as client:
            response = await client.get(
                "https://api.semrush.com/",
                params={"key": api_key, "type": "domain_rank", "domain": "example.com"}
            )
            if response.status_code == 200:
                print(f"{GREEN}✓{RESET} SEMrush API key valid")
                results.append(True)
            else:
                print(f"{RED}✗{RESET} SEMrush API key invalid")
                results.append(False)
    except Exception as e:
        print(f"{RED}✗{RESET} SEMrush API test failed: {e}")
        results.append(False)
    
    # OpenAI
    try:
        import openai
        openai.api_key = os.getenv("OPENAI_API_KEY")
        # Simple test: list models
        models = await openai.Model.alist()
        print(f"{GREEN}✓{RESET} OpenAI API key valid")
        results.append(True)
    except Exception as e:
        print(f"{RED}✗{RESET} OpenAI API test failed: {e}")
        results.append(False)
    
    return all(results)

def check_dependencies() -> bool:
    """Check all required Python packages installed"""
    required_packages = [
        "fastapi",
        "uvicorn",
        "sqlalchemy",
        "aiosqlite",
        "httpx",
        "pydantic",
        "structlog",
        "prometheus_client",
    ]
    
    missing = []
    for package in required_packages:
        try:
            __import__(package)
        except ImportError:
            missing.append(package)
    
    if missing:
        print(f"{RED}✗{RESET} Missing packages: {', '.join(missing)}")
        print(f"  Install with: pip install {' '.join(missing)}")
        return False
    
    print(f"{GREEN}✓{RESET} All dependencies installed")
    return True

async def main():
    """Run all validation checks"""
    print("\n" + "="*60)
    print("AIM Production Environment Validation")
    print("="*60 + "\n")
    
    checks = [
        ("Environment file", check_env_file()),
        ("Required variables", check_required_vars()),
        ("Environment mode", check_environment_mode()),
        ("Dependencies", check_dependencies()),
        ("Database connection", await check_database()),
        ("API keys", await check_api_keys()),
    ]
    
    passed = sum(1 for _, result in checks if result)
    total = len(checks)
    
    print("\n" + "="*60)
    print(f"Results: {passed}/{total} checks passed")
    print("="*60 + "\n")
    
    if passed == total:
        print(f"{GREEN}✓ Environment validation PASSED{RESET}")
        print("Ready for deployment!")
        return 0
    else:
        print(f"{RED}✗ Environment validation FAILED{RESET}")
        print("Fix issues above before deploying.")
        return 1

if __name__ == "__main__":
    sys.exit(asyncio.run(main()))
```

**Steps:**
1. Create `scripts/validate_environment.py`
2. Make executable: `chmod +x scripts/validate_environment.py`
3. Load environment: `set -a; source .env.production; set +a`
4. Run validation: `python scripts/validate_environment.py`
5. Fix any issues reported
6. Re-run until all checks pass

**Output:** Environment validation passes all checks
