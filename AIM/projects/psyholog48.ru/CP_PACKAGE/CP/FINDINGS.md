## 14. ПЛАТФОРМА: Почему Tilda — это проблема

**Источник:** Deep Research (2026-06-03)

### Технические ограничения Tilda:
1. **AJAX-загрузка контента** — Яндекс не индексирует JS-контент так же хорошо, как Google. 80% поискового трафика РФ — Яндекс.
2. **Нет Schema.org** для медицинских сайтов — MedicalBusiness, Physician, Article (E-E-A-T)
3. **URL с #rec12345678** — невидимы для поисковиков
4. **Скорость:** мобильный PageSpeed 30-55/100, LCP 4-8 секунд
5. **Блог примитивный** — нет категорий, тегов, авторов, RSS
6. **Zero Block текст** — хранится в data-атрибутах, поисковики назначают пониженный вес
7. **Vendor lock-in** — нельзя экспортировать сайт, при смене платформы всё с нуля
8. **Потолок масштабирования** — при 100+ страниц админка тормозит

### Yandex-специфичные проблемы:
- Стандартный robots.txt блокирует критический контент от Яндекса
- JS-рендеринг Яндекса значительно хуже Google — страницы могут быть пустыми для поисковика
- Turbo Pages отключены в 2024
- Yandex.Neuro (AI-поиск) не может парсить Tilda-сайты

### Статистика миграций:
- Сайты, ушедшие с Tilda на WordPress: **+30-150% органического трафика за 3-6 месяцев**
- Индексация новых страниц: **в 2-3 раза быстрее**
- Временная просадка на 2-4 недели при миграции, затем устойчивый рост

### Рекомендация:
**WordPress + Elementor** — лучшая альтернатива для психологического центра:
- Полный SEO-контроль (Yoast/RankMath)
- Медицинские Schema.org плагины
- Правильный блог с E-E-AТ сигналами
- 152-ФЗ compliance
- Нет vendor lock-in
- Русскоязычное сообщество и поддержка
- Серверный рендеринг — мгновенная индексация Яндексом

## 15. КОНТЕНТ-СТРАТЕГИЯ: лучшие практики

**Источник:** Deep Research (2026-06-03)

### Частота публикаций
- **2-3 статьи в неделю** — оптимально для медицинского сайта
- Это ~104-156 статей в год
- Каждая статья = новая точка входа для поискового трафика
- Регулярность важнее объёма: лучше 2 стабильные статьи в неделю, чем 5 раз в месяц

### Длина статей
- Минимум 1,500 слов для конкурентных тем
- Оптимально 2,000-3,000 слов для психологических статей
- Длинные статьи ранжируются в среднем на 77% лучше коротких

### E-E-A-T сигналы (критично для медицинского контента)
- Авторство: каждую статью пишет конкретный психолог с указанием регалий
- Биография автора со структурированными данными (Person schema)
- Ссылки на научные источники
- Дата публикации и дата последнего обновления
- Политика редакционных стандартов

### AI/GEO оптимизация
- FAQ Schema на каждой статье (попадание в "People Also Ask")
- llms.txt файл для AI-сканеров
- Чёткая структура: H1 → H2 → H3 с ключевыми словами
- Первые 50 слов содержат прямой ответ на запрос
- Маркированные списки (лучше читаются и людьми, и AI)
