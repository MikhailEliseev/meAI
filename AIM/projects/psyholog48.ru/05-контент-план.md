## Форматы контента — спецификации

### Статья для блога (стандарт)
- **Объём:** 1 500 - 3 000 слов
- **Структура:** проблема → почему это важно → что говорит наука → практические шаги → CTA
- **SEO:** H1 с ключевым словом, H2/H3 по семантическому ядру, meta-description 150 знаков
- **Лид-магнит:** чек-лист, памятка или бесплатная диагностика
- **Частота:** 3 статьи в неделю

### Видео для YouTube / VK Видео
- **Длительность:** 8-20 минут
- **Структура:** крюк (5 сек) → проблема → разбор → решение → CTA
- **Обязательно:** субтитры, таймкоды, ссылка на сайт в описании
- **Частота:** 2 видео в неделю

### Пост для VK / Telegram
- **Длительность:** 500-1500 знаков
- **Структура:** личная история / вопрос → разбор → вывод → приглашение в комментарии
- **Визуал:** фото психолога или карточка с цитатой
- **Частота:** 5 постов в неделю

### Сторис для Instagram / VK Клипы
- **Длительность:** 15-60 секунд
- **Формат:** «Вопрос-ответ», «Миф-разрушение», «Совет дня», «Закулисье»
- **Частота:** 3-5 сторис в день
