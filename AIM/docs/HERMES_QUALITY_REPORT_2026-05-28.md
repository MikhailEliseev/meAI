**Дата:** 2026-05-28

**Диалогов:** 8 (по 2 per scenario)
**Суммарное время:** 285.8s (~4.8 min)

## 1. Общая оценка: 6.5/10

Гермес живой, адаптирует тон под размер бизнеса, не падает при ошибках инструментов. Но **не выполняет главную задачу** — не запускает CI-анализ конкурентов когда они названы, дублирует SEO-аудит на втором ходу, а в премиум-сценарии просто сдаётся.

---

## 2. Проблемы (по severity)

### CRITICAL: `find_competitors` не работает ни разу
- **Причина:** отсутствует `/app/AIM/data/apify_keys.json`
- **Частота:** 8/8 диалогов
- **Влияние:** Гермес вынужден просить названия конкурентов вручную — ломает первый ход диалога
- **Фикс:** Добавить Apify ключи на сервер

### HIGH: Дублирование `run_seo_audit` на втором ходу
- **Сценарии:** medium (T2), premium (T2)
- **Поведение:** Гермес повторно запускает SEO-аудит того же сайта, хотя уже делал это в T1
- **Время:** +30-38s бесполезной работы
- **Фикс:** Добавить в agent_wrapper.py проверку — если SEO-аудит уже был для этого URL в рамках сессии, использовать кешированный результат

### HIGH: CI-анализ (`run_ci_analysis`) не вызывается НИКОГДА
- **Ожидание:** Когда пользователь называет конкурентов (T2), Гермес должен запустить `run_ci_analysis` с их сайтами
- **Реальность:** Гермес либо перезапускает SEO-аудит, либо сдаётся
- **Пример:** large T2 — "Запускаю?" — но не запускает
- **Фикс:** Проверить, зарегистрирован ли `run_ci_analysis` в тулсете и доступен ли он в presale-режиме

### MEDIUM: Одинаковый quality_score = 55/100 для всех
- **Сайты:** arclinic.ru, familydoctor.ru, smclinic.ru, emcmos.ru
- **Результат:** у всех 55/100
- **Вероятная причина:** SEO-аудит берёт только базовые метрики (response time, mobile-friendly), не делает глубокий анализ
- **Фикс:** Проверить фазы CI-пайплайна — возможно часть фаз падает молча

### MEDIUM: "Конкурентная среда — низкая" для всех
- **Неправдоподобно:** Для сети из 30+ центров в Москве (СМ-Клиника) конкуренция не может быть низкой
- **Фикс:** Проверить фазу 7 (ci-strategist) — как считается competitive_intensity

### MEDIUM: Премиум T2 — полная капитуляция
- **EMC T2:** "Техника подводит... передам Михаилу"
- **Проблема:** Гермес не пытается дать хоть какую-то ценность — даже SEO-результаты T1 не резюмирует
- **Фикс:** Добавить fallback-правило — если инструменты падают, собрать всё что уже есть и дать резюме

### LOW: `step-start`/`step-end` события не приходят
- **tool_steps_count = 0** во всех 8 диалогах
- **tool_progress** работает (6-9 событий)
- **Фикс:** Проверить, шлёт ли agent_wrapper события step-start/step-end через push_tool_progress
