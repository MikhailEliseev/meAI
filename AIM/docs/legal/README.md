## 🚀 Интеграция на сайт

### Шаг 1: Создать страницы в Next.js

```bash
# Создать страницы в frontend
cd AIM/frontend

mkdir -p app/privacy-policy
mkdir -p app/terms-of-service
mkdir -p app/confidentiality
mkdir -p app/requisites
```

### Шаг 2: Конвертировать Markdown в React компоненты

Используйте библиотеку `react-markdown` или конвертируйте вручную в JSX.

```javascript
// app/privacy-policy/page.tsx
import fs from 'fs';
import path from 'path';
import ReactMarkdown from 'react-markdown';

export default function PrivacyPolicy() {
  const markdown = fs.readFileSync(
    path.join(process.cwd(), '../docs/legal/privacy-policy.md'),
    'utf8'
  );
  
  return (
    <div className="legal-document">
      <ReactMarkdown>{markdown}</ReactMarkdown>
    </div>
  );
}
```

## ⚠️ Требуется дополнить

Перед публикацией документов на сайте необходимо получить и добавить следующие данные:

### 1. ОГРНИП (основной государственный регистрационный номер)
**Где взять:**
- Свидетельство о регистрации ИП
- Выписка из ЕГРИП (nalog.ru)
- Личный кабинет ФНС

### 2. Дата регистрации ИП
**Где взять:**
- Свидетельство о регистрации ИП
- Выписка из ЕГРИП

### 3. Полный почтовый адрес
**Формат:** Индекс, регион, город, улица, дом, корпус, офис

**Где взять:**
- Документы регистрации ИП
- Адрес из ЕГРИП

### 4. Банковские реквизиты
Необходимо:
- Название банка
- Расчётный счет (р/с) — 20 цифр
- Корреспондентский счет (к/с) — 20 цифр
- БИК банка — 9 цифр

**Где взять:**
- Договор банковского обслуживания
- Личный кабинет банка
- Реквизиты в мобильном приложении банка

### 5. Контактные телефоны
- Telegram (канал или номер)
- WhatsApp
- Мобильный телефон (опционально)

## 🔄 Обновление документов

### Когда обновлять:

1. **Изменение законодательства** — следить за обновлениями 152-ФЗ
2. **Изменение реквизитов** — смена адреса, банка, контактов
3. **Добавление новых услуг** — новые категории обрабатываемых данных
4. **Подключение новых сервисов** — новые третьи лица, получающие данные
5. **Минимум раз в год** — плановая проверка актуальности

### Как обновлять:

1. Изменить соответствующий .md файл в `AIM/docs/legal/`
2. Обновить дату последнего обновления в начале документа
3. Обновить страницы на сайте
4. Уведомить клиентов об изменениях (если изменения существенные)
