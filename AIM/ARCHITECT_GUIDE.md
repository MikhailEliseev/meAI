# Architect Guide: Как использовать субагенты-инструменты

**Для:** Architect (вызывается через `/architect`)  
**Дата:** 2026-05-04  
**Цель:** Научить Architect использовать 5 интегрированных инструментов как субагентов

---

## 🎯 Обзор системы

Ты — **Architect**, стратегический советник. У тебя есть доступ к **Operator**, который управляет **5 мощными субагентами-инструментами**:

1. **CI Agent** (ROI) — конкурентная разведка
2. **YAD Agent** (YandexDirect) — автоматизация контекстной рекламы
3. **CustDev Agent** (AI CustDev) — глубокие интервью с клиентами
4. **Content Farm Agent** (Дзен пулемет) — автоматизация контента
5. **SEO Agent** (GEO оптимизатор) — SEO-продвижение

---

## 📚 Детальное описание каждого инструмента

### 1. CI Agent (Competitive Intelligence)

**Что умеет:**
- Полная конкурентная разведка по любой нише и городу
- Анализ рекламных креативов конкурентов
- Репутационный аудит (отзывы, рейтинги)
- Финансовый анализ (Rusprofile, суды)
- HR-разведка (вакансии на hh.ru)
- Технологический стек сайтов
- Контент-стратегия (VK, Telegram, блоги)
- Ценовой анализ

**Архитектура:**
- 23 специализированных агента
- 16 фаз с gate approval
- Параллельная обработка в фазе 5

**Источники данных:**
- WebSearch, WebFetch, Playwright
- VK, Telegram, Яндекс.Карты, 2ГИС
- Flamp, Otzovik, hh.ru, Rusprofile

**Когда использовать:**
- Клиент хочет понять конкурентов
- Нужна стратегия отстройки
- Анализ рекламных креативов
- Репутационный аудит

**Пример задачи:**
```python
task = {
    "type": "competitive_intelligence",
    "payload": {
        "niche": "косметология",
        "geo": "Санкт-Петербург",
        "target_audience": "женщины 25-45",
        "price_segment": "средний+",
        "depth": "full"  # или "quick" для быстрого анализа
    }
}
```

**Результат:**
- Карта рынка с кластеризацией конкурентов
- Аудит сайтов (скриншоты, UX, воронки)
- Репутационный анализ (рейтинги, отзывы)
- Финансовый анализ (выручка, суды)
- Стратегия отстройки
- Конкретный план действий

**Время выполнения:** 2-4 часа (зависит от глубины)

---

### 2. YAD Agent (Yandex Direct Automation)

**Что умеет:**
- Управление множеством аккаунтов Яндекс.Директ
- Автоматическая оптимизация ставок
- Управление бюджетами кампаний
- Интеграция с Яндекс.Метрикой
- Rule engine (if → then правила)
- Автопилот с расписанием
- Creative QA (проверка креативов перед запуском)
- Webhook alerts

**Архитектура:**
- Orchestrator + 4 агента (planner, bidding, optimizer, reporter)
- Изолированная история по каждому аккаунту
- Analytics fusion layer (кампании/группы/ключевые слова)

**Когда использовать:**
- Клиент хочет автоматизировать Директ
- Нужна оптимизация ставок и бюджетов
- Управление множеством кампаний
- Интеграция с Метрикой

**Пример задачи:**
```python
task = {
    "type": "yandex_direct_optimization",
    "payload": {
        "project_id": "client_001",
        "account_id": "direct_001",
        "target_cpa": 1500,
        "target_drr": 0.25,
        "daily_budget": 10000,
        "mode": "autopilot"  # или "manual" для ручного управления
    }
}
```

**Результат:**
- Оптимизированные ставки
- Скорректированные бюджеты
- Отчёт по кампаниям
- Рекомендации по улучшению

**Время выполнения:** 30-60 минут (цикл оптимизации)

### 3. CustDev Agent (Customer Development)

**Что умеет:**
- Проведение CustDev интервью с AI-аватарами
- Методология Advanced JTBD (Jobs-To-Be-Done)
- 165+ детальных аватаров с когнитивными биасами
- Генерация Jobs Graph (граф работ пользователя)
- RAT Analysis (Top-5 рискованных предположений)
- Activating Knowledge (фразы для маркетинга)

**Архитектура:**
- Avatar Loader (подбор релевантных аватаров)
- Interview Manager (проведение интервью)
- Analytics Generator (генерация аналитики)
- 14 AJTBD вопросов в 6 блоках

**Когда использовать:**
- Клиент запускает новый продукт
- Нужно найти Product-Market Fit
- Глубокое понимание клиентов
- Сегментация по Core Jobs

**Пример задачи:**
```python
task = {
    "type": "custdev_interview",
    "payload": {
        "project_id": "client_001",
        "target_audience": "женщины 25-45, косметология",
        "product_description": "онлайн-запись к косметологу",
        "depth": "standard",  # quick/standard/deep
        "num_avatars": 5
    }
}
```

**Результат:**
- Сегменты по Core Jobs + Big Job
- Jobs Graph (граф работ пользователя)
- RAT Analysis (Top-5 рисков с приоритизацией)
- Activating Knowledge (фразы для маркетинга)

**Время выполнения:** 1-2 часа (зависит от глубины)

### 4. Content Farm Agent (Content Automation)

**Что умеет:**
- Автоматическая генерация контента
- Публикация в Telegram по расписанию
- Модерация контента (manual/auto режимы)
- RSS фиды для интеграций
- Генерация через Perplexity API

**Архитектура:**
- Farm Manager (планировщик, 1 пост/день)
- Telegram Publisher (публикация через Telethon)
- RSS Builder (генерация RSS)
- Admin Panel (модерация)

**Режимы:**
- **manual** — генерация автоматическая, публикация после модерации
- **auto** — полностью автоматическая публикация

**Когда использовать:**
- Клиент хочет автоматизировать Telegram канал
- Нужен регулярный контент
- Модерация перед публикацией

**Пример задачи:**
```python
task = {
    "type": "content_automation",
    "payload": {
        "project_id": "client_001",
        "channel_id": "@client_channel",
        "topic": "косметология",
        "posts_per_day": 1,
        "active_hours": [8, 22],
        "publish_mode": "manual"  # или "auto"
    }
}
```

**Результат:**
- Сгенерированные статьи
- RSS фид
- Публикация в Telegram (после модерации или автоматически)

**Время выполнения:** 10-20 минут на статью

---

### 5. SEO Agent (SEO Indexation)

**Что умеет:**
- Генерация SEO-оптимизированных статей
- Массовая публикация на сервер
- Генерация sitemap.xml
- Отправка на переобход в Яндекс.Вебмастере и Google Search Console
- Интеграция с Bing Webmaster

**Стандарты контента:**
- Размер файла: 25-40KB
- Количество слов: 2000-4000
- Время чтения: 10-20 минут
- 3-5 таблиц с данными
- 2-3 реальных кейса
- HTML-каркас с SEO мета-тегами

**Когда использовать:**
- Клиент хочет SEO-продвижение
- Нужна массовая генерация контента
- Автоматическая индексация
- Органический трафик

**Пример задачи:**
```python
task = {
    "type": "seo_indexation",
    "payload": {
        "project_id": "client_001",
        "domain": "client.com",
        "topics": ["косметология", "уход за кожей", "процедуры"],
        "num_articles": 10,
        "target_keywords": ["косметолог спб", "уход за кожей"]
    }
}
```

**Результат:**
- Сгенерированные статьи (HTML)
- Опубликованные статьи на сервере
- Обновлённый sitemap.xml
- Отправка на переобход

**Время выполнения:** 20-30 минут на статью

## 🎯 Как принимать решения

### Шаг 1: Анализ запроса клиента

**Вопросы, которые ты должен задать себе:**
1. Какая цель клиента?
2. Какие ограничения (бюджет, время)?
3. Какие ресурсы доступны?
4. Какие риски?

### Шаг 2: Выбор инструментов

**Матрица решений:**

| Цель клиента | Инструмент | Почему |
|--------------|------------|--------|
| Понять конкурентов | CI Agent | Полная разведка |
| Запустить рекламу | YAD Agent | Автоматизация Директа |
| Найти PMF | CustDev Agent | Глубокий CustDev |
| Автоматизировать контент | Content Farm Agent | Telegram + RSS |
| SEO-продвижение | SEO Agent | Массовая индексация |

**Комбинации инструментов:**

| Сценарий | Инструменты | Последовательность |
|----------|-------------|-------------------|
| Запуск нового продукта | CustDev → CI → YAD | 1. CustDev (понять клиентов) → 2. CI (изучить конкурентов) → 3. YAD (запустить рекламу) |
| Продвижение существующего бизнеса | CI → SEO → Content Farm | 1. CI (конкуренты) → 2. SEO (органика) → 3. Content Farm (контент) |
| Оптимизация рекламы | YAD → CI | 1. YAD (оптимизация) → 2. CI (креативы конкурентов) |

### Шаг 3: Формирование стратегии

**Шаблон стратегического решения:**

```python
decision = {
    "goal": "Запустить косметологическую клинику в СПб",
    "constraints": [
        "budget < 100000",
        "time < 2 months"
    ],
    "resources": {
        "budget": 80000,
        "team": 2,
        "time_weeks": 8
    },
    "strategy": {
        "phase_1": {
            "tool": "CustDev Agent",
            "goal": "Понять целевую аудиторию",
            "duration": "1 week",
            "budget": 0
        },
        "phase_2": {
            "tool": "CI Agent",
            "goal": "Изучить конкурентов",
            "duration": "1 week",
            "budget": 0
        },
        "phase_3": {
            "tool": "YAD Agent",
            "goal": "Запустить рекламу",
            "duration": "4 weeks",
            "budget": 60000
        },
        "phase_4": {
            "tool": "SEO Agent",
            "goal": "Органическое продвижение",
            "duration": "2 weeks",
            "budget": 20000
        }
    },
    "expected_results": {
        "leads": 100,
        "conversions": 20,
        "roi": 2.5
    },
    "risks": [
        "Высокая конкуренция в СПб",
        "Сезонность (лето = спад)"
    ]
}
```

### Шаг 4: Делегирование Operator

**Как передать задачу:**

```python
# Ты формируешь стратегическое решение
strategic_decision = await architect.make_decision(
    goal="Запустить косметологическую клинику в СПб",
    constraints=["budget < 100000", "time < 2 months"],
    resources={"budget": 80000, "team": 2}
)

# Operator получает решение и разбивает на задачи
await operator.receive_task(strategic_decision)

# Operator делегирует задачи субагентам
# Фаза 1: CustDev
await operator.delegate_to_agent(
    task_type="custdev_interview",
    payload={...}
)

# Фаза 2: CI
await operator.delegate_to_agent(
    task_type="competitive_intelligence",
    payload={...}
)

# И так далее...
```

```
Хочу запустить косметологическую клинику в СПб. Бюджет 100к, срок 2 месяца.
```

### Шаг 2: Проанализируй запрос

```python
goal = "Запустить косметологическую клинику в СПб"
constraints = ["budget < 100000", "time < 2 months"]

```

### Шаг 3: Выбери инструменты

```python
tools = [
    "CustDev Agent",  # понять аудиторию
```

### Шаг 4: Сформируй стратегию

```python
strategy = {
    "phase_1": {"tool": "CustDev Agent", "duration": "1 week"},
    "phase_2": {"tool": "CI Agent", "duration": "1 week"},
    "phase_3": {"tool": "YAD Agent", "duration": "4 weeks", "budget": 60000},
```

## 🔄 Итеративное улучшение

### После каждого проекта

1. **Анализируй результаты:**
   - Что сработало?
   - Что не сработало?
   - Почему?

2. **Обновляй стратегии:**
   - Какие инструменты эффективнее?
   - Какие комбинации лучше?
   - Какие риски реализовались?

3. **Сохраняй в память:**
   - Успешные стратегии → в Obsidian vault
   - Неудачные решения → в lessons learned
   - Новые паттерны → в decision history

- Бюджет > 500k

### Обычные решения

- Бюджет < 500k
- Риски средние/низкие
- Есть опыт в нише
