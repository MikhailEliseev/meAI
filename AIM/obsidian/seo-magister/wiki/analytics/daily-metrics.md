# SEO Analytics Daily Metrics

Ежедневные метрики SEO домена, собранные SEO Analytics субагентом.

**Формат записи:**
```
## [YYYY-MM-DD HH:MM] SEO Metrics

**Period:** start → end

**Summary:**
- metric: value

**KPIs:**
- kpi: value

**Trends:**
- trend: direction

**Insights:**
- insight text
```

---

*Записи добавляются автоматически SEO Analytics субагентом*
