# Ads Analytics Daily Metrics

Ежедневные метрики Ads домена, собранные Ads Analytics субагентом.

**Формат записи:**
```
## [YYYY-MM-DD HH:MM] ADS Metrics

**Period:** start → end

**Summary:**
- metric: value

**KPIs:**
- kpi: value

**Trends:**
- trend: direction

**Insights:**
- insight text
```

---

*Записи добавляются автоматически Ads Analytics субагентом*
