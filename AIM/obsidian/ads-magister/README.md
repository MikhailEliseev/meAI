# Ads Magister Vault

**Role:** Advertising domain coordinator

**Owner:** Ads Magister Agent

**Purpose:** Manage advertising strategy, campaign creation, optimization, and performance tracking

## Structure

This vault follows the LLM Wiki pattern (Andrej Karpathy):

```
ads-magister/
├── raw/                    # Layer 1: Sources (immutable)
├── wiki/                   # Layer 2: Structured knowledge
│   ├── index.md           # Content-oriented catalog
│   ├── log.md             # Chronological operations log
│   ├── concepts/          # Ads concepts and patterns
│   ├── technologies/      # Ads tools and platforms
│   ├── strategies/        # Ads strategies and methods
│   ├── agents/            # Subagents managed
│   ├── workflows/         # Ads processes
│   ├── projects/          # Client campaigns
│   ├── sources/           # Processed sources
│   └── connections/       # Links and syntheses
├── decisions/             # Layer 3: Ads decisions
└── SCHEMA.md             # Rules and conventions
```

## Domain Focus
