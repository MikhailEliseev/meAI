# Content Magister Vault

**Role:** Content domain coordinator

**Owner:** Content Magister Agent

**Purpose:** Manage content strategy, creation, optimization, and distribution

## Structure

This vault follows the LLM Wiki pattern (Andrej Karpathy):

```
content-magister/
├── raw/                    # Layer 1: Sources (immutable)
├── wiki/                   # Layer 2: Structured knowledge
│   ├── index.md           # Content-oriented catalog
│   ├── log.md             # Chronological operations log
│   ├── concepts/          # Content concepts and patterns
│   ├── technologies/      # Content tools and technologies
│   ├── strategies/        # Content strategies and methods
│   ├── agents/            # Subagents managed
│   ├── workflows/         # Content processes
│   ├── projects/          # Client projects
│   ├── sources/           # Processed sources
│   └── connections/       # Links and syntheses
├── decisions/             # Layer 3: Content decisions
└── SCHEMA.md             # Rules and conventions
```
