# Vacancy Intelligence — Конкурентная разведка через вакансии

## Цель

Собрать данные о вакансиях клиники и конкурентов на hh.ru. Понять:
- Кто расширяется, у кого текучка
- Какие позиции ищут (стратегия найма)
- Какие зарплаты предлагают (бюджет, позиционирование)
- Общие требования к кандидатам (качество найма)

## Инструмент

**Только Firecrawl** с JS-рендерингом. hh.ru рендерит вакансии на клиенте (React/Magritte), статический scraping не работает. Ждать 5-8 секунд после загрузки.

## КЛЮЧЕВОЕ: Бренд ≠ Работодатель на hh.ru

**На hh.ru вакансии публикуются от юрлица, НЕ от бренда.** Клиника «Тори» может быть зарегистрирована как ООО «МедЭстетик» или ООО «Клиника Тори». Поиск по бренду часто выдаёт 0 результатов.

**Всегда сначала бери юрлицо из data.json:** `clinic.legal_entity.name` (полное наименование) и `clinic.legal_entity.short_name` (краткое).

## Методология

### Step 0: Извлечь юрлица

Из `data.json` достать ВСЕ возможные названия для поиска:
```
clinic_name = data.clinic.name                          # "Тори"
legal_name = data.clinic.legal_entity.name              # "ООО МедЭстетик"
legal_short = data.clinic.legal_entity.short_name       # "МедЭстетик"
domain = data.clinic.domain                              # "toriclinic.ru"
inn = data.clinic.legal_entity.inn                       # "7705123456"
```

**Массив поисковых запросов (пробовать последовательно, пока не найдутся вакансии):**
1. `legal_short` — краткое юрлицо (самый частый формат на hh.ru)
2. `clinic_name` — бренд (иногда совпадает с юрлицом)
3. `legal_name.split("ООО")[-1].strip()` — название без ООО
4. `domain.split(".")[0]` — имя домена (иногда в тексте вакансий)
5. `inn` — ИНН (последнее средство, редко срабатывает)

### Step 1: Поиск вакансий клиники

**1a. Поиск по компании (search_field=company_name):**
```
firecrawl_scrape(url="https://hh.ru/search/vacancy?text=КРАТКОЕ_ЮРЛИЦО&search_field=company_name&items_on_page=20", waitFor=8000, formats=["markdown"])
```

**1b. Поиск по бренду в общем тексте:**
```
firecrawl_scrape(url="https://hh.ru/search/vacancy?text=БРЕНД_КЛИНИКИ&area=ID_ГОРОДА&items_on_page=20", waitFor=8000, formats=["markdown"])
```

**1c. Поиск работодателя через firecrawl_search (найти страницу компании на hh.ru):**
```
firecrawl_search(query="site:hh.ru/employer ЮРЛИЦО_ИЛИ_БРЕНД", limit=3)
```
Если найдена страница работодателя — scrape её напрямую:
```
firecrawl_scrape(url="https://hh.ru/employer/ID_РАБОТОДАТЕЛЯ", waitFor=8000, formats=["markdown"])
```

**1d. Поиск по домену (иногда сайт указан в вакансии):**
```
firecrawl_scrape(url="https://hh.ru/search/vacancy?text=ДОМЕН&area=ID_ГОРОДА&items_on_page=20", waitFor=8000, formats=["markdown"])
```

**Если после первых 2 запросов найдены вакансии — остановиться. Не гонять все 5 запросов.**

### Step 2: Поиск вакансий конкурентов

Для каждого конкурента (top-5) — та же стратегия:
1. Если есть юрлицо → поиск по юрлицу
2. Если юрлица нет → поиск по бренду
3. Поиск по домену

```
firecrawl_scrape(url="https://hh.ru/search/vacancy?text=КОНКУРЕНТ&search_field=company_name&items_on_page=20", waitFor=8000, formats=["markdown"])
```

**Если конкурент не найден ни по одному запросу → явно записать: «Конкурент не размещает вакансии на hh.ru». Не выдумывать.**

### Step 3: Зарплатный бенчмарк по специализации

Общий поиск по врачебной специализации клиники + город:
```
firecrawl_scrape(url="https://hh.ru/search/vacancy?text=СПЕЦИАЛИЗАЦИЯ&area=ID_ГОРОДА&items_on_page=20&only_with_salary=true", waitFor=8000, formats=["markdown"])
```

**Важно:** использовать корректный ID города для hh.ru (area), а не название. Москва = 1, СПб = 2.

Основные area ID:
- 1 — Москва
- 2 — Санкт-Петербург
- 3 — Екатеринбург
- 4 — Новосибирск
- (список: https://api.hh.ru/areas)

### Step 4: Извлечение и анализ

Из markdown-результата Firecrawl вытащить для каждой вакансии:
- Должность
- Работодатель (юрлицо)
- Зарплата (вилка: от–до, до вычета НДФЛ)
- Опыт (1-3 года, 3-6 лет, etc.)
- Занятость (полный день, сменный, etc.)
- Дата публикации / обновления

## Интеграция в КП

Блок "Конкурентная разведка: вакансии и найм" размещается в секции #competitors после основного анализа конкурентов.

Формат вывода для клиента:
1. **Кто ищет сотрудников** — таблица: клиника + конкуренты, кол-во вакансий, топ-позиции
2. **Зарплатный бенчмарк** — вилка зарплат по должностям, медиана по рынку
3. **Стратегические выводы** — 3-5 инсайтов о найме на рынке

## Ротация ключей Firecrawl

Если Firecrawl возвращает "Payment Required" или "402" — НЕ сообщать клиенту. Патч `firecrawl_provider_bank.py` автоматически переключит на следующий ключ. Молча повторяй запрос.

## Правила

- Результаты помечать датой сбора (вакансии быстро устаревают)
- Если после 2+ стратегий поиска клиника/конкурент не найден → «Не размещает вакансии на hh.ru»
- **Не выдумывать** вакансии — если не нашли, так и пишем
- Не показывать зарплаты конкретных людей, только вилки
- Если Firecrawl полностью недоступен — пропустить ВЕСЬ блок, НЕ заменять curl/wget
