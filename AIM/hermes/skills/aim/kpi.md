# KPI Framework AIM

## North Star метрика

**Стоимость привлечения пациента (CPA)** — единая метрика эффективности всего агентства.

**Цель:** <2 000 за пациента
**Период:** скользящие 3 месяца
**Расчёт:** все расходы клиента (агентство + рекламные бюджеты) / количество новых пациентов

Всё что мы делаем — SEO, контент, реклама — работает на снижение этой цифры.

---

## SEO KPI

Измеряются ежемесячно, сравниваются с предыдущим месяцем и планом.

### Позиции в поиске
- **Ключевых слов в топ-3:** количество и % от семантического ядра
  - Цель: >30% ядра в топ-3 через 6 месяцев работы
- **Ключевых слов в топ-10:** количество и % от ядра
  - Цель: >50% ядра в топ-10 через 6 месяцев
- **Средняя позиция по ядру:** средневзвешенная по трафику
  - Цель: улучшение на 20% квартал к кварталу

### Органический трафик
- **Сессии/мес (Яндекс + Google):** общее количество
  - Цель: +25% квартал к кварталу
- **Пользователи/мес (уникальные):** без повторных визитов
  - Цель: +20% квартал к кварталу
- **Трафик на посадочных страницах услуг:** самые важные страницы
  - Цель: +30% квартал к кварталу (приоритет над блогом)

### Поведенческие
- **CTR из поиска:** для отслеживаемых запросов
  - Цель: >3% для коммерческих, >5% для информационных
- **Bounce rate (показатель отказов):** 
  - Цель: <40% по сайту, <30% на страницах услуг
- **Глубина просмотра:** страниц/сессию
  - Цель: >2.5
- **Время на сайте:** среднее
  - Цель: >2 минуты

### Конверсия
- **Посетитель → лид (заявка/звонок):**
  - Цель: >2% по сайту, >5% на страницах услуг
- **Лид → запись на приём:**
  - Цель: >50% (зависит от колл-центра клиники)

### Ссылочный профиль
- **Domain Rating (Ahrefs):** авторитетность домена
  - Цель: +5 пунктов в год
- **Referring domains:** количество уникальных ссылающихся доменов
  - Цель: +20% в квартал
- **Токсичные ссылки:** количество и % от профиля
  - Цель: <5% токсичных

## Content KPI

Измеряются ежемесячно.

### Производство контента
- **Материалов опубликовано/мес:** общее количество
  - Цель: 8-12 (в зависимости от пакета)
- **План-факт:** % материалов опубликовано по плану
  - Цель: 100%
- **Средний объём материала:** слов
  - Цель: 1 500-3 000 (статьи), 800-1 500 (страницы услуг)

### Качество и вовлечение
- **Медицинская достоверность:** оценка редактора после проверки
  - Цель: >95% (доля материалов без замечаний редактора)
- **Среднее время на странице:** для контентных страниц
  - Цель: >3 минут (статьи), >1.5 минут (страницы услуг)
- **Дочитываемость:** скролл >80% страницы
  - Цель: >40% посетителей

### SEO-эффект контента
- **Покрытие семантического ядра контентом:** % keywords с релевантной страницей
  - Цель: >80%
- **Позиции контентных страниц:** распределение топ-3/топ-10/топ-30
  - Цель: >20% контентных страниц в топ-3 через 3 месяца после публикации
- **Органический трафик на контентные страницы:**
  - Цель: +15% месяц к месяцу для новых страниц

## Ads KPI

Измеряются еженедельно (внутренне) и ежемесячно (для клиента).

### Эффективность (ROAS)
- **ROAS (Return on Ad Spend):** выручка / рекламные расходы
  - Цель: **>300%** (на каждый 1 рекламы — 3 выручки)
- **Доля рекламных расходов (ДРР):** рекламные расходы / выручка
  - Цель: <33%

### Стоимость клика и конверсии
- **CPC (стоимость клика):** по каналам
  - Яндекс.Директ поиск: цель <150 (медицинская тематика)
  - Яндекс.Директ РСЯ: цель <30
  - VK Ads: цель <50
  - Telegram Ads: цель <100
- **CPL (стоимость лида):** рекламные расходы / лиды
  - Цель: <1 000 (первичная), стремимся к <500
- **CPA (стоимость пациента):** рекламные расходы / новые пациенты из рекламы
  - Цель: <2 000 (основной KPI, объединяет все каналы)

### Кликабельность
- **CTR (Click-Through Rate):** по каналам
  - Яндекс.Директ поиск: цель >5%
  - Яндекс.Директ РСЯ: цель >0.5%
  - VK Ads: цель >1%
- **Качество показов:** % нецелевых запросов (по минус-словам)
  - Цель: <10% нецелевых

### Конверсия
- **Клик → лид:** для рекламных лендингов
  - Цель: >3%
- **Лид → запись:** отложенная конверсия
  - Цель: >50% (зависит от колл-центра клиники)

### Качество кампаний (Яндекс.Директ)
- **Quality Score (средний):** оценка Яндекса
  - Цель: >7/10
- **Доля показов (Impression Share):** % от доступного трафика
  - Цель: >80% по брендовым, >50% по общим

## Client Health KPI

Измеряются ежемесячно для каждого клиента, агрегируются по агентству.

### Удовлетворённость
- **NPS (Net Promoter Score):** опрос раз в квартал
  - Цель: >50 (отлично: >70)
- **Статус проекта (светофор):**
  - Green: все KPI в плане или выше (цель: >70% проектов)
  - Yellow: 1-2 KPI ниже плана (допустимо: <25%)
  - Red: >2 KPI ниже плана или клиент выразил недовольство (недопустимо: <5%)

### Операционные
- **Дней с последнего отчёта:**
  - Цель: <7 (для еженедельного), <35 (для ежемесячного)
- **Среднее время ответа Operator клиенту:**
  - Цель: <15 минут в рабочее время (10:00-19:00 МСК)
- **Время решения эскалации:**
  - Цель: <60 минут

### Финансовые
- **LTV (Lifetime Value):** общая выручка от клиента за всё время
  - Цель: >1 200 000 (6 месяцев Full Agency)
- **Retention Rate:** % клиентов, продливших контракт
  - Цель: **>90%** (годовой)
- **Средняя длительность проекта:**
  - Цель: >12 месяцев
- **Churn Rate:** % клиентов, ушедших в месяц
  - Цель: <5% в год

## Lead Pipeline KPI

Измеряются еженедельно для управления воронкой агентства.

### Поток лидов
- **Новых лидов/неделю:** абсолютное количество
  - Цель: 10+ (растущий показатель)
- **Источники лидов:** сайт, Telegram, рекомендации, конференции
  - Цель: максимум каналов с измеримой эффективностью

### Конверсия воронки
- **Presale конверсия:** лид → контракт
  - Цель: >20% квалифицированных лидов
- **Среднее время от лида до контракта:**
  - Цель: <2 недели для горячих, <1 месяц для тёплых

### Экономика воронки
- **CAC (Customer Acquisition Cost):** все расходы на привлечение / новые клиенты
  - Цель: <100 000 (окупается за первый месяц Full Agency)
- **CAC:LTV ratio:** стоимость привлечения к lifetime value
  - Цель: 1:12+ (CAC окупается 12+ раз за жизнь клиента)
- **Средний чек контракта:** 
  - Цель: >150 000/мес (стремимся к Full Agency >200 000/мес)

## Расчётные формулы

```
CPA = (расходы на агентство + рекламные бюджеты) / новые пациенты
ROAS = выручка клиента, атрибутированная к рекламе / рекламные расходы
CPL = рекламные расходы / количество лидов из рекламы
CTR = клики / показы * 100%
Bounce Rate = сессии с 1 просмотром / все сессии * 100%
Retention Rate = клиенты на конец периода / клиенты на начало периода * 100%
NPS = % Promoters (9-10) - % Detractors (0-6)
CAC = (расходы на маркетинг + зарплаты sales) / новые клиенты за период
LTV = средний чек * средняя длительность проекта
```
