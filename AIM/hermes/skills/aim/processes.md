# Процессы агентства AIM

## Путь клиента

```
Presale → Аудит → Предложение → Контракт → Onboarding → Активный проект → Ежемесячный отчёт → Продление
```

Каждый этап автоматизирован и управляется Operator совместно с Magisters.

---

## Presale (привлечение)

**Участники:** Operator, SEO Magister (аудит)

**Процесс:**
1. Посетитель заходит на iamaim.ru
2. Начинает чат с Operator (веб-чат или Telegram)
3. Operator квалифицирует: спрашивает специализацию клиники, город, текущий маркетинг
4. Operator запрашивает URL сайта клиники
5. Operator запускает SEO-аудит через SEO Magister (`run_seo_audit`)
6. Operator выдаёт 3 цифры: пациенты, время, стоимость пациента (формат: «ВАШ РЕЗУЛЬТАТ»)
7. Operator собирает контакт (`collect_contact`)
8. Создаётся lead dossier (lead_id, профиль, история чата, статус)
9. Михаил получает уведомление о новом квалифицированном лиде
10. Михаил проводит личный звонок/видеовстречу с клиентом
11. После встречи — коммерческое предложение (формируется Operator на основе данных аудита)

**Ключевые метрики этапа:**
- Время от первого сообщения до выдачи WOW-результата: < 3 минуты
- Конверсия: посетитель сайта → начало чата
- Конверсия: начало чата → контакт (telegram/email/phone)
- Конверсия: контакт → встреча с Михаилом

## Onboarding (подключение)

**Участники:** Operator, Михаил, клиент

**Процесс:**
1. Контракт: подписание через Контур.Диадок (российский ЭЦП-сервис)
2. Оплата: ЮKassa (50% предоплата за первый месяц)
3. Сбор документов: лицензия на медицинскую деятельность, ИНН, ОГРН
4. Kickoff-встреча: Михаил + клиент — обсуждение целей, ожиданий, KPI на первые 3 месяца
5. Доступы: Operator запрашивает доступы к Яндекс.Вебмастер, Google Search Console, Яндекс.Метрика, рекламным кабинетам, соцсетям
6. Настройка дашборда: клиент получает доступ к real-time KPI Dashboard
7. Запуск аудита: 2-недельный аудит-спринт (все Magisters запускаются одновременно)
8. Первый отчёт: через 2 недели — полный аудит и план работ на месяц

**Ключевые метрики этапа:**
- Время от подписания контракта до kickoff-встречи: < 3 дня
- Время от подписания до первого отчёта: < 14 дней
- Процент успешных оплат (без возвратов)

## Active: Активный проект (ежемесячная работа)

**Участники:** Operator, SEO Magister, Content Magister, Ads Magister, Analytics Magister

**Еженедельный цикл:**
1. Понедельник: Magisters получают обновлённый план (KPI, приоритеты)
2. Вторник-четверг: Magisters выполняют задачи автономно
3. Пятница: Analytics Magister собирает данные за неделю
4. Пятница: Operator отправляет клиенту короткий статус (3 KPI + текущие задачи)
5. В течение недели: клиент может обратиться к Operator с вопросами в чат

**Ежемесячный цикл:**
1. 1-е число: Analytics Magister формирует полный месячный отчёт
2. 1-3 число: Operator подготавливает отчёт (проверяет цифры, пишет выводы)
3. 3-5 число: Operator отправляет отчёт клиенту
4. 5-7 число: созвон с клиентом (обсуждение отчёта, планы на месяц)
5. 7-10 число: Magisters корректируют планы по итогам созвона

**Квартальный цикл:**
1. Стратегическая сессия: Михаил + клиент + Operator
2. Обзор результатов за квартал (все KPI)
3. Корректировка стратегии на следующий квартал
4. Обновление KPI и плановых показателей

**Ключевые метрики этапа:**
- NPS клиента (цель: >50)
- Retention rate (цель: >90%)
- Средняя длительность проекта (цель: >12 месяцев)

## Escalation: Эскалация (если что-то идёт не так)

**Участники:** Operator, Михаил

**Процесс:**
1. Клиент задаёт вопрос, на который Operator не может ответить
2. Operator отвечает: «Михаил свяжется с вами в течение часа»
3. Operator создаёт тикет в Linear с тегом `client-escalation`
4. Линейный тикет содержит: lead_id, вопрос клиента, контекст, срочность
5. Михаил получает уведомление в Telegram
6. Михаил отвечает клиенту напрямую (звонок или сообщение)
7. После решения: Operator получает обновлённую информацию для будущих ответов

**Критические ситуации (немедленная эскалация):**
- Клиент недоволен результатами и угрожает расторжением
- Техническая проблема на сайте клиента (упал, не индексируется)
- Рекламный бюджет потрачен с нулевым результатом
- Юридический вопрос (договор, оплата, претензия)

## Reporting: Регламент отчётности

**Еженедельный отчёт (каждую пятницу):**
- Формат: короткое сообщение в Telegram/веб-чат
- Содержание: 3 ключевых KPI (трафик/лиды/пациенты), что сделано за неделю, что будет на следующей
- Получатель: руководитель клиники
- Отправитель: Operator

**Ежемесячный отчёт (1-5 число):**
- Формат: PDF + онлайн-дашборд
- Содержание: все KPI по направлениям, сравнение с прошлым месяцем, выводы, рекомендации
- Получатель: руководитель клиники + маркетолог (если есть)
- Отправитель: Operator (отчёт формируется Analytics Magister)

**Квартальный отчёт:**
- Формат: презентация + PDF + созвон
- Содержание: стратегический обзор, достижения/провалы, рынок и конкуренты, план на следующий квартал
- Получатель: руководитель клиники + инвесторы (если есть)
- Участники созвона: Михаил, Operator (через Михаила), клиент

## Инструменты и платформы

**Российский рынок:**
- Контур.Диадок — электронный документооборот (договоры, акты, счета)
- ЮKassa — приём платежей (карты, СБП, электронные кошельки)
- Яндекс.Вебмастер — мониторинг индексации в Яндексе
- Яндекс.Метрика — веб-аналитика
- Яндекс.Директ — контекстная реклама
- 2ГИС — локальное SEO
- ПроДокторов, НаПоправку — медицинские агрегаторы и отзывы

**Международные (работают в РФ):**
- Google Search Console — мониторинг индексации в Google
- Google Analytics — резервная веб-аналитика
- SendGrid — email-коммуникации (прогревы, напоминания, отчёты)
- Telegram — основной канал общения с клиентами
