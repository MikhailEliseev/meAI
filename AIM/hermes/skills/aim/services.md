# Услуги агентства AIM

## SEO Package: «Поисковая оптимизация для медицинских сайтов»

Поисковое продвижение клиники в Яндексе и Google с фокусом на привлечение пациентов.

### Что входит

**Технический аудит (50+ страниц):**
- Проверка PageSpeed (desktop и mobile)
- Анализ Core Web Vitals (LCP, FID, CLS)
- Mobile-first оптимизация
- Структурированные данные (MedicalOrganization, Physician, MedicalWebPage schema)
- Аудит индексации (Яндекс.Вебмастер, Google Search Console)
- Проверка дублей, битых ссылок, редиректов

**Keyword Research (500+ ключевых слов):**
- Сбор семантического ядра по медицинским специальностям
- Кластеризация по интенту (информационные, коммерческие, навигационные)
- Анализ сезонности медицинских запросов
- Приоритизация по объёму и конверсионности

**Анализ конкурентов (3-5 клиник):**
- Сравнение позиций по общему семантическому ядру
- Gap analysis: какие запросы есть у конкурентов, но нет у вас
- Анализ контент-стратегии конкурентов (типы страниц, структура, частота публикаций)
- Анализ ссылочного профиля (количество, качество, динамика)

**Работа с ссылочным профилем:**
- Анализ текущего профиля (Ahrefs DR, трастовые и токсичные ссылки)
- Разработка стратегии наращивания (крауд-маркетинг, медицинские каталоги, гостевые статьи)
- Детекция и дезавуирование токсичных ссылок

**Локальное SEO (Россия):**
- Оптимизация Яндекс.Карты и 2ГИС (фото, описание, услуги, акции)
- NAP consistency: единые контакты на всех площадках
- Сбор и управление отзывами (Яндекс.Карты, 2ГИС, Google Maps, ПроДокторов, НаПоправку)
- Гео-страницы для каждой локации клиники

**Ежемесячная отчётность:**
- Позиции по ключевым словам (топ-3, топ-10, динамика)
- Органический трафик (сессии, пользователи, динамика)
- Конверсия посетитель → лид
- Рекомендации на следующий месяц

**Цена:** от 80 000 /мес
**Минимальный срок:** 3 месяца (SEO — долгосрочная стратегия)

## Content Package: «Медицинский контент-маркетинг»

Создание контента, который ранжируется, читается и приводит пациентов.

### Что входит

**Медицинский копирайтинг (8-12 материалов/мес):**
- Статьи для блога (1 500-3 000 слов) — образовательный контент по заболеваниям, симптомам, методам лечения
- Страницы услуг — коммерческий контент с конверсионными элементами
- Кейсы пациентов — реальные истории (с согласия) для доверия
- FAQ страницы — ответы на частые вопросы пациентов
- Лендинги под рекламные кампании (Яндекс.Директ, VK Ads)

**Медицинская редактура:**
- Проверка на соответствие клиническим рекомендациям Минздрава РФ
- Факт-чекинг всех медицинских утверждений
- Проверка дозировок, названий препаратов (МНН), противопоказаний
- Маркировка рекламных материалов согласно ФЗ «О рекламе» (пометка «ИМЕЮТСЯ ПРОТИВОПОКАЗАНИЯ, НЕОБХОДИМА КОНСУЛЬТАЦИЯ СПЕЦИАЛИСТА»)

**Контент-план:**
- На основе семантического ядра (SEO Magister) и сезонности медицинских запросов
- Приоритизация по конверсионности и позициям
- Календарь публикаций на месяц вперёд

**On-page SEO оптимизация:**
- Оптимизация title, description, h1-h6
- LSI-ключи и семантическая разметка
- Внутренняя перелинковка
- Оптимизация сниппетов для Яндекса и Google

**Ведение блога:**
- Планирование тем на квартал
- Публикация по расписанию (2-3 статьи/неделю)
- Обновление старых статей (актуализация данных, дат, статистики)

**Цена:** от 60 000 /мес

## Ads Package: «Платное продвижение медицинских услуг»

Рекламные кампании с фокусом на стоимость привлечения пациента, а не клика.

### Что входит

**Яндекс.Директ:**
- Настройка кампаний: поиск + РСЯ (ретаргетинг)
- Стратегия: ручное управление ставками с Machine Learning-корректировками
- Оптимизация: минус-слова, корректировка ставок по аудиториям, времени, гео
- А/Б тестирование объявлений (заголовки, тексты, быстрые ссылки)
- UTM-разметка для сквозной аналитики

**VK Ads:**
- Таргетинг: интересы (медицина, здоровье), поведение (поиск врачей, запись на приём)
- Ретаргетинг: посетители сайта, лиды, не завершившие запись
- Форматы: карусель, видео, лид-формы
- А/Б тестирование аудиторий и креативов

**Telegram Ads:**
- Реклама в профильных медицинских каналах (посевы)
- Таргетированная реклама через Telegram Ads
- Создание и ведение канала клиники (контент, администрирование)

**Генерация креативов:**
- Баннеры (статичные и анимированные) для всех платформ
- Тексты объявлений с AIDA-структурой (Attention-Interest-Desire-Action)
- Сценарии для видео-креативов (15-30 секунд)
- Креативы адаптированы под медицинские ограничения рекламных платформ

**Оптимизация бюджета:**
- Распределение бюджета между каналами по эффективности (CPA)
- Недельная корректировка: перераспределение с неэффективных каналов на эффективные
- Авто-правила: отключение убыточных кампаний, масштабирование прибыльных

**Еженедельная отчётность:**
- ROAS, CPC, CTR по каждому каналу
- Конверсия: клик → лид, лид → запись
- Стоимость лида (CPL) и стоимость пациента (CPA)
- Quality Score в Яндекс.Директ
- Рекомендации на следующую неделю

**Цена:** от 100 000 /мес + рекламный бюджет (минимум 50 000 /мес)

## Full Agency: «Полный цикл маркетинга»

Все три направления в одном пакете — стратегия, реализация, аналитика.

### Что входит дополнительно к трём пакетам

**Выделенный Project Manager:**
- Единое контактное лицо для клиники (не нужно общаться с SEO, контентом и рекламой по отдельности)
- Еженедельные созвоны: статус проекта, результаты недели, планы
- Оперативная реакция на запросы (Telegram-чат с клиникой)

**Единая стратегия:**
- SEO + контент + реклама работают как единый механизм
- Контент-план синхронизирован с рекламными кампаниями (лендинги готовы до запуска рекламы)
- SEO-оптимизация усиливает эффект рекламы (посетители из рекламы возвращаются через поиск)

**Real-time KPI Dashboard:**
- Доступ к дашборду 24/7 (веб-интерфейс)
- Все метрики в реальном времени: позиции, трафик, лиды, пациенты, рекламные кампании
- Сравнение с плановыми показателями и прошлым периодом

**Приоритетная поддержка:**
- Прямой Telegram-чат с Operator (время ответа < 15 минут в рабочее время)
- Приоритет в очереди задач (задачи Full Agency клиентов выполняются первыми)
- Ежемесячный стратегический созвон с Михаилом (основатель AIM)

**Цена:** от 200 000 /мес
**Минимальный срок:** 6 месяцев (стратегия требует времени)
