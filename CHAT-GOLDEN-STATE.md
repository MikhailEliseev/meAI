## Параметры эталона

### Стиль
- **Окно чата:** 88vw × 85vh, отцентрировано (`margin: 0 auto`), скруглённые углы 24px
- **Фон:** полностью непрозрачный (`--glass-bg: #ffffff` / `#0d0d0d`)
- **Без backdrop-filter** на chat-wrapper и message bubbles
- **Glass-эффект** убран — сплошной цвет, ничего не просвечивает

### Сообщения прогресса (SSE tool-progress events)
Человекочитаемые сообщения на русском для каждого тула:
- 📋 Определяю клинику: ИНН, юрлицо, адрес…
- 🔍 Собираю обзор: врачи, услуги, соцсети…
- 🗺️ Ищу конкурентов рядом через Google Maps (это ~1-2 минуты)…
- 💰 Получаю выручку конкурентов из ФНС…
- ✅ [тул] готов

### Markdown рендеринг
- **На лету в RAF loop:** `marked.parse()` + `DOMPurify.sanitize()`
- Клиент НЕ видит сырой Markdown — сразу HTML (таблицы, заголовки, жирный)

### Брендинг
- **НЕ упоминаем:** «Гермес», технологии, model names
- Welcome: «Здравствуйте! Я AI-ассистент AIM — делаю предварительную разведку по вашей клинике»
- Везде: «AI-ассистент AIM»

### Кнопка «AIM Ассистент»
- **Скрыта** когда чат открыт (`display: none`)
- **Показана** когда чат закрыт (`display: flex`)

### Phase Tracker
- **Убран полностью** (`chat-inline-pro.php` отключён)
- Плашка «Разведка пресейла 0/8» не показывается
