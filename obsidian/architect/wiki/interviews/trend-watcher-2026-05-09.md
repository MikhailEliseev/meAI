## Блок 1: Роль и уникальность

**Q1: Что делает Trend Watcher Agent?**

A: Мониторит тренды в социальных сетях (Instagram, YouTube Shorts), анализирует виральные ролики конкурентов и генерирует ТЗ для создания собственного контента.

**Q2: Кто родительский Magister?**

A: Social Magister

**Q3: Почему это критично для агентства?**

A: Без Trend Watcher агентство теряет возможность быстро реагировать на тренды и упускает потенциальный трафик. Один виральный ролик может дать огромный охват и продажи.

**Уникальная ценность:**
- Быстро реагировать на тренды (обнаружение за 6 часов)
- Быть первыми по охватам (генерация ТЗ до того, как тренд устареет)
- Собирать трафик и делать продажи

---

## Блок 2: Входные данные

**Q4: Откуда берутся данные?**

A: 
- Список аккаунтов конкурентов (Instagram, YouTube)
- API ключи для мониторинга (Apify Instagram Web Scraper API)
- Пороги виральности (минимум просмотров, engagement rate)

**Q5: Какие обязательные параметры?**

A:
- `competitor_accounts: list[str]` — список аккаунтов для мониторинга
- `monitoring_interval: int` — интервал мониторинга (по умолчанию 6 часов)
- `virality_threshold: float` — порог виральности (по умолчанию 500)

**Опциональные:**
- `max_videos_per_check: int` — максимум роликов за проверку (по умолчанию 10)
- `min_views: int` — минимум просмотров (по умолчанию 10000)
- `max_video_age_hours: int` — максимальный возраст ролика (по умолчанию 48 часов)

## Блок 3: Алгоритм работы

**Q6: Какие основные шаги?**

A: 8 шагов:
1. Мониторинг аккаунтов конкурентов (Apify Instagram Web Scraper API)
2. Отбор виральных роликов (по коэффициенту виральности)
3. Транскрибация аудио (Assembly AI)
4. Визуальный анализ (срезы каждые 5 секунд, Google Cloud Vision API)
5. Генерация сценария (Claude API)
6. Генерация ТЗ для монтажёра
7. Генерация описания для поста
8. Расчёт метрик и статистика

**Q7: Какие внешние API используются?**

A:
- **Apify Instagram Web Scraper API** — мониторинг конкурентов
- **Assembly AI** — транскрибация + перевод
- **Google Cloud Vision API** — визуальный анализ кадров
- **Claude API** — генерация сценария и описания (Opus 4.7 для максимальной человечности)

**Q8: Есть ли специфичная логика?**

A: Да, несколько важных моментов:

1. **Коэффициент виральности:**
   ```
   virality_score = (views / hours_since_publish) * (1 + engagement_rate)
   engagement_rate = (likes + comments) / views
   ```
   **TODO:** Формула требует исследования (1-2 недели)

2. **Ротация API ключей:**
   - Пул бесплатных аккаунтов Apify (по $5)
   - Автоматическое переключение при исчерпании лимитов

3. **Согласование перед публикацией:**
   - `approval_required: true`
   - Пользователь утверждает через Operator

4. **Мониторинг каждые 6 часов:**
   - Баланс между скоростью и нагрузкой

## Блок 4: Результаты и метрики

**Q9: Что возвращает агент?**

A: Для каждого тренда:
- Сценарий ролика (текст)
- Озвучка (текст для озвучки)
- ТЗ для монтажёра (кадры, камеры, визуальные элементы)
- Описание для поста (короткий текст)
- Метрики виральности ролика-источника
- Статистика по взлетевшим роликам

**Q10: Какие метрики качества?**

A:
- **Success rate:** > 95%
- **Execution time:** < 10 минут на 1 ролик
- **Процент взлетевших роликов:** > 30% (из предложенных трендов)
- **Скорость реакции:** < 12 часов (от обнаружения до ТЗ)
- **Точность предсказания:** > 50% (из предложенных трендов реально взлетели)

## Блок 5: Особенности и edge cases

**Q11: Какие специфичные ошибки?**

A:
1. **API_KEY_EXHAUSTED** — все ключи из пула исчерпаны → переключение на следующий → эскалация если все исчерпаны
2. **VIDEO_NO_AUDIO** — ролик без звука → только визуальный анализ → генерация сценария на основе визуала
3. **VIDEO_FOREIGN_LANGUAGE** — ролик на иностранном языке → транскрибация + перевод на русский → генерация сценария на русском
4. **TREND_OUTDATED** — тренд уже устарел (> 48 часов) → пропустить → логировать для анализа паттернов

## Комментарии и инсайты

**Во время интервью:**
- Формула виральности — ключевой момент, требует исследования
- Ротация API ключей — критичная функция (пул бесплатных аккаунтов)
- Согласование перед публикацией — обязательно (approval_required: true)
- Мониторинг каждые 6 часов — баланс между скоростью и нагрузкой

**Решения:**
- Использовать Claude Opus 4.7 для генерации сценария (максимальная человечность)
- Визуальный анализ каждые 5 секунд (баланс между детальностью и скоростью)
- Retry 10 раз при ошибках API (exponential backoff)
