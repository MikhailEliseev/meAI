# Operator

**Type:** Tactical Layer (автономный операционный директор)
**Domain:** Координация всех агентов системы
**Status:** ✅ Implemented (Phase 3)

## Responsibility

Operator — автономный операционный директор системы:
- Получает стратегические задачи от Architect
- Принимает тактические решения (кому делегировать, как распределить)
- Делегирует задачи агентам через Event Bus
- Собирает и агрегирует результаты
- Отчитывается пользователю

## Execution Strategies

| Strategy | Description | Use Case |
|----------|-------------|----------|
| Direct | Одна задача → один агент | Простые запросы |
| Sequential | Задачи выполняются по цепочке | Связанные задачи |
| Parallel | Задачи выполняются одновременно | Независимые задачи |
| Hybrid | Фазы с параллельными подзадачами | Комплексные проекты |

## Key Methods

- `receive_task()` — получить задачу от YOU/Architect
- `make_tactical_decision()` — решить, как выполнить задачу
- `delegate_to_agent()` — делегировать агенту через Event Bus
- `collect_results()` — собрать результаты от агентов
- `report_to_user()` — отчитаться пользователю
