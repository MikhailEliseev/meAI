API Architecture

  • Base URL: https://api.direct.yandex.com/json/v5/{service}
  • Authentication: OAuth 2.0 Bearer token + optional Client-Login header
  • Rate Limits: 5 concurrent connections, 100,000 points/day
  • Error Codes: 152 (not enough points), 506 (too many connections), 1002 (invalid token)

  • Prohibited: Patient testimonials, guarantees, targeting minors, comparison claims
  • Required: Medical license number, issuing authority, specialist qualifications
  • Moderation: 24-48 hours manual review

Resilience Patterns

  • Connection Pooling: Limit to 5 concurrent connections (httpx.Limits)
  • Circuit Breaker: Open after 5 failures, reset after 60s
  • Exponential Backoff: 1s → 2s → 4s → 8s → 16s → 30s max
  • Rate Limit Detection: Detect 506 error and backoff
  • Changes Service: 80-90% API call reduction for monitoring
