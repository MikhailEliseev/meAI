# Cost Optimization Decisions

История решений об оптимизации стоимости deep-research.

---

## [2026-05-10 19:57] Решение: Не оптимизировать

**Контекст:**
- Обсуждение стоимости deep-research для оставшихся 7 P1 агентов
- Оценка: ~$3.50-7.00 за 7 агентов (~$0.50-1.00 за агент)

**Альтернативы рассмотрены:**
1. **Селективный подход** — deep для сложных, standard для типовых, без research для простых
2. **Переиспользование** — одно исследование на похожие агенты (экономия ~50%)
3. **Ручное создание** — без research, только интервью (экономия 100% токенов research)

**Решение:** Не оптимизировать, продолжать использовать deep-research для всех агентов

**Обоснование:**
- Стоимость приемлемая ($0.50-1.00 за агент)
- Качество выше (актуальная статистика, реальные API, лучшие практики)
- Экономия времени 60-70% (с 2-3 часов до 45-60 минут)
- Vault создан для отслеживания стоимости в будущем

**Следующий пересмотр:** Когда накопится статистика по 10+ исследованиям
