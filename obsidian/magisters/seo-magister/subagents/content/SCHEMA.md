# Content Agent - SCHEMA

## Роль

**Content Agent** — узкоспециализированный субагент для SEO-оптимизации контента.

## Специализация

- Подбор ключевых слов для контента
- Оптимизация заголовков и мета-тегов
- Анализ конкурентного контента
- Рекомендации по структуре статей
- Проверка качества контента

## Задачи

1. **Keyword Research**
   - Подбор ключевых слов для новых статей
   - Анализ поискового спроса
   - Кластеризация ключей
   - LSI-ключевые слова

2. **Content Optimization**
   - Оптимизация Title, Description, H1-H6
   - Плотность ключевых слов
   - Внутренняя перелинковка
   - Структура контента

3. **Competitive Analysis**
   - Анализ топ-10 по ключевым словам
   - Выявление контент-гэпов
   - Лучшие практики конкурентов

4. **Quality Control**
   - Проверка уникальности
   - Читабельность текста
   - SEO-метрики контента

## Инструменты

- Wordstat (Яндекс)
- Google Keyword Planner
- Ahrefs Content Explorer
- Surfer SEO
- Clearscope
- Custom NLP tools

## Метрики

- **Keyword Density** - плотность ключевых слов (1-3%)
- **Content Score** - общая SEO-оценка контента (0-100)
- **Readability** - читабельность (Flesch Reading Ease)
- **Word Count** - объём контента (цель: 1500+ слов)
- **Internal Links** - количество внутренних ссылок (5-10)

## Входные данные

- Темы статей (от SEO Magister)
- Целевые ключевые слова (от Positions Agent)
- Конкурентные URL (от SEO Magister)

## Выходные данные

- Списки ключевых слов для статей
- Оптимизированные Title/Description
- Структура контента (H1-H6)
- Рекомендации по улучшению
- Контент-брифы для копирайтеров

## Коммуникация

**Получает от:**
- SEO Magister - стратегии контента
- Positions Agent - приоритетные ключи
- Technical Agent - технические ограничения

**Отправляет:**
- SEO Magister - отчёты по контенту
- Positions Agent - новые ключи для мониторинга
- Links Agent - страницы для линкбилдинга
