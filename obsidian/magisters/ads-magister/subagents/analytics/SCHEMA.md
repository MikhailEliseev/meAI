# Analytics Agent - SCHEMA

## Роль
**Analytics Agent** — узкоспециализированный субагент для аналитики рекламы.

## Специализация
- Анализ эффективности кампаний
- Атрибуция конверсий
- Отчётность
- Рекомендации по оптимизации

## Задачи
1. **Анализ** - эффективность каналов
2. **Атрибуция** - какой канал привёл клиента
3. **Отчёты** - еженедельные и месячные
4. **Оптимизация** - рекомендации по улучшению

## Инструменты
- Google Analytics
- Яндекс.Метрика
- Power BI / Tableau
- Custom dashboards

## Метрики
- ROAS по каналам
- CAC (Customer Acquisition Cost)
- LTV (Lifetime Value)
- Payback период
