Просканировано 5 страниц сайта. Ключевые находки:

  • ✅ robots.txt настроен и доступен

  • ✅ Viewport мета-тег на всех страницах
  • ✅ JSON-LD структурированные данные (MedicalOrganization, WebSite, BreadcrumbList)
  • ✅ Canonical URL на всех внутренних страницах

Критические проблемы

📍 Изображения без alt-тегов (1% покрытие)

На главной странице — 96 изображений, из них только 1 с alt-тегом. Это означает 95 неописанных картинок. Для клиники, где «до/после» — главный контент, это потеря трафика из Google Images и Yandex.Images. Каждый пациент, ищущий «абдоминопластика до после Москва», проходит мимо ИПХиК.

📍 Отсутствие Open Graph тегов

На всех 5 страницах OG-title, OG-description, OG-image — пусты. При репосте ссылок в Telegram, VK, WhatsApp — нет превью с фотографией клиники или врача. Ссылка выглядит как голый текст. Каждый такой репост — упущенный пациент.

📍 Короткие title на внутренних страницах

  • «Отделения» — 9 символов
  • «Наши врачи» — 10 символов

Яндекс и Google используют title как главный сигнал релевантности. Заголовок «Отделения» не говорит ни о чём — ни города, ни клиники, ни специализации. Конкуренты с полными заголовками (например, «Отделения пластической хирургии в Москве | ИПХиК») будут ранжироваться выше.

📍 Переполненный meta description на странице отделения

Длина — 302 символа при норме 150-160. Яндекс обрежет текст, и пациент увидит обрубленную фразу. Это снижает кликабельность (CTR) в поисковой выдаче.

📍 Нет llms.txt и ai.txt

ИПХиК не подготовлен к AI-поиску. При запросе ChatGPT/Perplexity «лучшая клиника пластической хирургии Москва» — ИПХиК будет опираться только на общие данные из интернета, а не на структурированный файл с УТП клиники.

06 — Ключевые находки

1. SEO: 95% изображений без alt-тегов = невидимость в Google Images

На главной странице 96 картинок, описание имеет только 1. Для ниши пластической хирургии, где визуальный контент (до/после, результаты операций) — главный магнит для пациентов — это прямая потеря трафика.

2. Open Graph теги полностью отсутствуют

Ни на одной из 5 проверенных страниц нет OG-title, OG-description, OG-image. Каждый репост в мессенджеры — потерянная возможность показа клиники с лицом.

3. Instagram-присутствие: 1 из 22 врачей

В нише пластической хирургии Instagram — ключевой канал привлечения. Один аккаунт с 521 подписчиком при 22 врачах — это не канал, а формальность.

4. Медийный разрыв: 3 упоминания за 8 лет

Для института с 88-летней историей — 3 упоминания в целевых СМИ за 8 лет недостаточно. Конкуренты активно цитируются в Forbes, RBC, Vademecum ежегодно.

5. Нет llms.txt — не готовы к AI-поиску

Когда пациент спрашивает ChatGPT «какую клинику пластической хирургии выбрать в Москве» — ИПХиК опирается только на общедоступные данные, а не на структурированный файл, который клиника могла бы контролировать.

07 — Рекомендации (по приоритету)

🔴 Срочно (1-2 недели)

1. Alt-теги для изображений

Несмотря на техническую простоту — это 95 «невидимых» изображений на главной. Заполнять: название операции, часть тела, «до/после». Это сразу откроет трафик из Google/Yandex Images.

2. Open Graph теги

Внедрить OG-title, OG-description, OG-image на всех страницах. Срок: 1 день при наличии CMS-доступа. Эффект: каждый репост ссылки — с красивой карточкой клиники.

3. Мeta-теги на внутренних страницах

Заполнить title и description для /department/, /specialists/, /price/. Добавить город и название клиники.

🟡 Стратегически (1-3 месяца)

4. Instagram для ключевых врачей

Минимум 3-5 врачей должны вести Instagram с регулярным контентом: до/после, ответы на вопросы, рассказы об операциях. Формат: Reels (15-30 сек), Stories (ежедневно). Целевая аудитория каждого аккаунта: 5-20K подписчиков за 6 месяцев.

5. llms.txt для AI-поиска

Создать структурированный файл с описанием клиники, услуг, врачей, лицензий. Это позволит ChatGPT и Perplexity корректно рекомендовать ИПХиК при поисковых запросах.

6. Медийная стратегия

Установить ритм публикаций: минимум 1 экспертная статья в RBC/Vademecum/Forbes в квартал. Темы: инновации в пластической хирургии, результаты операций, тренды рынка.

🟢 Рост (3-6 месяцев)

7. Контентная система для врачей

Контент-план для 5 топ-врачей: 2 поста в неделю, привязанные к сезонности и страхам пациентов. Рубрики: «Мифы о пластике», «Как проходит реабилитация», «Чего боятся пациенты — и как мы решаем».

8. Дзен и Telegram-канал

Дзен — для переупаковки длинного контента. Telegram — для оперативной коммуникации с пациентами. Оба канала на данный момент отсутствуют.
