### 1. OPERATOR ✅
**Файл:** `docs/agents-specs/OPERATOR_SPEC.md`

**Ключевые решения:**
- Operator = Project Manager агентства
- Создаёт папки клиентов и проектов
- Иерархия: Клиент → Проект → Агенты
- Сохраняет весь контекст (встречи, emails, письма)
- Недельные спринты (точка А → точка Б)
- Дашборд для клиентов и владельца
- Telegram-бот для постановки задач и отчётов

**Magisters роль:**
- Magisters = Учителя и контролёры качества (НЕ исполнители!)
- Получают знания от Teacher Agent
- Обучают Orchestrators и Subagents
- Контролируют качество работы своего направления

**Operator умный:**
- Сам выстраивает цепочки зависимостей
- Использует шаблоны для типовых задач
- Пример: "Запусти услугу" → CustDev → Market Research → SEO → Content → Ads → Analytics

**Дашборд:**
- Web-приложение (в будущем)
- Сейчас фокус на Backend, логику, Magisters

### 2. SEO MAGISTER ✅
**Файл:** `docs/agents-specs/SEO_MAGISTER_SPEC.md`

**Ключевые решения:**

**Источники знаний:**
- Clipper + Inbox система (владелец закидывает материалы)
- Gatekeeper анализирует и направляет к нужному Magister
- Perplexity исследования (Researcher)
- Мониторинг новостей SEO
- База знаний из собственных проектов

**Критерии качества:**
- Рост позиций (поисковики, гео-сервисы, нейросети)
- Рост трафика
- Рост заявок
- Снижение CAC с SEO-канала

**Еженедельный контроль:**
- Сколько текстов написано?
- Проиндексированы ли?
- Ведут ли трафик?
- Делают ли продажи?

**GEO Orchestrator:**
- На уровне с SEO Orchestrator (работают в паре!)
- Оптимизация под нейросети (ChatGPT, Perplexity, Claude)
- Мониторинг выдачи в AI

**Медицинская специфика:**
- Medical Fact-Checker Agent (обязательно!)
- Утверждение у доктора (два режима: строгий → расслабленный)
- Только академические источники (Perplexity, PubMed, Google Scholar)
- Законодательство РФ по медицинской рекламе

**Глубина анализа:**
- Только FULL (полный анализ)
- Качество > Скорость
- Время не важно, важна идеальность

### 3. CONTENT MAGISTER ✅
**Файл:** `docs/agents-specs/CONTENT_MAGISTER_SPEC.md`

**Ключевые решения:**

**Роль:**
- Content Magister отвечает за СМЫСЛ (не за формат!)
- Контент = любой текст (Reels, SEO, статья, email, etc.)
- На основе смысла → контент для любого носителя

**Инструкции:**
- Чёткие инструкции для КАЖДОГО типа контента
- Как писать Reels, SEO-тексты, лендинги, баннеры, emails, скрипты для колл-центра, YouTube, Telegram, VK, листовки

**Обучение:**
- Психография ЦА (как достучаться?)
- Фреймворки: AIDA, PAS, BAB, 4P, Storytelling
- Распределение смыслов по носителям (листовка 30 сек → YouTube 30 мин)
- Tone of Voice (от Brand Magister)

**Tone of Voice:**
- Brand Magister → CustDev → Сегментация ЦА → ToV для каждого сегмента
- Content Magister → получает ToV → обучает Subagents
- Контроль соблюдения ToV (еженедельно)

**Медицинская экспертность:**
- Medical Fact-Checker Subagent
- Два режима: строгий (начало) → расслабленный (доверие)
- Академические источники → простой язык для ЦА
- Всегда утверждение у доктора (режим 1)

**Критерии качества:**
- Опираться на статистику
- Анализ успешного контента (что "залетело"?)
- Выявление паттернов
- База знаний успешных кейсов

**Subagents по типам:**
- Reels Script Writer
- SEO Content Writer
- Blog Article Writer
- YouTube Script Writer
- Email Writer
- Telegram/VK Post Writer
- Landing Page Writer
- Banner Copy Writer
- Call Center Script Writer
- Leaflet Writer
- + Content Editor

- + SEO Content Optimizer

### 4. ADS MAGISTER ✅
**Файл:** `docs/agents-specs/ADS_MAGISTER_SPEC.md`

**Ключевые решения:**

**Роль:**
- Оптимизатор перформанс-каналов
- Привлечение трафика → Анализ → Выводы → Корректировка → Улучшение

**Обучение:**
- Оптимизация бюджетов (перераспределение на основе эффективности)
- Конверсионные объявления (высокий CTR + продажи, не обещать лишнего)
- Квас-квасная аналитика (деньги с каждого объявления/ключевого слова)
- Тестирование гипотез (основа перформанса!)

**Главная метрика:**
- Получить большее количество квалифицированных клиентов за меньшие деньги

**Критерии качества:**
- Адекватность объявлений (не обещать лишнего)
- Эффективность трафика
- Конверсия в клиентов
- Финансовая эффективность (ROMI)

**Платформы:**
- Яндекс Директ (основная)
- VK Реклама
- Telegram Ads
- Другие (нужно исследовать)
- Google Ads (не работает в РФ)

**Ограничения медицины:**
- Есть, но обходятся (лицензия медорганизации)

**Тестирование:**
- Все типы кампаний = гипотезы
- Тестируем: объявления, заголовки, креативы, каналы, аудитории, ставки
- Выделяем бюджет → смотрим → расширяем или закрываем

**Оптимизация бюджета:**
- Приоритизация по маржинальности (вместе с клиентом)
- Динамическая оптимизация (автоматическая!)
- Если сливается → выключаем автоматически
- Если эффективно → увеличиваем бюджет

**Автоматическая корректировка:**
- ОБЯЗАТЕЛЬНА!
- Перформанс = самый дорогой канал
- Нельзя терять деньги

**Частота:**
- Сбор данных: ежедневно
- Анализ и выводы: еженедельно

**Subagents:**
- Campaign Creator Agent
- Budget Optimizer Agent
- A/B Testing Agent
- Audience Targeting Agent
- Creative Generator Agent (NEW! - статичные баннеры)
- Campaign Analyzer Agent (NEW! - квас-квасная аналитика)
- Auto-Optimizer Agent (NEW! - автоматическая корректировка)

**Задача:**
- Провести глубокое исследование перформанса
- Как строится, метрики, практики, кейсы

## 🔑 КЛЮЧЕВЫЕ РЕШЕНИЯ

### 1. Архитектура обучения:

```
Teacher Agent (собирает знания от Architect)
    ↓
Magisters (обучают и контролируют качество)
    ↓
Orchestrators (координируют выполнение)
    ↓
Subagents (конкретные исполнители)
```

### 2. Роль Magisters:
- ❌ НЕ исполняют задачи сами
- ✅ Обучают Orchestrators и Subagents
- ✅ Следят за качеством работы своего направления
- ✅ Получают знания от Teacher Agent
- ✅ Сортируют информацию в свой Obsidian vault

### 3. Operator умный:
- Сам выстраивает цепочки зависимостей
- Использует шаблоны для типовых задач
- Понимает бизнес-логику

### 4. Clipper + Inbox система:
- Владелец/Researcher → Clipper → Inbox
- Gatekeeper анализирует и направляет к Magister
- Magister решает: применяли? стоит попробовать? взять в работу?

### 5. Медицинская специфика:
- Medical Fact-Checker Agent (обязательно!)
- Два режима: строгий (начало) → расслабленный (доверие)
- Академические источники (Perplexity, PubMed, Google Scholar)
- Утверждение у доктора
- Законодательство РФ

### 6. Качество > Скорость:
- Полный анализ (FULL)
- Время не важно
- Важна идеальность результата

### 7. Data-driven подход:
- Все решения на основе метрик
- Еженедельный анализ
- Статистика и выводы

### 8. Недостающие Magisters:
- Brand Magister (CustDev, ToV, позиционирование)
- Reputation Magister (репутация, отзывы, кризисы)
