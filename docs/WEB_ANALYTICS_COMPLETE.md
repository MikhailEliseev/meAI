## 🎯 Ключевые особенности агента

### Роль
**Web Analytics Agent** — главный аналитик системы, который собирает метрики со всех счётчиков и источников.

### Уникальная ценность
- **Данные = основа решений** — без аналитики невозможно понять, куда двигаться
- **Отслеживание динамики** — видим изменения день за днём
- **Источники трафика** — понимаем, откуда приходят пациенты
- **Конверсии и результаты** — отслеживаем цели и конверсии
- **Единый источник правды** — все метрики в одном месте

### Критичность
⭐⭐⭐⭐ **P1 (Важный)** — данные = основа для всех решений в SEO стратегии.

## 🔧 Технические детали

### Алгоритм работы (5 шагов)
1. Сбор данных со всех источников (Яндекс Метрика, Google Analytics, опционально Вебмастер и Search Console)
2. Усреднение данных (если есть расхождения между источниками)
3. Отслеживание отклонений (аномалии, резкие изменения)
4. Проверка ошибок получения (API недоступны, данные неполные)
5. Передача данных дальше (на анализ верхнего уровня — SEO Magister)

### Источники данных

**Обязательные:**
- **Яндекс Метрика** — трафик, источники, конверсии, поведение
- **Google Analytics** — сессии, пользователи, цели, e-commerce

**Опциональные:**
- **Яндекс Вебмастер** — запросы, позиции в выдаче Яндекса
- **Google Search Console** — клики, показы, позиции в Google

### Особенности
- **Множественные источники** — данные из 2+ обязательных + 2 опциональных источников
- **Усреднение данных** — при расхождениях < 50% между источниками
- **Отслеживание аномалий** — резкие изменения > 20%
- **Сырые данные** — возвращает цифры в сыром виде, без выводов
- **Graceful degradation** — работает даже если один источник недоступен

## 🔄 Что возвращает агент

**Результат:**
- Метрики день за днём (визиты, пользователи, просмотры, отказы, конверсии)
- Исходные данные от каждого источника (для аудита)
- Аномалии (резкие изменения)
- Качество данных (доступность источников, расхождения)
- Сводка (итоговые показатели)

## 🚨 Специфичные ошибки

**API_UNAVAILABLE:**
- Яндекс Метрика или Google Analytics недоступны
- Retry с exponential backoff (10 попыток)
- Graceful degradation (продолжить с другими источниками)

**DATA_QUALITY_ISSUE:**
- Расхождения > 50% между источниками
- Флаг `large_discrepancy`, сохранение обоих значений
- Partial success

**RATE_LIMIT_EXCEEDED:**
- Превышен лимит запросов к API
- Подождать до сброса лимита → retry

## 📚 Границы ответственности

**Что делает агент:**
- ✅ Собирает метрики из Яндекс Метрики и Google Analytics
- ✅ Собирает данные из Яндекс Вебмастера и Google Search Console (опционально)
- ✅ Отслеживает отклонения и аномалии
- ✅ Усредняет данные при расхождениях между источниками
- ✅ Передаёт данные в сыром виде (цифры день за днём)
- ✅ Сохраняет историю метрик в БД и Obsidian

**Что НЕ делает агент:**
- ❌ Не делает выводы и рекомендации (это задача SEO Magister)
- ❌ Не имплементирует изменения (это задача других агентов)
- ❌ Не строит прогнозы (это задача аналитических агентов верхнего уровня)
- ❌ Не создаёт отчёты (это задача Report Generator Agent)
