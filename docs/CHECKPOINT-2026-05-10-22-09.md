## 🔧 TROUBLESHOOTING

### Если Exa MCP не загрузился

**Проверь конфигурацию:**
```bash
cat ~/.claude.json | grep -A 10 exa
```

Должно быть:
```json
"exa": {
  "transport": "http",
  "url": "https://mcp.exa.ai/mcp?tools=web_search_exa,deep_researcher_start,deep_researcher_check"
}
```

**Переустанови MCP:**
```bash
claude mcp remove exa
claude mcp add --transport http exa 'https://mcp.exa.ai/mcp?tools=web_search_exa,deep_researcher_start,deep_researcher_check'
```

### Если OAuth не открывается

При первом запросе к Exa должен открыться браузер для авторизации. Если не открылся:
1. Проверь, что браузер по умолчанию настроен
2. Попробуй вручную: https://dashboard.exa.ai

### Если deep-research всё ещё падает

Проверь логи:
```bash
tail -f ~/Documents/[Topic]_Research_[YYYYMMDD]/run_manifest.json
```

Если 503 ошибки продолжаются → проблема в rate limits Anthropic API, не в Exa.
