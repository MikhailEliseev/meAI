#### 1. Синтетический CustDev ⭐⭐⭐⭐⭐

**Инструмент:** Advanced JTBD Customer Development Platform  
**Локация:** `/Users/mikhaileliseev/Desktop/Dev/AI CustDev от Елисеева`  
**Статус:** ✅ v1.2 - Production Ready

**Что это:**
- AI-платформа для интервью с AI-аватарами
- Методология Advanced JTBD от Вани Замесина
- 165+ детальных аватаров с когнитивными биасами

**Ключевые возможности:**
- **14 AJTBD вопросов** в 6 блоках (quick/standard/deep)
- **Jobs Graph** - визуализация работ пользователя
- **RAT Analysis** - Top-5 рисков с P×I scoring
- **Activating Knowledge** - готовые фразы для маркетинга ⭐⭐⭐

**API интеграция:**

```bash
# Создать интервью
POST /api/interviews
{
  "project_id": "uuid",
  "avatar_ids": ["avatar_001", "avatar_002"],
  "mode": "problem_discovery",
  "depth": "standard"
}

# Сгенерировать аналитику
POST /api/analytics/analyze
{
  "project_id": "uuid",
  "interview_ids": ["int_1", "int_2"]
}

# Получить результаты
GET /api/analytics/{project_id}
```

**Что получаем:**
- `ajtbd_segments` - сегменты с Core Jobs и Big Job → **для ToV**
- `rat_analysis` - Top-5 рисков
- `jobs_graph` - граф работ пользователя
- `activating_knowledge` - фразы для маркетинга → **для Content Magister**
