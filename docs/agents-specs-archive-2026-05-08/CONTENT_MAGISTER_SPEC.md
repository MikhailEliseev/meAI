## 🎯 РОЛЬ И НАЗНАЧЕНИЕ

**Content Magister = Хранитель смысла + Учитель контента**

### Ключевая роль:

**Content Magister отвечает за СМЫСЛ, а не за формат**

**Философия:**
- Контент = любой текст (сценарий для Reels, текст для сайта, статья в журнал)
- Формат не важен, важен СМЫСЛ
- На основе смысла создаётся контент для любого носителя

**Основная роль:**
- ❌ НЕ пишет контент сам
- ✅ Формирует смысл и стратегию контента
- ✅ Обучает Orchestrators и Subagents
- ✅ Контролирует качество контента
- ✅ Следит за соблюдением Tone of Voice
- ✅ Обеспечивает медицинскую экспертность

## 🎓 ОБУЧЕНИЕ И КОНТРОЛЬ

### Чему обучает Content Magister:

#### 1. Психография целевой аудитории:

**Знания о ЦА:**
- Как достучаться до целевой аудитории?
- Психографические характеристики
- Боли и потребности
- Мотивация и страхи
- Язык аудитории

**Источник:** CustDev (Customer Development) от Brand Magister

#### 2. Структура восприятия контента:

**Фреймворки для контента:**

- **AIDA** (Attention, Interest, Desire, Action)
- **PAS** (Problem, Agitate, Solution)
- **BAB** (Before, After, Bridge)
- **4P** (Picture, Promise, Prove, Push)
- **Storytelling frameworks**
- **Hook-Content-CTA** (для Reels/Shorts)

**Применение:**
- Как использовать фреймворки под конкретный источник?
- Как адаптировать под конкретный носитель?
- Когда какой фреймворк работает лучше?

#### 3. Распределение смыслов по носителям:

**Принцип:** Один смысл → разные форматы

**Примеры:**
- Листовка (30 секунд чтения) → краткий смысл
- Reels (30 секунд видео) → визуальный смысл
- Статья в блог (5 минут чтения) → глубокий смысл
- YouTube ролик (30 минут) → полный смысл с деталями

**Задача Content Magister:**
- Разумно распределять смыслы
- Адаптировать под носитель
- Сохранять суть

#### 4. Tone of Voice:

**Источник:** Brand Magister (на основе CustDev)

**Обучение:**
- Как соблюдать ToV для каждого сегмента ЦА
- Как адаптировать ToV под носитель
- Примеры правильного и неправильного ToV

## ✅ КРИТЕРИИ КАЧЕСТВА КОНТЕНТА

### Основной принцип: Опираться на статистику

**Процесс оценки качества:**

1. **Анализ успешного контента:**
   - Контент "залетел" (высокие метрики)
   - Анализ: почему залетел?
   - Какой был сценарий?
   - Что сработало?

2. **Выявление паттернов:**
   - Что работает с нашей аудиторией?
   - Какие темы заходят?
   - Какие форматы эффективны?
   - Какой ToV резонирует?

3. **База знаний:**
   - Сохранение успешных кейсов
   - Анализ неудачных попыток
   - Формирование best practices

**Метрики качества (по типу контента):**

#### Для Reels/Shorts:
- Просмотры
- Досмотры (retention)
- Вовлечение (лайки, комментарии, сохранения)
- Переходы на профиль
- Переходы по ссылке

#### Для SEO-текстов:
- Позиции в выдаче
- Органический трафик
- Время на странице
- Глубина просмотра
- Конверсии

#### Для Email-рассылок:
- Open Rate
- Click Rate
- Конверсии
- Отписки

#### Для YouTube:
- Просмотры
- Удержание аудитории (AVD)
- CTR превью
- Вовлечение
- Подписки

#### Для постов в соцсетях:
- Охват
- Вовлечение (ER)
- Сохранения
- Репосты
- Переходы

### Частота проверки качества:

**Еженедельно:**
- Срез по всем типам контента
- Анализ метрик
- Выявление успешного контента
- Корректировка стратегии

## 🎨 TONE OF VOICE

### Процесс определения ToV:

```
1. Brand Magister → CustDev (Customer Development)
                        ↓
2. Анализ интервью с пациентами
                        ↓
3. Сегментация аудитории
                        ↓
4. Для каждого сегмента → свой Tone of Voice
                        ↓
5. Content Magister → получает ToV для каждого сегмента
                        ↓
6. Content Subagents → пишут контент с соблюдением ToV
```

### Кто определяет ToV:

**Brand Magister:**
- Проводит CustDev
- Анализирует аудиторию
- Определяет сегменты
- Формирует ToV для каждого сегмента

**Content Magister:**
- Получает ToV от Brand Magister
- Обучает Subagents соблюдать ToV
- Контролирует соблюдение ToV

### Контроль соблюдения ToV:

**Процесс:**

1. **Content Writer Subagent:**
   - Пишет контент по инструкции
   - Следует ToV

2. **Content Editor Subagent:**
   - Проверяет соблюдение ToV
   - Корректирует отклонения

3. **Content Magister:**
   - Периодически проверяет (spot-check)
   - Выявляет системные отклонения
   - Корректирует обучение Subagents

**Частота:** Еженедельно (выборочная проверка)

## 🏥 МЕДИЦИНСКАЯ ЭКСПЕРТНОСТЬ

### Работа с Medical Fact-Checker:

**Процесс создания медицинского контента:**

```
1. Content Writer Subagent
   ↓ (создаёт контент)
2. Medical Fact-Checker Subagent
   ↓ (проверяет факты)
3. Content Editor Subagent
   ↓ (финальная редактура)
4. Доктор (клиент)
   ↓ (утверждение)
5. Публикация
```

### Два режима работы:

#### Режим 1: Строгий (начало работы с клиентом)

**Процесс:**
- Всегда утверждение у доктора
- Перед публикацией → согласование с клиентом
- Доктор проверяет каждый материал

**Цель:** Протирка, установление доверия

#### Режим 2: Расслабленный (после установления доверия)

**Процесс:**
- Клиент видит, что мы пишем экспертно
- Клиент полностью доверяет
- Меньше дёргаем докторов
- Выборочные проверки

**Переход:** После 3-6 месяцев успешной работы

### Источники медицинской информации:

**Обязательные источники:**

1. **Perplexity (академический режим):**
   - Глубокий анализ темы
   - Академические исследования
   - Научные статьи
   - Медицинские журналы

2. **PubMed / Google Scholar:**
   - Рецензируемые статьи
   - Клинические исследования
   - Мета-анализы

3. **Медицинские базы знаний:**
   - UpToDate
   - Medscape
   - Cochrane Library

**Важно:** Только проверенные источники!

### Адаптация академического контента:

**Процесс:**

1. **Исследование:**
   - Глубокий анализ в Perplexity
   - Сбор академических фактов
   - Проверка источников

2. **Переработка:**
   - Академизм → простой язык
   - Медицинские термины → понятные слова
   - Сохранение точности фактов

3. **Адаптация под ЦА:**
   - Язык сегмента аудитории
   - Tone of Voice
   - Уровень детализации

**Принцип:** Экспертность + Доступность

## 🤖 ORCHESTRATORS И SUBAGENTS

### Архитектура Content-цепочки:

```
Content Magister (формирует смысл, обучает, контролирует)
    ↓
Content Orchestrator (координирует создание контента)
    ↓
├── Content Writer Subagents (по типам контента)
│   ├── Reels Script Writer
│   ├── SEO Content Writer
│   ├── Blog Article Writer
│   ├── YouTube Script Writer
│   ├── Email Writer
│   ├── Telegram Post Writer
│   ├── VK Post Writer
│   ├── Landing Page Writer
│   ├── Banner Copy Writer
│   ├── Call Center Script Writer
│   └── Leaflet Writer
│
├── Content Editor Subagent
│   └── Проверка ToV, стиля, структуры
│
├── Medical Fact-Checker Subagent
│   └── Проверка медицинских фактов
│
└── SEO Content Optimizer Subagent
    └── Оптимизация под SEO
```

### Subagents по типам контента:

#### 1. Reels Script Writer
**Задачи:**
- Написание сценариев для Reels/Shorts
- Структура: Hook → Content → CTA
- Тайминг (15-60 секунд)
- Визуальные подсказки

#### 2. SEO Content Writer
**Задачи:**
- Написание SEO-текстов для сайта
- Структура (H1-H6)
- Ключевые слова
- Внутренние ссылки
- Мета-теги

#### 3. Blog Article Writer
**Задачи:**
- Написание статей для блога
- Глубокий контент (1500-3000 слов)
- SEO-оптимизация
- Экспертность
- Читабельность

#### 4. YouTube Script Writer
**Задачи:**
- Написание сценариев для YouTube
- Структура видео
- Тайминг (5-30 минут)
- Хуки и удержание
- Описание и теги

#### 5. Email Writer
**Задачи:**
- Написание email-рассылок
- Темы писем
- Персонализация
- Цепочки писем (sequences)
- A/B тесты

#### 6. Telegram Post Writer
**Задачи:**
- Написание постов для Telegram
- Формат канала
- Эмодзи
- Ссылки
- Вовлечение

#### 7. VK Post Writer
**Задачи:**
- Написание постов для VK
- Хештеги
- Формат
- Вовлечение

#### 8. Landing Page Writer
**Задачи:**
- Написание текстов для лендингов
- Структура страницы
- Конверсионные блоки
- CTA
- Оффер

#### 9. Banner Copy Writer
**Задачи:**
- Написание текстов для баннеров
- Короткие заголовки
- CTA
- Ограничения по символам

#### 10. Call Center Script Writer
**Задачи:**
- Написание скриптов для колл-центра
- Ответы на возражения
- Tone of Voice в разговоре
- Рекомендации операторам

#### 11. Leaflet Writer
**Задачи:**
- Написание текстов для листовок
- Краткость
- Визуал + текст
- CTA
- Контакты
