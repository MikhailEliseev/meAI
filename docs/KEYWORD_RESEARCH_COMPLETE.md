## 🎯 Ключевые особенности агента

### Роль
**Keyword Research Agent** — подборщик ключевых слов для роста органического трафика сайта.

### Уникальная ценность
- **Фундамент SEO стратегии** — без ключевых слов невозможно построить SEO
- **Привлечение платежеспособного трафика** — органический трафик = бесплатный и качественный
- **Видимость в поиске** — показывает, как сайт находится в поисковых системах
- **Конкурентное преимущество** — анализ конкурентов, поиск незанятых ниш
- **Данные для принятия решений** — объективные метрики для приоритизации

### Критичность
⭐⭐⭐⭐ **P1 (Важный)** — SEO — один из основных каналов привлечения платежеспособного трафика из поиска.

## 🔧 Технические детали

### Алгоритм работы (5 шагов)
1. Сбор данных из источников (Яндекс Вордстат, Google Keyword Planner, Метрика, Analytics)
2. Анализ ключевых слов по параметрам (спрос, конкуренция, сезонность)
3. Анализ текущих позиций сайта
4. Генерация рекомендаций (Title, Description, H1, текст)
5. Сохранение результатов (БД + Obsidian)

### Источники данных

**Обязательные:**
- **Яндекс Вордстат** — частотность, сезонность
- **Google Keyword Planner** — объём поиска, конкуренция
- **Яндекс Метрика** — реальный трафик
- **Google Analytics** — реальный трафик
- **Сбор позиций** — текущие позиции сайта

**Опциональные:**
- **Semrush API** — конкурентный анализ
- **TopVisor API** — мониторинг позиций
- **Ahrefs API** — анализ конкурентов

### Особенности
- **Множественные источники** — данные из 5+ источников
- **Приоритизация** — высокий/средний/низкий потенциал
- **Группировка по темам** — ключевые слова группируются по страницам
- **Рекомендации** — конкретные указания, куда включить ключевые слова
- **Graceful degradation** — работает даже если один источник недоступен

## 🚨 Специфичные ошибки

**RATE_LIMIT_EXCEEDED:**
- Превышен лимит запросов к API
- Подождать до сброса лимита → retry

**NO_DATA_AVAILABLE:**
- Нет данных для анализа (новый сайт)
- Вернуть success с пустым результатом

**INVALID_TOKEN:**
- Неверный токен API
- Эскалация → User (нужно обновить токен)
