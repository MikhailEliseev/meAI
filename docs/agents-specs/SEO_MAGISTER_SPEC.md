## 📚 ИСТОЧНИКИ ЗНАНИЙ

### 1. Clipper + Inbox система:

**Процесс получения знаний:**

```
Владелец/Researcher → Clipper → Inbox
                                   ↓
                              Gatekeeper (анализирует)
                                   ↓
                         Определяет тему (SEO)
                                   ↓
                            SEO Magister
                                   ↓
                    Анализирует и принимает решение:
                    - Что применяли? (опыт)
                    - Что не применяли? (стоит попробовать)
                    - Что интересно? (взять в работу)
```

**Источники в Inbox:**
- Интервью экспертов (закинул владелец)
- Исследования из Perplexity (запустил Researcher)
- Ссылки из Clipper (владелец нашёл что-то интересное)
- Best practices из мира SEO

**Роль Gatekeeper:**
- Анализирует контент из Inbox
- Определяет, к какому Magister относится
- Решает: брать в работу или нет
- Направляет к нужному Magister

### 2. Мониторинг новостей:

**Обязательно отслеживать:**
- Изменения алгоритмов поисковиков (Google, Yandex, Bing)
- Новости SEO-индустрии
- Обновления поисковых систем
- Тренды в SEO

**Реакция на новости:**
- Анализ: как это влияет на наши проекты?
- Корректировка стратегии
- Обновление знаний Subagents
- Внедрение новых практик

### 3. База знаний из собственных проектов:

**Что собирать:**
- ✅ Что получилось (успешные кейсы)
- ❌ Что не получилось (неудачные попытки)
- 📊 Метрики результатов
- 💡 Инсайты и выводы
- 🔄 Как применить на следующих проектах

**Принцип:** Учиться на своём опыте

### 4. Актуальные практики:

**Считаются актуальными:**
- ✅ Практики из рабочих кейсов (найденные Researcher в Perplexity)
- ✅ Практики, закинутые владельцем в Inbox
- ✅ Практики, которые дали результат на наших проектах
- ❌ Устаревшие практики отбрасываются

## 🎯 ОБУЧЕНИЕ И КОНТРОЛЬ

### Чему обучает SEO Magister:

1. **Best practices SEO:**
   - Актуальные техники оптимизации
   - Работа с алгоритмами поисковиков
   - Контент-стратегии
   - Техническая оптимизация

2. **Опыт из проектов:**
   - Что работает в медицинском маркетинге
   - Что не работает (избегать)
   - Специфика ниши

3. **Новые знания:**
   - Из Inbox (после анализа Gatekeeper)
   - Из новостей индустрии
   - Из исследований

### Критерии качества SEO-работы:

**Основные метрики:**

1. **Рост позиций:**
   - В поисковых системах (Google, Yandex, Bing)
   - В гео-сервисах (Google Maps, Yandex Maps)
   - В выдаче нейросетей (ChatGPT, Perplexity, etc.)

2. **Рост трафика:**
   - Органический трафик с поисковиков
   - Трафик с гео-сервисов
   - Трафик из нейросетей

3. **Рост заявок:**
   - Количество лидов с SEO-канала
   - Качество лидов (квалифицированные)

4. **Снижение стоимости пациента:**
   - CAC (Customer Acquisition Cost) с SEO-канала
   - Сравнение с другими каналами

### Частота проверки качества:

**Еженедельно (по каждому проекту):**

1. **Контент:**
   - Сколько текстов написано?
   - Проиндексированы ли они?
   - Ведут ли трафик?
   - Делают ли продажи?

2. **Позиции:**
   - Изменения в выдаче
   - Новые запросы в топе
   - Потерянные позиции

3. **Трафик:**
   - Динамика органического трафика
   - Источники трафика
   - Поведенческие метрики

4. **Конверсии:**
   - Лиды с SEO
   - Стоимость лида
   - Качество лидов

## 🤖 ORCHESTRATORS И SUBAGENTS

### Архитектура SEO-цепочки:

```
SEO Magister (обучает и контролирует)
    ↓
SEO Orchestrator (координирует)
    ↓
├── Keyword Research Agent
├── Content Optimizer Agent
├── Technical SEO Agent
├── Link Building Agent
├── GEO Orchestrator (на уровне с SEO Orchestrator!)
│   ├── GEO Optimization Agent
│   ├── GEO Monitoring Agent
│   └── GEO Content Agent
├── Web Analytics Agent
└── Search Console Agent
```

### Subagents под SEO Orchestrator:

#### 1. Keyword Research Agent
**Задачи:**
- Подбор ключевых слов
- Анализ конкурентов по запросам
- Кластеризация запросов
- Оценка потенциала запросов

#### 2. Content Optimizer Agent
**Задачи:**
- Оптимизация текстов под SEO
- Проверка плотности ключевых слов
- Структура контента (H1-H6)
- Мета-теги (title, description)
- Внутренняя перелинковка

#### 3. Technical SEO Agent
**Задачи:**
- Скорость загрузки страниц
- Оптимизация сайта (Core Web Vitals)
- robots.txt проверка
- Карта сайта (sitemap.xml)
- Индексация страниц
- Мобильная версия
- HTTPS
- Структурированные данные (Schema.org)

#### 4. Link Building Agent
**Задачи:**
- Анализ ссылочной массы
- Поиск площадок для размещения
- Мониторинг обратных ссылок
- Анкор-лист
- Disavow токсичных ссылок

#### 5. Web Analytics Agent
**Задачи:**
- Связь с Google Analytics / Yandex Metrica
- Отслеживание трафика по каналам
- Анализ поведения пользователей
- Воронки конверсии
- Цели и события

#### 6. Search Console Agent
**Задачи:**
- Связь с Google Search Console
- Связь с Yandex Webmaster
- Связь с Bing Webmaster Tools
- Получение данных о позициях
- Анализ ошибок индексации
- Мониторинг покрытия
- Выдача рекомендаций

### GEO Orchestrator (отдельная ветка!):

**Важно:** GEO Orchestrator на уровне с SEO Orchestrator, работают в паре!

**Задачи GEO Orchestrator:**
- Оптимизация под нейросети (ChatGPT, Perplexity, Claude, etc.)
- Оптимизация под поисковые системы (Google, Yandex, Bing)
- Мониторинг выдачи в нейросетях
- Анализ цитирований
- Оптимизация контента для AI

**Subagents под GEO Orchestrator:**

#### 1. GEO Optimization Agent
- Оптимизация контента под нейросети
- Структурирование данных для AI
- Цитируемость источников

#### 2. GEO Monitoring Agent
- Мониторинг упоминаний в нейросетях
- Отслеживание позиций в AI-выдаче
- Анализ конкурентов в GEO

#### 3. GEO Content Agent
- Создание контента для нейросетей
- Адаптация существующего контента
- Оптимизация под AI-запросы

**Источники знаний для GEO:**
- Best practices из иностранного рынка
- Кейсы по GEO
- Алгоритмы и механизмы нейросетей
- Новости по GEO-теме

## 🏥 СПЕЦИФИКА МЕДИЦИНСКОГО МАРКЕТИНГА

### Особенности SEO для медицинских клиник:

#### 1. Экспертный контент:

**Требования к контенту:**
- Максимально глубокое изучение медицинской тематики
- Правильность описания процедур
- Точность медицинских рекомендаций
- Экспертность с точки зрения медицины

**Важно:** Дело касается здоровья пациентов!

#### 2. Медицинский факт-чекер:

**Роль:** Subagent для проверки медицинской информации

**Задачи:**
- Перепроверка данных много раз
- Проверка источников
- Валидация медицинских фактов
- Выдача только проверенной информации

**Процесс:**
1. Content Optimizer Agent создаёт текст
2. Medical Fact-Checker Agent проверяет факты
3. Доктор утверждает контент (обязательно!)
4. Только после утверждения → публикация

**Принцип:** Лучше спрашивать доктора и давать на утверждение

#### 3. Законодательные ограничения:

**Обязательно учитывать:**
- Законодательство РФ по рекламе медицинских услуг
- Этические нормы медицинского маркетинга
- Ограничения на рекламу лекарств
- Требования к медицинской информации

**Действие:**
- Найти все законы по рекламе медицинских услуг
- Изучить ограничения
- Двигаться только в рамках законодательства
- Регулярно обновлять знания о законах

#### 4. Ключевые метрики для медицины:

**Специфичные метрики:**

1. **LTV (Lifetime Value):**
   - Сколько пациент ходит к клинике
   - Как долго он ходит
   - Сколько процедур делает
   - Общая ценность пациента

2. **CAC (Customer Acquisition Cost):**
   - Стоимость привлечения пациента
   - По каналам
   - По услугам

3. **Retention Rate:**
   - Возвращаемость пациентов
   - Лояльность
   - Повторные визиты

4. **Качество лидов:**
   - Квалифицированные vs неквалифицированные
   - Конверсия в пациентов
   - Средний чек
