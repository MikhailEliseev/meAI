# AIM Website — Design Spec

**Date:** 2026-06-11
**Status:** Approved
**Stack:** WordPress (кастомная тема) + React-виджет чата

## Overview

Полная перестройка `iamaim.ru` с нуля. Старый Next.js фронтенд (`AIM/frontend/`) удаляется. Новый сайт — кастомная WordPress-тема с встроенным React-чатом Hermes. Максимальный минимализм. Чат — ядро, всё остальное — вспомогательные блоки для SEO и социального доказательства.

## Site Structure

```
iamaim.ru
├── /                    # Главная
├── /blog/               # Блог (GEO-статьи)
├── /blog/{slug}         # Пост
├── /research/{slug}     # Исследование (custom post type)
├── /contact/            # Контакты
```

Удаляемые страницы: `/about`, `/services`, `/case-studies`, `/privacy-policy`, `/analytics`, `/dashboard/*`, все API-роуты Next.js.

## Page Designs

### 1. Главная (`/`)

Секции сверху вниз:

1. **Анимированный текст** — циклическая смена слов: `AIMarketing` → `AIMedicine` → `AIManagement`. Механика: посимвольная замена букв (не бегущая строка). Идея: показать связку AI + M. AI = искусственный интеллект, M = marketing/medicine/management.

2. **Слоган** — «Если вас привёл AI — он приведёт вам пациентов». Точная формулировка будет докручена.

3. **Чат с Hermes** — основной интерактивный блок. Hermes начинает сессию при загрузке страницы. Никаких традиционных CTA-кнопок — чат сам ведёт пресейл-диалог. Технически: React-виджет, собранный как standalone ESM-бандл, подключён через `wp_enqueue_script`, монтируется в `#hermes-chat` div.

4. **Блок основателя** — фото + краткий опыт. Контент предоставит Михаил. Без self-praise, сухо и по делу.

5. **Логотипы клиник** — «Нам доверяют»: ряд логотипов. Только лого, без названий кейсов, описаний, ссылок.

6. **Футер** — контакты, Telegram, телефон, ссылки на /blog и /contact.

### 2. Блог (`/blog`, `/blog/{slug}`)

Стандартные посты WordPress. Категории/теги — медицинский маркетинг, привлечение пациентов, AI в медицине, SEO для клиник. Цель: GEO-индексация, холодный поисковый трафик. Дизайн: минимальный, хорошая типографика, без сайдбаров.

### 3. Исследования (`/research/{slug}`)

Custom post type `research`. Каждое исследование — конкурентная разведка по конкретной клинике. Данные собираются через `/aim-scout`.

Структура страницы динамическая — зависит от того, какие данные собраны:
- Hero: название клиники + ключевые метрики
- Секции: о центре, рынок, эксперты, контент-анализ, СМИ, конкуренты, белые поля, цифровое присутствие, стратегия, оффер
- Навигация по секциям (sticky nav)
- CTA-блок в конце («обсудить», контакт в Telegram)

Формат соответствует примеру `ИПХиК.html`:
- Шрифты: Playfair Display (заголовки) + Inter (текст)
- Light/dark theme toggle
- Декоративные элементы (ripple-кольца)
- Таблицы, карточки, метрики, blockquotes
- Адаптивная вёрстка

### 4. Контакты (`/contact/`)

Минимальная страница: Telegram, телефон, email. Без формы обратной связи — эту роль выполняет чат на главной.

## Technical Approach

### WordPress-тема

- Кастомная тема с нуля, никаких page builders
- `wp-content/themes/aim-theme/`
- Шаблоны: `front-page.php`, `single-research.php`, `single.php`, `page-contact.php`, archive
- Tailwind CSS для стилей (собрать в theme.css)
- Никаких лишних плагинов

### React-чат

- Существующие компоненты (`SalesChat`, `ChatBubble`, `ChatInput`, `EmptyChat`, `ProgressSteps`, хук `useStreamChat`) пакуются как standalone ESM-бандл
- Бандл кладётся в тему (`aim-theme/assets/chat.js`)
- Монтируется в `<div id="hermes-chat"></div>` на front-page.php
- Стриминг через Hermes API (FastAPI)
- Механика чата будет улучшена отдельно (пользователь предоставит примеры)

### Хостинг и деплой

- Текущий WordPress на сервере 78.17.128.169
- Тема деплоится через git или SSH
- React-бандл собирается локально и заливается вместе с темой
- Hermes (FastAPI) продолжает работать в Docker на сервере

## Что удаляется

- `AIM/frontend/` — весь Next.js проект
- Все существующие страницы: about, services, case-studies, privacy-policy, analytics, dashboard
- Все Next.js API-роуты
- Компоненты, которые не нужны новой теме (старый PublicLayout, Header, Footer, DashboardNav)

## Что сохраняется

- React-компоненты чата: `SalesChat`, `ChatBubble`, `ChatInput`, `EmptyChat`, `ProgressSteps`
- Хук `useStreamChat`
- Tailwind-конфиг (цвета, типографика) — адаптируется под WordPress-тему
- SEO-метаданные из layout.tsx — переносятся в WordPress (Yoast или хардкод)

## Открытые вопросы

1. **Механика чата** — пользователь предоставит примеры для улучшения. Отложено до фазы реализации.
2. **Контент основателя** — фото + текст предоставит Михаил.
3. **Точная формулировка слогана** — будет докручена.
4. **Стартовый набор логотипов клиник** — нужно получить от пользователя.

## Не входит в этот проект

- Улучшение самого Hermes (логика пресейла, инструменты)
- Сбор данных для исследований (это `/aim-scout`)
- Миграция контента со старого сайта
