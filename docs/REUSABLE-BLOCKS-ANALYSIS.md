### Секция 6: ИНТЕГРАЦИИ (полностью стандартная)

- 6.1 Event Bus (формат событий одинаковый для всех)
- 6.2 Event Store (логирование одинаковое)
- 6.3 Obsidian Vault (структура LLM Wiki Pattern)

**Что меняется:**

### Секция 7: ОБРАБОТКА ОШИБОК (80% стандартная)

**Стандартные ошибки (одинаковые для всех):**
- INVALID_INPUT
- API_ERROR
- TIMEOUT
- INTERNAL_ERROR

**Специфичные ошибки (уникальны для каждого агента):**
- Trend Watcher: API_KEY_EXHAUSTED, VIDEO_NO_AUDIO, VIDEO_FOREIGN_LANGUAGE, TREND_OUTDATED
- Content Scheduler: API_UNAVAILABLE, CONTENT_MODERATION_FAILED, DUPLICATE_PUBLICATION, CONTENT_PLAN_NOT_APPROVED

**Что меняется:**
- Список специфичных ошибок (2-5 ошибок на агента)
- Retry параметры (10 попыток, 1-5 минут интервал)

**Экономия времени:** ~3 минуты (копируем стандартные, добавляем 2-5 специфичных)

### Секция 8: ОБУЧЕНИЕ И АДАПТАЦИЯ (90% стандартная)

**Что меняется:**

**Экономия времени:** ~2 минуты (копируем, меняем примеры)

### Секция 9: ЛОГИРОВАНИЕ (100% стандартная)

### Секция 10: ТЕСТИРОВАНИЕ (80% стандартная)

**Что меняется:**
- Специфичные unit тесты (2-3 теста на агента)
- Примеры тестов (специфичны для агента)

**Экономия времени:** ~3 минуты (копируем стандартные, добавляем 2-3 специфичных)
