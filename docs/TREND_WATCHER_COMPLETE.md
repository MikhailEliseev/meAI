## 🎯 Ключевые особенности агента

### Роль
**Trend Watcher Agent** — автономный агент для мониторинга трендов в социальных сетях (Instagram, YouTube Shorts), анализа виральных роликов конкурентов и генерации ТЗ для создания собственного контента.

### Уникальная ценность
- **Быстро реагировать на тренды** — обнаружение виральных роликов за 6 часов
- **Быть первыми по охватам** — генерация ТЗ до того, как тренд устареет
- **Собирать трафик и делать продажи** — один виральный ролик может дать огромный охват

### Критичность
⭐⭐⭐ **P1 (Критичный)** — без Trend Watcher агентство теряет возможность быстро реагировать на тренды и упускает потенциальный трафик.

## 🔧 Технические детали

### Алгоритм работы (8 шагов)
1. Мониторинг аккаунтов конкурентов (Apify Instagram Web Scraper API)
2. Отбор виральных роликов (по коэффициенту виральности)
3. Транскрибация аудио (Assembly AI)
4. Визуальный анализ (срезы каждые 5 секунд, Google Cloud Vision API)
5. Генерация сценария (Claude API)
6. Генерация ТЗ для монтажёра
7. Генерация описания для поста
8. Расчёт метрик и статистика

### Внешние API
- **Apify Instagram Web Scraper API** — мониторинг конкурентов
- **Assembly AI** — транскрибация + перевод
- **Google Cloud Vision API** — визуальный анализ кадров
- **Claude API** — генерация сценария и описания (Opus 4.7 для максимальной человечности)

### Особенности
- **Ротация API ключей** — пул бесплатных аккаунтов Apify (по $5)
- **Коэффициент виральности** — формула требует исследования (TODO)
- **Согласование перед публикацией** — обязательно (approval_required: true)
- **Мониторинг каждые 6 часов** — баланс между скоростью и нагрузкой

## 🚨 Специфичные ошибки

**API_KEY_EXHAUSTED:**
- Все API ключи из пула исчерпаны
- Переключение на следующий ключ
- Эскалация, если все ключи исчерпаны

**VIDEO_NO_AUDIO:**
- Ролик без звука
- Только визуальный анализ
- Генерация сценария на основе визуального анализа

**VIDEO_FOREIGN_LANGUAGE:**
- Ролик на иностранном языке
- Транскрибация + перевод на русский
- Генерация сценария на русском

**TREND_OUTDATED:**
- Тренд уже устарел (> 48 часов)
- Пропустить этот тренд
- Логировать для анализа паттернов
