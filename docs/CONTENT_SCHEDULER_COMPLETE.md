## 🎯 Ключевые особенности агента

### Роль
**Content Scheduler Agent** — автономный контент-менеджер, который получает готовый контент от других агентов, формирует контент-план, получает утверждение от пользователя и публикует контент по расписанию во все каналы.

### Уникальная ценность
- **Централизованное управление публикациями** — один контент-план для всех каналов
- **Автоматизация публикаций** — контент публикуется по расписанию без ручной работы
- **Контроль и прозрачность** — пользователь видит весь контент-план и статусы публикаций
- **Гибкость** — можно изменить контент-план после утверждения

### Критичность
⭐⭐⭐ **P1 (Критичный)** — без Content Scheduler контент создаётся, но не публикуется → нет результата, нет статистики, нет трафика.

## 🔧 Технические детали

### Алгоритм работы (7 шагов)
1. Получение готового контента от агентов (Content Magister, Trend Watcher, etc.)
2. Формирование контент-плана (календарь в Airtable/Notion/Google Sheets)
3. Отправка контент-плана на утверждение пользователю (через Operator)
4. Публикация контента по расписанию после утверждения
5. Мониторинг статусов публикаций (опубликовано/ошибка/отложено/в очереди)
6. Обработка ошибок и retry (10 попыток, 5 минут интервал)
7. Ежедневные уведомления (раз в день вечером через Telegram бот)

### Каналы публикации
- **Социальные сети:** Instagram, YouTube, Telegram, VK, Яндекс.Дзен
- **Блог и сайт:** WordPress, Bitrix24
- **Контент-план:** Airtable, Notion, Google Sheets
- **Fallback:** Post My Post, Buffer API

### Особенности
- **Утверждение контент-плана обязательно** — пользователь утверждает через Operator
- **Оптимальное время публикации** — утро (08:00-09:00) и вечер (18:00-20:00)
- **Retry 10 раз** — при ошибке API
- **Ежедневные уведомления** — раз в день вечером (20:00 GMT+3) через Telegram бот
- **Гибкость** — можно изменить контент-план после утверждения (добавить/удалить/перенести)

## 🚨 Специфичные ошибки

**API_UNAVAILABLE:**
- API платформы недоступен (Instagram down, YouTube down)
- Retry 10 раз, затем fallback (Post My Post, Buffer)
- Уведомить пользователя

**CONTENT_MODERATION_FAILED:**
- Контент не прошёл модерацию платформы
- Немедленное уведомление пользователя (критичная ошибка)
- Не retry (модерация не пройдёт повторно)

**DUPLICATE_PUBLICATION:**
- Тот же контент уже был опубликован
- Пропустить публикацию
- Уведомить пользователя

**CONTENT_PLAN_NOT_APPROVED:**
- Контент-план не утверждён пользователем
- Не публиковать контент
- Напомнить пользователю через 24 часа

**SCHEDULED_TIME_PASSED:**
- Запланированное время публикации уже прошло
- Опубликовать немедленно (если < 1 часа прошло)
- Пропустить публикацию (если > 1 часа прошло)
