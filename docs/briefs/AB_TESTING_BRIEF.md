# Бриф: A/B Testing Agent

**Дата:** 2026-05-11  
**Приоритет:** P2  
**Родительский Magister:** Ads Magister

## Назначение

A/B Testing Agent проводит статистически валидные эксперименты для оптимизации рекламных кампаний. Тестирует все элементы рекламных объявлений (изображения, заголовки, тексты, tone of voice) и лендингов, используя данные от CustDev и интеграции с Яндекс.Вариокуб/Метрика.

## Контекст и специфика

### Типы A/B тестов

**Рекламные объявления:**
- Изображения (креативы, фото, иллюстрации)
- Заголовки (длина, формулировки, эмоциональная окраска)
- Тексты объявлений (структура, призывы к действию)
- Tone of voice (формальный/дружелюбный, экспертный/простой)
- Попадание в сегмент (таргетинг, аудитории)

**Лендинги:**
- Структура страницы (расположение элементов)
- Заголовки и подзаголовки
- Призывы к действию (CTA)
- Формы заявок (количество полей, формулировки)
- Визуальные элементы (изображения, видео)

### Источники данных

**CustDev (Customer Development):**
- Данные о конверсиях и продажах
- Получение через Brand Analytics Agent (или другой агент верхнего уровня)
- Реальные кассовые данные клиник

**Яндекс.Вариокуб:**
- Инструмент внутри Яндекс.Метрики
- A/B тесты лендингов
- Требуется проверка API для интеграции

**Яндекс.Метрика:**
- Поведение пользователей на лендингах
- Глубина просмотра, время на сайте, конверсии
- Веб-визор: записи сессий, критические точки взаимодействия

### Медицинская специфика

**Законодательные ограничения (КРИТИЧНО изучить):**
- Федеральный закон 38-ФЗ "О рекламе" (медицинские услуги)
- Федеральный закон 323-ФЗ "Об охране здоровья"
- Запрет на гарантии результата лечения
- Требования к маркировке медицинской рекламы
- Ограничения на использование "до/после" изображений
- Запрет на рекламу рецептурных препаратов
- Требования к упоминанию лицензий

**Этические соображения:**
- Не манипулировать страхами пациентов
- Честность в описании процедур и результатов
- Прозрачность цен и условий

## Интеграции

### Входные данные

**От агентов:**
- Campaign Manager Agent — текущие кампании, объявления, настройки
- Performance Monitor Agent — метрики производительности (CTR, CPC, конверсии)
- Analytics Agent — агрегированные данные, тренды, сезонность
- Brand Analytics Agent (или аналог) — данные CustDev (конверсии, продажи)

**От внешних систем:**
- Google Ads API — данные о показах, кликах, конверсиях
- Яндекс.Директ API — данные о кампаниях и объявлениях
- Яндекс.Метрика API — поведение на лендингах, Веб-визор
- Яндекс.Вариокуб API — результаты A/B тестов лендингов

### Выходные данные

**Агентам:**
- Campaign Manager Agent — результаты тестов, рекомендации по применению победителей

**Внешним системам:**

- Яндекс.Директ API — обновление объявлений с победившими элементами
- Яндекс.Вариокуб — запуск и управление тестами лендингов

### Связанные агенты

- Campaign Manager Agent — создание и управление тестовыми кампаниями
- Performance Monitor Agent — мониторинг метрик во время тестов
- Analytics Agent — агрегация результатов тестов
- Brand Analytics Agent — источник CustDev данных

### Внешние API

## Приоритеты исследования

### 🔴 КРИТИЧНО (обязательно глубоко изучить)

1. **Statistical significance testing**
   - P-value calculation и интерпретация
   - Confidence intervals (95%, 99%)
   - Power analysis (1-β, обычно 80%)
   - Type I и Type II errors
   - Multiple testing correction (Bonferroni, FDR при множественных сравнениях)

2. **Sample size calculation**
   - Минимальная выборка для валидных результатов
   - Формулы расчёта (effect size, baseline conversion rate, power)
   - Калькуляторы и инструменты
   - Медицинский маркетинг: типичные conversion rates и effect sizes

3. **Test duration**
   - Когда останавливать тест (достижение significance)
   - Early stopping rules (sequential testing, alpha spending)
   - Минимальная длительность (учёт недельной сезонности)
   - Максимальная длительность (opportunity cost)

4. **Законодательные ограничения медицинской рекламы**
   - Федеральный закон 38-ФЗ "О рекламе" (статьи о медицинских услугах)
   - Федеральный закон 323-ФЗ "Об охране здоровья"
   - Запреты и ограничения (гарантии результата, "до/после", рецептурные препараты)
   - Требования к маркировке и лицензиям
   - Штрафы и ответственность за нарушения
   - Практические примеры разрешённых и запрещённых формулировок

### 🟡 ВАЖНО (изучить, но не так глубоко)

1. **A/B test design patterns**
   - Split testing (50/50, 80/20 allocation)
   - Multivariate testing (тестирование комбинаций элементов)
   - Factorial designs (2^k experiments)
   - Holdout groups (control group для долгосрочной валидации)

2. **Medical marketing A/B testing specifics**
   - Типичные элементы для тестирования (заголовки, CTA, изображения)
   - Tone of voice варианты (экспертный, дружелюбный, эмпатичный)
   - Сегментация аудиторий (возраст, пол, заболевания)
   - Сезонные эффекты (грипп зимой, аллергии весной)

3. **Sequential testing**
   - Continuous monitoring vs fixed horizon
   - Alpha spending functions (O'Brien-Fleming, Pocock)
   - Early stopping for futility (тест не покажет результат)
   - Adaptive sample size (увеличение выборки при необходимости)

4. **Winner selection criteria**
   - Statistical significance (p < 0.05)
   - Business significance (минимальный lift для внедрения)
   - Confidence intervals (не только point estimate)
   - Risk assessment (вероятность ошибки)

5. **Яндекс.Вариокуб и Яндекс.Метрика**
   - API возможности (если есть)
   - Интеграция с Яндекс.Метрикой
   - Веб-визор: использование записей сессий для анализа
   - Ограничения и best practices

### 🟢 ОПЦИОНАЛЬНО (можно пропустить или поверхностно)

1. **Bayesian A/B testing**
   - Bayesian vs frequentist подходы
   - Prior distributions
   - Posterior probabilities
   - Credible intervals

2. **Multi-armed bandits**
   - Adaptive allocation (больше трафика на лучший вариант)
   - Exploration vs exploitation trade-off
   - Thompson sampling, UCB algorithms

3. **Advanced variance reduction methods**
   - CUPED (Controlled-experiment Using Pre-Experiment Data)
   - Stratification
   - Regression adjustment
