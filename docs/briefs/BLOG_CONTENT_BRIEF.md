# Бриф: Blog Content Agent

**Дата:** 2026-05-10  
**Приоритет:** P1  
**Родительский Magister:** Content Magister

---

## Назначение

**Основная задача:** Писать максимально эффективные тексты для всех типов контента (лендинги, блог-статьи, листовки, сценарии для рилсов, email-рассылки), которые "бьют прямо в сердце" целевой аудитории.

**Ключевая особенность:** Интеллектуальный выбор фреймворка написания (AIDA, PAS, BAB, FAB, 4P, StoryBrand и др.) в зависимости от:
- Типа контента (лендинг, блог, соцсети, email)
- Сегмента аудитории (пациенты, врачи, администраторы клиник)
- Tone of Voice бренда
- Результатов Brand Magister и Synthetic CustDev

---

## Контекст и специфика

### Медицинская специфика

1. **E-E-A-T (Experience, Expertise, Authoritativeness, Trustworthiness)**
   - Тексты должны демонстрировать экспертность
   - Обязательное цитирование медицинских источников
   - Авторитетность через упоминание квалификации врачей

2. **YMYL (Your Money Your Life)**
   - Медицинские тексты = YMYL категория
   - Высокие требования к точности и безопасности
   - Нельзя давать прямые медицинские рекомендации без disclaimer

3. **152-ФЗ Compliance**
   - Нельзя использовать персональные данные пациентов без согласия
   - Кейсы и отзывы только с разрешения

4. **Медицинская терминология**
   - Упрощение сложных терминов для пациентов
   - Сохранение точности для врачей
   - Адаптация под сегмент аудитории

### Юридические риски

- Что можно/нельзя писать о лечении
- Запрет на гарантии результата ("100% излечение")
- Обязательные disclaimer для медицинских советов

## Интеграции

### Входные данные

**От Brand Magister:**
- Tone of Voice бренда (формальный/дружелюбный/экспертный)
- Brand Voice характеристики
- Ключевые сообщения бренда

**От Synthetic CustDev:**
- Боли и потребности целевой аудитории
- Язык аудитории (как они говорят о проблемах)
- Триггеры и возражения

**От Keyword Research Agent:**
- Ключевые слова для SEO
- Поисковые запросы аудитории

**От Medical Fact-Checker Agent:**
- Проверенные медицинские факты
- Источники для цитирования

**От пользователя:**
- Тип контента (лендинг, блог, рилс, email)
- Сегмент аудитории (пациенты, врачи, администраторы)
- Цель текста (информирование, продажа, вовлечение)
- Длина текста (краткая/средняя/длинная)

### Выходные данные

**Готовый текст:**
- Заголовок (H1)
- Подзаголовки (H2, H3)
- Основной текст
- CTA (Call to Action)
- Meta-описание (для SEO)

**Метаданные:**
- Использованный фреймворк (AIDA, PAS, etc.)
- Readability Score (Flesch Reading Ease)
- SEO Score
- Tone of Voice соответствие (%)

### Связанные агенты

**Обязательные интеграции:**
- **Tone of Voice Agent** — проверка соответствия ToV бренда
- **Medical Fact-Checker Agent** — проверка медицинских фактов
- **Keyword Research Agent** — SEO-оптимизация
- **Brand Magister** — получение Brand Voice

**Опциональные интеграции:**
- **Editor Agent** — финальная редактура и полировка
- **GEO Content Agent** — оптимизация под AI-поиск

### Внешние API

**Для проверки качества:**
- Grammarly API (грамматика, стиль)
- Hemingway Editor API (readability)
- Yoast SEO API (SEO-оптимизация)

**Для генерации:**
- Anthropic Claude API (основной движок генерации)
- Perplexity API (поиск актуальной медицинской информации)

## Приоритеты исследования

### 🔴 КРИТИЧНО (обязательно глубоко изучить)

1. **Фреймворки копирайтинга**
   - AIDA (Attention, Interest, Desire, Action)
   - PAS (Problem, Agitate, Solution)
   - BAB (Before, After, Bridge)
   - FAB (Features, Advantages, Benefits)
   - 4P (Picture, Promise, Prove, Push)
   - StoryBrand (Donald Miller)
   - PASTOR (Problem, Amplify, Story, Transformation, Offer, Response)
   - Какой фреймворк для какого типа контента?
   - Как выбирать фреймворк автоматически?

2. **Интеллектуальный выбор фреймворка**
   - Алгоритм выбора фреймворка на основе:
     * Тип контента (лендинг → AIDA, блог → PAS, рилс → BAB)
     * Сегмент аудитории (пациенты → эмоции, врачи → факты)
     * Цель текста (продажа → AIDA, информирование → FAB)
   - Decision tree для выбора фреймворка
   - Примеры успешного применения каждого фреймворка

3. **Tone of Voice адаптация**
   - Как адаптировать текст под ToV бренда?
   - Метрики соответствия ToV (формальность, дружелюбность, экспертность)
   - Примеры трансформации текста под разные ToV

4. **Медицинская специфика в копирайтинге**
   - E-E-A-T требования для медицинских текстов
   - YMYL compliance (что можно/нельзя писать)
   - Юридические риски (гарантии, рекомендации, disclaimer)
   - Упрощение медицинской терминологии без потери точности

### 🟡 ВАЖНО (изучить, но не так глубоко)

5. **Структура текстов по типам**
   - Лендинг: структура, длина, CTA placement
   - Блог-статья: структура, заголовки, readability
   - Листовка: краткость, визуальная иерархия
   - Сценарий для рилса: хуки, storytelling, timing
   - Email-рассылка: subject line, preview text, body

6. **SEO-оптимизация контента**
   - Естественное вплетение ключевых слов
   - LSI keywords (латентно-семантическое индексирование)
   - Meta-теги (title, description)
   - Внутренние ссылки

7. **Метрики качества текста**
   - Readability Score (Flesch Reading Ease > 60)
   - SEO Score (Yoast > 80)
   - Engagement Rate (Time on Page > 3 мин)
   - Conversion Rate (для лендингов)

8. **Инструменты для проверки качества**
   - Grammarly API (грамматика, стиль, тон)
   - Hemingway Editor API (readability, сложность предложений)
   - Yoast SEO API (SEO-оптимизация)
   - Медицинские базы данных (PubMed, UpToDate)

### 🟢 ОПЦИОНАЛЬНО (можно пропустить или поверхностно)

9. **Визуальное оформление текстов**
   - Форматирование (жирный, курсив, списки)
   - Изображения и инфографика
   - Цитаты и врезки

10. **Продвижение контента**
    - Соцсети (как адаптировать для разных платформ)
    - Email-маркетинг (subject lines, preview text)
    - Paid ads (как писать рекламные тексты)
