# Бриф: Competitor Discovery Agent

**Дата:** 2026-05-22
**Приоритет:** P0
**Родительский Magister:** Sales Admin Agent (пресейл)

## Назначение

Находить 3 максимально релевантных конкурента для клиники клиента на этапе пресейла. Конкуренты должны быть похожи по:
- Услугам/направлениям/отделениям
- Масштабу (выручка, количество сотрудников)
- Локации (тот же город, ≤50 км)
- Специализации (моно vs многопрофильная)

Максимальная релевантность = максимальная ценность для клиента на пресейле → выше конверсия в продажу.

## Контекст и специфика

### Проблемы текущей реализации (competitor_matcher.py)
1. **DaData-кандидаты (25 шт.) не попадают в топ-10** — все топы OSM
2. **Одинаковые скоры у OSM-кандидатов** — rev=0.75, svc=0.40, data=0.40, pop=0.50, vis=0.40 у всех; дифференциация только по локации
3. **OSM-специализация определяется поисковым запросом**, не реальными услугами — "Клиника концептуальной стоматологии" tagged как косметология
4. **Yandex Maps API 403** — ключ невалиден, Tier 3 не работает
5. **Нет различения моно vs многопрофильная** — одноместная косметология может получить многопрофильную клинику как конкурента

### Специфика
- **Только коммерческая медицина** (ООО, АО, ЗАО, ИП)
- **Российский рынок** — DaData, Яндекс.Карты, 2GIS, OSM
- **Пресейл** — нужно дать максимум информации до первого контакта

## Интеграции

### Входные данные
- URL сайта клиента
- Извлечённые услуги (service_extractor.py)
- Специализация и город

### Выходные данные
- Топ-3 CompetitorMatch с:
  - Название, адрес, координаты
  - Услуги, выручка, сотрудники
  - Match score с разбивкой по компонентам
  - Match reason (почему похож)

### Источники данных
- **DaData API** — юрлица, финансовые данные
- **OpenStreetMap (Overpass + Nominatim)** — физические клиники на карте
- **Yandex Maps API** — поиск организаций + рейтинги (сейчас сломан)
- **2GIS API** (потенциально) — ещё один источник организаций

### Связанные агенты
- Competitor Analysis Agent — получает найденных конкурентов для глубокого CI-анализа
- Sales Admin Agent — использует результат для пресейл-диалога
