# Бриф: Landing Content Agent

**Дата:** 2026-05-10  
**Приоритет:** P1  
**Родительский Magister:** Content Magister

---

## Назначение

**Основная задача:** Создавать высококонверсионные лендинги для медицинских услуг, которые превращают посетителей в лиды с конверсией 5-15%.

**Ключевая особенность:** Специализация на conversion-focused контенте с использованием проверенных conversion frameworks (AIDA, PAS, 4P) и психологических триггеров (scarcity, social proof, authority).

---

## Контекст и специфика

### Отличия от Blog Content Agent

**Blog Content Agent:**
- Цель: информирование, SEO, долгосрочный трафик
- Длина: 1,500-2,000 слов
- Фреймворки: все 7 (AIDA, PAS, BAB, FAB, 4P, StoryBrand, PASTOR)
- Conversion: 2-5%

**Landing Content Agent:**
- Цель: конверсия, генерация лидов, продажа услуги
- Длина: 800-1,500 слов (короче, фокус на действие)
- Фреймворки: только conversion-focused (AIDA, PAS, 4P)
- Conversion: 5-15% (в 3 раза выше)

### Медицинская специфика

1. **Compliance (как у Blog Content)**
   - E-E-A-T требования
   - FDA/152-ФЗ compliance
   - Запрет на outcome guarantees
   - Обязательные disclaimers

2. **Психологические триггеры**
   - Scarcity: "Осталось 3 места на этой неделе"
   - Social proof: "500+ пациентов вылечились"
   - Authority: "15 лет опыта, кандидат медицинских наук"
   - Urgency: "Запишитесь сегодня — получите скидку 20%"

3. **Trust elements**
   - Фото врачей с credentials
   - Сертификаты и лицензии
   - Отзывы пациентов (с согласием 152-ФЗ)
   - До/после (если применимо и этично)

## Интеграции

### Входные данные

**От Content Magister:**
- Услуга для продажи (diagnostic, treatment, preventive)
- Целевая аудитория (patients, их сегмент)
- Ценовой сегмент (budget, mid, premium)

**От Brand Magister:**
- Tone of Voice бренда
- Brand positioning
- Unique Value Proposition (UVP)

**От Synthetic CustDev:**
- Боли целевой аудитории
- Возражения (objections)
- Триггеры к действию

**От Keyword Research Agent:**
- Ключевые слова для SEO (secondary priority)

**От пользователя:**
- Услуга (название, описание, цена)
- Врачи (имена, credentials, фото)
- Социальные доказательства (отзывы, статистика)
- Оффер (скидка, бонус, гарантия)

### Выходные данные

**Готовый лендинг:**
- Hero section (заголовок + подзаголовок + CTA)
- Problem section (боль аудитории)
- Solution section (как услуга решает проблему)
- Benefits section (3-5 ключевых выгод)
- Social proof section (отзывы, статистика)
- Pricing section (цена, оффер)
- FAQ section (5-7 вопросов)
- Final CTA section (призыв к действию)

**Метаданные:**
- Использованный фреймворк (AIDA, PAS, 4P)
- Психологические триггеры (scarcity, social proof, authority, urgency)
- Conversion Score (predicted, 0-100)
- Compliance Risk (low, medium, high)

### Связанные агенты

**Обязательные интеграции:**
- **Tone of Voice Agent** — проверка соответствия ToV бренда
- **Medical Fact-Checker Agent** — проверка медицинских фактов
- **Brand Magister** — получение Brand Voice и UVP

**Опциональные интеграции:**
- **Editor Agent** — финальная редактура
- **A/B Testing Agent** — создание вариантов для тестирования (TODO)

### Внешние API

**Для проверки качества:**
- LanguageTool API (грамматика, стиль)
- Textstat (readability)

**Для генерации:**
- Anthropic Claude API (основной движок)

## Приоритеты исследования

### 🔴 КРИТИЧНО (обязательно глубоко изучить)

1. **Conversion frameworks для лендингов**
   - AIDA для медицинских лендингов
   - PAS для pain-focused продаж
   - 4P для high-ticket услуг
   - Какой фреймворк для какой услуги?
   - Benchmarks конверсии по фреймворкам

2. **Психологические триггеры**
   - Scarcity (дефицит): как использовать этично в медицине
   - Social proof (социальное доказательство): отзывы, статистика, кейсы
   - Authority (авторитет): credentials, сертификаты, опыт
   - Urgency (срочность): ограниченные предложения, дедлайны
   - Reciprocity (взаимность): бесплатная консультация, чек-лист
   - Consistency (последовательность): micro-commitments

3. **Структура высококонверсионного лендинга**
   - Hero section: формула заголовка (боль + решение + результат)
   - Above the fold: что должно быть видно без скролла
   - CTA placement: где размещать кнопки (сколько, какие тексты)
   - Visual hierarchy: как направлять взгляд пользователя
   - Length: оптимальная длина лендинга (short vs long)

4. **Медицинская специфика лендингов**
   - Compliance: что можно/нельзя обещать
   - Trust elements: как показать экспертность и безопасность
   - Disclaimers: где и как размещать
   - Pricing: как показывать цены (прозрачно vs "от X руб")

5. **Формы захвата лидов**
   - Обязательные поля: имя, телефон (минимум для высокой конверсии)
   - Опциональные поля: email, комментарий, предпочитаемое время звонка
   - Multi-step forms vs single-step (влияние на конверсию: multi-step +30-40%)
   - Интеграция с CRM: автоматическая отправка лида (AmoCRM, Bitrix24)
   - Валидация: проверка формата телефона, email в реальном времени
   - Защита от спама: reCAPTCHA, honeypot fields

### 🟡 ВАЖНО (изучить, но не так глубоко)

6. **CTA (Call to Action) оптимизация**
   - Тексты кнопок: "Записаться" vs "Получить консультацию" vs "Узнать цену"
   - Цвета кнопок: психология цвета в медицине
   - Размещение: сколько CTA на странице (1, 3, 5+?)
   - Формы: какие поля запрашивать (имя, телефон, email, комментарий)

7. **Social proof элементы**
   - Отзывы: структура, длина, фото пациентов (с согласием)
   - Статистика: "500+ пациентов", "15 лет опыта", "98% успеха"
   - Кейсы: до/после (если этично и разрешено)
   - Сертификаты: какие показывать, как оформлять

8. **Pricing presentation**
   - Прозрачность: показывать точную цену vs "от X руб"
   - Anchoring: как использовать якорение цен
   - Packages: один пакет vs несколько (basic, standard, premium)
   - Discounts: как показывать скидки этично

9. **Mobile optimization**
   - Адаптация контента под мобильные
   - Упрощение форм для мобильных
   - Click-to-call кнопки

10. **Exit-intent popups**
    - Когда показывать: при попытке закрыть страницу (mouse movement к верхней границе)
    - Что предлагать: скидка 10-20%, бесплатная консультация, чек-лист, гайд
    - Compliance: не раздражать (показывать 1 раз в сессию), не обманывать
    - A/B тестирование: разные офферы для разных сегментов
    - Метрика: Exit-intent conversion rate > 5%

11. **Retargeting pixels и аналитика**
    - Яндекс Метрика цели: просмотр страницы, скролл 50%, клик на CTA, отправка формы
    - Google Analytics события: engagement, conversions, bounce rate
    - Facebook/VK пиксели для ретаргетинга: создание custom audiences
    - Сегментация аудитории: по глубине скролла, времени на странице, действиям
    - UTM-метки: отслеживание источников трафика

12. **Speed optimization**
    - Время загрузки < 3 секунды (критично: каждая секунда задержки = -7% конверсии)
    - Lazy loading изображений: загрузка по мере скролла
    - Минификация CSS/JS: сжатие файлов
    - CDN для статики: быстрая доставка контента
    - Critical CSS: inline стили для above-the-fold контента
    - Image optimization: WebP формат, сжатие без потери качества

### 🟢 ОПЦИОНАЛЬНО (можно пропустить или поверхностно)

13. **A/B тестирование**
    - Что тестировать: заголовки, CTA, цвета, длину
    - Как интерпретировать результаты
    - Statistical significance

14. **Визуальный дизайн**
    - Цветовая схема
    - Типографика
    - Изображения и иконки

15. **Chatbot integration**
    - Онлайн-консультант: человек vs бот vs гибрид
    - Быстрые ответы на FAQ: автоматические ответы на типовые вопросы
    - Квалификация лида через чат: BANT-вопросы в диалоге
    - Платформы: Jivo, Carrot quest, Bitrix24, custom bot
    - Timing: когда показывать чат (сразу, через 30 сек, при exit-intent)
    - Метрика: Chat-to-lead conversion rate > 15%
