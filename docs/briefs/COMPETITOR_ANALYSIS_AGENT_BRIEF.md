# Бриф: Competitor Analysis Agent

**Дата:** 2026-05-11  
**Приоритет:** P1  
**Родительский Magister:** SEO Magister

## Назначение

Глубокий анализ конкурентов для выявления возможностей и gaps в SEO, контенте, рекламе, технологиях и стратегиях. Агент должен находить всё, что конкуренты делают лучше, и предлагать конкретные действия для обгона.

## Контекст и специфика

### Медицинский маркетинг
- **Конкурентная разведка:** Отслеживание стратегий конкурентов (новые услуги, акции, врачи, технологии)
- **Специфические метрики:** Медицинские KPI (конверсия в запись, доверие пациентов, репутация клиники)
- **Медицинская экспертиза:** Анализ качества медицинского контента (врачи-авторы, цитирование исследований, E-E-A-T)

### Глубина анализа
Максимальная глубина — анализ всех аспектов:
- SEO (keywords, rankings, backlinks)
- Контент (темы, форматы, качество)
- Реклама (кампании, креативы, бюджеты)
- Технологии (скорость, структура, schema)
- Стратегии (позиционирование, УТП, аудитория)

## Интеграции

### Входные данные
- URL конкурента (от пользователя)
- Список конкурентов (от SEO Magister)
- URL клиента для сравнения (от SEO Magister)

### Выходные данные
- Полный отчёт по конкуренту (JSON + Markdown)
- Keyword gaps (для Keyword Research Agent)
- Content gaps (для Content Strategy Agent)
- Technical findings (для Technical SEO Agent)
- Backlink opportunities (для Backlink Analysis Agent)

### Связанные агенты
- **Keyword Research Agent:** Получает keyword gaps для исследования
- **Content Strategy Agent:** Получает content gaps и стратегии конкурентов
- **Technical SEO Agent:** Получает технические находки конкурентов
- **Backlink Analysis Agent:** Получает профили ссылок конкурентов для анализа

### Внешние API
- **SEMrush API:** Трафик, ключевые слова, backlinks, рекламные кампании (самый полный набор)
- **Google Search Console API:** Позиции в поиске, CTR, impressions (данные напрямую от Google)
- **PageSpeed Insights API:** Скорость загрузки, Core Web Vitals, технические метрики

## Приоритеты исследования

### 🔴 КРИТИЧНО (обязательно глубоко изучить)

1. **Keyword gap analysis**
   - Какие ключевые слова используют конкуренты
   - Где они ранжируются (топ-3, топ-10, топ-100)
   - Какие gaps есть у клиента (конкурент есть, клиента нет)
   - Keyword difficulty и search volume для gaps
   - Приоритизация gaps по потенциалу

2. **Content strategy analysis**
   - Темы контента конкурентов (медицинские, коммерческие, информационные)
   - Форматы (статьи, видео, инфографика, кейсы)
   - Частота публикаций и обновлений
   - Качество контента (E-E-A-T, врачи-авторы, цитирование)
   - Content gaps (что есть у конкурентов, чего нет у клиента)

3. **Backlink profile analysis**
   - Откуда конкуренты получают ссылки (домены, страницы)
   - Качество доноров (DR, DA, трафик, тематика)
   - Anchor texts (брендовые, коммерческие, информационные)
   - Backlink gaps (где есть ссылки на конкурентов, но нет на клиента)
   - Стратегии линкбилдинга конкурентов

4. **Technical SEO audit**
   - Скорость сайта (PageSpeed, Core Web Vitals)
   - Мобильная версия (responsive, AMP, PWA)
   - Структура сайта (URL, навигация, внутренние ссылки)
   - Schema markup (Organization, MedicalBusiness, FAQPage, etc.)
   - Технические преимущества конкурентов

### 🟡 ВАЖНО (изучить, но не так глубоко)

1. **Paid advertising analysis**
   - Какие рекламные кампании запускают конкуренты
   - Креативы и посылы (УТП, оффер, CTA)
   - Примерные бюджеты (по количеству объявлений и позициям)
   - Landing pages для рекламы

2. **Social media presence**
   - Активность в соцсетях (частота, вовлечённость)
   - Типы контента (образовательный, коммерческий, развлекательный)
   - Аудитория (размер, демография, интересы)

3. **Brand positioning**
   - УТП конкурентов (что они продают)
   - Позиционирование (премиум, масс-маркет, специализация)
   - Tone of voice (формальный, дружелюбный, экспертный)

### 🟢 ОПЦИОНАЛЬНО (можно пропустить или поверхностно)

1. **Email marketing**
   - Наличие email-рассылок
   - Частота и темы писем

2. **Offline presence**
   - Наличие физических клиник
   - Реклама в оффлайне
