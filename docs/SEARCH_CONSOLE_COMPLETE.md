## 🎯 Ключевые особенности агента

### Роль
**Search Console Agent** — глаза системы в поисковых системах, который собирает данные о том, как сайт показывается в поисковой выдаче.

### Уникальная ценность
- **Видимость в поиске** — показывает, как сайт находится в поисковых системах
- **Упущенные возможности** — показы без кликов (низкий CTR)
- **Проблемы индексации** — страницы не в индексе, ошибки сканирования, штрафы
- **Диагностика проблем** — почему трафик не растёт
- **Данные для оптимизации** — какие запросы и страницы нужно оптимизировать

### Критичность
⭐⭐⭐⭐ **P1 (Важный)** — без этих данных мы слепые, не понимаем, почему трафик не растёт.

## 🔧 Технические детали

### Алгоритм работы (5 шагов)
1. Сбор данных из Google Search Console (запросы, показы, клики, позиции, CTR, проблемы индексации)
2. Сбор данных из Яндекс Вебмастера (запросы, показы, клики, позиции, CTR, проблемы индексации)
3. Объединение данных (по запросам, по страницам)
4. Проверка ошибок получения (API недоступны, данные неполные)
5. Передача данных дальше (SEO Magister через Event Bus)

### Источники данных

**Обязательные:**
- **Google Search Console API** — данные о поисковой выдаче Google
- **Яндекс Вебмастер API** — данные о поисковой выдаче Яндекса

### Особенности
- **Два источника** — Google + Яндекс
- **Запросы и страницы** — метрики по запросам (показы, клики, CTR, позиции) и по страницам
- **Проблемы индексации** — страницы не в индексе, ошибки сканирования, штрафы
- **Объединение данных** — по запросам и страницам (если есть в обоих источниках)
- **Сырые данные** — возвращает данные в сыром виде, без выводов
- **Graceful degradation** — работает даже если один источник недоступен

**Результат:**
- Список запросов с метриками (запрос, показы, клики, CTR, средняя позиция) — отдельно Google, отдельно Яндекс

## 🚨 Специфичные ошибки

**API_UNAVAILABLE:**
- Google Search Console или Яндекс Вебмастер недоступны
- Retry с exponential backoff (10 попыток)
- Graceful degradation (продолжить с другим источником)

**SITE_NOT_VERIFIED:**
- Сайт не верифицирован в Search Console или Вебмастере
- Возврат ошибки с инструкцией по верификации
- Эскалация → User

**RATE_LIMIT_EXCEEDED:**
- Превышен лимит запросов к API
- Подождать до сброса лимита → retry

## 📚 Границы ответственности

**Что делает агент:**
- ✅ Собирает данные из Google Search Console и Яндекс Вебмастера
- ✅ Отслеживает запросы, позиции, показы, клики, CTR
- ✅ Мониторит проблемы индексации, ошибки сканирования, штрафы
- ✅ Объединяет данные по запросам и страницам
- ✅ Передаёт данные в сыром виде (без выводов)
- ✅ Сохраняет историю в БД и Obsidian

**Что НЕ делает агент:**
- ❌ Не собирает метрики трафика (это Web Analytics Agent)
- ❌ Не анализирует конкурентов (это Competitor Analysis Agent)
- ❌ Не делает выводы и рекомендации (это задача SEO Magister)
- ❌ Не исправляет проблемы (это задача других агентов)
