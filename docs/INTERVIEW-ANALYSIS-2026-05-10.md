### 5. AI Sales Admin — Приоритеты мониторинга сайта (🟡 ВАЖНО)

**Добавлено:** Раздел 3.2.7 "Приоритеты мониторинга сайта" (~6 KB)

**Содержание:**
- Проблема: Playwright не даёт чёткой информации о ценах
- Приоритет 1: WordPress REST API / Bitrix24 REST API (рекомендуется)
  - Примеры кода для WordPress и Bitrix24
  - Преимущества: структурированные данные, точные цены, быстро, надёжно
- Приоритет 2: Schema.org парсинг
  - Пример кода для извлечения JSON-LD
  - Преимущества: структурированные данные, не требует API ключей
  - Недостатки: не все сайты имеют разметку
- Приоритет 3: Playwright (fallback)
  - Пример кода для рендеринга и парсинга
  - Преимущества: работает на любом сайте
  - Недостатки: медленно, хрупко, ресурсоёмко
- Стратегия выбора с примером кода (try REST API → try Schema.org → fallback Playwright)
- Метрики: API success rate > 95%, Data accuracy 100%, Update latency < 1 час

**Почему важно:**
Актуальность цен в базе знаний критична. Если агент называет неправильную цену → потеря доверия пациента. REST API даёт точные данные из базы, Playwright может ошибаться.
