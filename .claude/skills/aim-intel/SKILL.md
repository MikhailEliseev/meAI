# Competitor Intel — загрузка разведки конкурента на сервер

## Задача

Когда ты проводишь конкурентную разведку через терминал — результат должен автоматически
заливаться в правильном формате на сервер, где Hermes его подхватит.

## Флоу

### Шаг 1: Определи клиента и конкурента

Спроси у пользователя:
- `client` — slug клиента (arclinic, detstvo-plus, ...)
- `slug` — slug конкурента (dega, rami, laserdoctor, ...)

Если пользователь уже назвал их в сообщении — не переспрашивай.

### Шаг 2: Проверь, есть ли уже data.json

```bash
ssh aim "cat /opt/hermes-data/AIM/{client}/competitors/{slug}/data.json 2>/dev/null" || echo "NOT_FOUND"
```

Если файл уже есть — покажи его содержимое пользователю и спроси, обновить или нет.

### Шаг 3: Выдай промпт для LLM

Прочитай `README.md` (секция 4) и `data-schema.json` из этой же директории.
Выдай пользователю итоговый промпт, подставив конкретные значения:

```
Ты — агент конкурентной разведки AIM. Собери полные данные о конкуренте:

КЛИНИКА: {название}
ГОРОД: Санкт-Петербург
INSTAGRAM: @{handle}
САЙТ: {url}

Собери:
1. ВСЕХ врачей с сайта (ФИО + специализация + должность)
2. Рейтинги: Яндекс.Карты, ProDoctorov, 2ГИС
3. Instagram: подписчики, посты, ER, темы контента (3-5), формат, топ-пост
4. Технический аудит сайта: PageSpeed, Schema.org, llms.txt
5. СМИ-упоминания (forbes.ru, rbc.ru, kommersant.ru, vogue.ru, vademec.ru)
6. Выписка ФНС: ИНН, выручка (egrul.nalog.ru)
7. Ключевые враги: Instagram врачей, подписчики, темы контента

Верни результат СТРОГО в JSON-формате (схема в data-schema.json).
БЕЗ длинных тире. БЕЗ «EGRUL» (→ «выписка ФНС»). БЕЗ додумывания.
```

### Шаг 4: Получи JSON от пользователя

Пользователь скормит этот промпт LLM на своей машине и отдаст тебе готовый `data.json`.
Прими JSON, провалидируй:

1. Это валидный JSON
2. Есть обязательные ключи верхнего уровня: `clinic`, `doctors`, `content_analysis`, `tech_audit`, `smi`, `gaps`, `wow_insights`
3. Нет длинных тире (—) — замени на короткие (–)
4. Нет слова «EGRUL» — замени на «выписка ФНС»
5. Все строки — UTF-8

### Шаг 5: Залей на сервер

```bash
# Сохрани JSON локально во временный файл
# Затем scp на сервер
scp /tmp/{slug}-data.json aim:/opt/hermes-data/AIM/{client}/competitors/{slug}/data.json
```

Если slug-директории нет — создай:
```bash
ssh aim "mkdir -p /opt/hermes-data/AIM/{client}/competitors/{slug}"
```

### Шаг 6: Проверь результат

```bash
ssh aim "python3 /root/bin/competitor-mgr.py list {client}"
```

Убедись, что статус конкурента сменился с `⬜` на `✅`.

### Шаг 7: Скажи «готово»

Напиши пользователю:
- Имя конкурента
- Путь на сервере
- Статус (✅)
- Ключевые цифры из разведки (врачи, выручка, рейтинг)

## Важные правила

- **Сервер:** `aim`
- **Путь:** `/opt/hermes-data/AIM/{client}/competitors/{slug}/data.json`
- **Схема:** строго по `data-schema.json` (в этой же директории)
- **Промпт:** из `README.md` секция 4 (в этой же директории)
- **Не додумывай данные** за пользователя. Если чего-то нет в JSON — спроси.
- **Всегда валидируй JSON** перед заливкой.
