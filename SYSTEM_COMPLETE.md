## 📝 TECHNICAL NOTES

### Architecture Decisions:

1. **Three-Layer Hierarchy**
   - Strategy: Architect (strategic decisions)
   - Tactical: Operator (task delegation)
   - Execution: Magisters + Agents (work execution)

2. **Event-Driven Communication**
   - Async Event Bus (P0-P3 priorities)
   - Decoupled components
   - Scalable architecture

3. **Database Design**
   - JSON storage for flexibility
   - Indexed for performance
   - Async SQLAlchemy

4. **Memory System**
   - Obsidian vaults per agent
   - LLM Wiki Pattern
   - Persistent knowledge

5. **Business Logic**
   - Models contain rules
   - Managers handle persistence
   - Agents execute tasks
   - Clear separation of concerns
