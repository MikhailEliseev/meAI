Design System

Dual Theme
Design System

Один набор шрифтов, две личности. Светлая тема — монохромный минимализм. Тёмная тема — роскошь Art Deco с золотом.

Typography

Fonts — Universal

Playfair Display (serif) для заголовков + Jost (geometric sans) для текста. Одинаковые в обеих темах. Чистая геометрия и королевская элегантность.

Display

Heading — Playfair Display 400

Subheading — Playfair Display 500

Body text uses Jost, a geometric sans-serif with clean lines. Perfect for UI elements and longer content.

Jost (regular) — основной текст, 15–16px, line-height 1.7

Jost (small) — детали, кепшены, подписи

Jost (label) — uppercase лейблы
