# План: Улучшение UX чата — таймер, стабильность, кнопки

## Проблема
Чат зависает (визуально), не показывает оставшееся время, кнопки оформлены костыльно (CSS `::after { content: 'Отправить' }` скрывает SVG).

## Решение — 4 изменения в React чате

### 1. ⏱️ ETA таймер «Осталось ~X мин»
**Файл:** `AIM/theme/chat/src/useStreamChat.js` + `PhaseTracker.jsx`

Алгоритм оценки времени:
- Каждой фазе присвоить среднюю длительность на основе реальных данных из логов
- При старте фазы показывать «Осталось ~X мин» — сумма оставшихся фаз
- Текст обновляется при смене фазы (на `phase-progress` событии)

Базовые длительности фаз (из логов Erasmile + arclinic):
```
PERPLEXITY: 100s, COMPETITORS: 130s, TECH_AUDIT: 90s, SOCIAL: 70s,
CONTENT: 110s, KEY_PERSONS: 70s, SMI: 65s, FORUM_PAINS: 45s,
FINANCE: 50s, CONTENT_PLAN: 65s, HTML_BUILD: 5s, QC: 35s, PRESENTATION: 5s
Итого: ~840s = ~14 мин
```

**Что добавить:**
- В `PhaseTracker.jsx`: строка под прогресс-баром «⏳ Осталось ~3 мин»
- В `useStreamChat.js`: расчёт ETA при каждом `phase-progress` событии
- Таймер обновляется каждую секунду (через `setInterval`), уменьшая оценку

**Визуальный вид:**
```
████████████░░░░░░░░  8/13
✓ Рынок  ✓ Конкуренты  ⟳ Тех.аудит  ○ Отзывы ...
⏳ Осталось ~6 мин · Анализирую технический аудит...
```

### 2. 🛡️ Защита от зависания (keep-alive)
**Файл:** `AIM/theme/chat/src/useStreamChat.js`

Проблема: нет таймаута — если Hermes замолкает, чат висит вечно.

Решение:
- Добавить `lastEventTime` — timestamp последнего полученного SSE события
- Добавить `watchdogInterval` (каждые 30 сек проверяет):
  - Если прошло >90 сек без событий → показать «⚠️ Соединение тихое, переподключаюсь...»
  - Если прошло >180 сек → авто-стоп с сообщением «Анализ занимает дольше обычного. Отчёт будет готов через несколько минут — мы пришлём ссылку.»
- На `report-ready` или `finish` — сброс watchdog

### 3. 🎨 Чистые текстовые кнопки (без CSS-костылей)
**Файлы:** `ChatInput.jsx`, `EmptyChat.jsx`, `ReportPreview.jsx`, `chat-theme.css`

Сейчас: кнопки рендерят SVG-иконку, а CSS её скрывает и добавляет текст через `::after { content: 'Отправить' }`.

Будет: убрать SVG из JSX, добавить текст напрямую в JSX:
```jsx
// Было:
<button className="shrink-0 w-10 h-10 ...">
  <svg>...arrow...</svg>
</button>

// Стало:
<button className="chat-btn chat-btn-primary">
  Отправить
</button>
```

Убрать хаки из `chat-theme.css` (строки 148-201). Новые чистые классы:
- `.chat-btn-primary` — акцентная кнопка (Отправить, Открыть отчёт)
- `.chat-btn-danger` — красная кнопка (Стоп)
- `.chat-btn-secondary` — вторичная (Прислать на почту)
- `.chat-btn-ghost` — быстрые действия (chips)

Премиальный стиль: padding 14px 24px, radius 16px, font Jost 600, hover translateY(-2px) + shadow.

### 4. 🔄 Авто-восстановление фаз при reload
**Файл:** `useStreamChat.js`

Сейчас: при перезагрузке страницы все фазы сбрасываются в pending (визуально чат "сломан").

Решение: если в localStorage есть `aim_session_id` и последнее сообщение от agent — показывать статус «Анализ продолжается в фоновом режиме. Отчёт будет готов через ~X мин» с spinner.

## Сборка и деплой

```bash
cd AIM/theme/chat
node esbuild.config.mjs          # сборка chat-bundle.js + .css
# Деплой на сервер:
scp dist/chat-bundle.js dist/chat-bundle.css aim:/tmp/
ssh aim "docker cp /tmp/chat-bundle.js aim-wordpress:/var/www/html/wp-content/themes/aim-theme/assets/js/"
ssh aim "docker cp /tmp/chat-bundle.css aim-wordpress:/var/www/html/wp-content/themes/aim-theme/assets/js/"
```

## Что НЕ меняется
- Backend (Hermes) — не трогаем
- SSE протокол — не трогаем
- React архитектура — не трогаем
- WordPress functions.php — не трогаем
- Только frontend React компоненты и CSS

## Риски
- Нужно пересобрать bundle через esbuild (проверим что node установлен)
- Деплой — копирование 2 файлов, без рестарта контейнера
- Откат — вернуть старые chat-bundle.js/css из бэкапа
