# План: Превратить отчёт из «скелета» в настоящий маркетинговый анализ

## Диагноз: почему отчёт — мусор

Я провёл глубокую разведку архитектуры. Нашёл **3 корневые причины**:

### 🔴 Причина 1: LLM СЛЕПОЙ
Для 3 ключевых тулов (`find_competitors`, `extract_clinic_profile`, `scrape_clinic_website`) LLM получает **заглушку** вместо данных:
```python
# llm.py:31-34
_TOOL_RESULT_HIDDEN = "[Данные получены и отображены пользователю... Сырой JSON скрыт]"
```
LLM буквально не видит ни выручку конкурентов, ни отзывы, ни врачей. Он пишет анализ **вслепую**.

### 🔴 Причина 2: Промпт ЗАПРЕЩАЕТ цифры
```python
# llm.py:1191
"КРИТИЧНО: НЕ повторяй НИ ОДНОЙ цифры из секций выше в своём тексте"
```
LLM лишён и данных, и права их использовать → анализ получается общим и водянистым.

### 🔴 Причина 3: Богатые данные собираются, но ВЫБРАСЫВАЮТСЯ
| Данные | Собирается? | Показывается? |
|--------|:-----------:|:------------:|
| `neuro_summary` — AI-резюме отзывов от Яндекса (500 символов) | ✅ | ❌ игнор |
| Цитаты отзывов 2ГИС (20 текстов) | ✅ | ❌ выкинуты |
| Прибыль/возраст/Instagram/врачи конкурентов | ✅ | ❌ только в чате |
| Клиентская выручка (позиция на рынке) | ✅ | ❌ нет, если ФНС не нашёл |
| Техаудит сайта (GEO score, schema, SEO) | ✅ | ❌ только в чате |

## Решение: 4 задачи

### Задача 1: Отдельный LLM-анализ для отчёта (главное)

**Файл:** `app/report_builder/analysis.py` (НОВЫЙ) + `app/llm.py`

При публикации отчёта — **отдельный LLM-вызов** с ПОЛНЫМИ данными (не слепой). Промпт просит глубокий анализ с цифрами, сравнениями, цитатами. Чат остаётся кратким.

```
_auto_publish_report()
  → QC gate
  → generate_report_analysis() ← НОВОЕ: LLM-анализ с полными данными
  → build_data_dict()          ← analysis_text попадает в секции
  → build_report_html()
  → publish_report()
```

`generate_report_analysis(collected_results, profile_cache)`:
- Собирает **context** — структурированная выжимка ВСЕХ данных:
  - Профиль: ИНН, город, специализация, врачи (имена), соцсети, услуги, возраст, CMS
  - Финансы: выручка/прибыль клиента + всех конкурентов с трендами
  - Отзывы: рейтинги по платформам + `neuro_summary` Яндекса + топ-темы + цитаты 2ГИС
  - Конкуренты: имена, выручка, прибыль, возраст, Instagram, CMS — по каждому
- Промпт просит 4 секции по 3-4 абзаца каждая:
  - **Позиция на рынке** — где клиент vs конкуренты (с цифрами выручки)
  - **Сильные стороны** — что лучше конкурентов (рейтинг, отзывы, врачи, соцсети)
  - **Точки роста** — где отстаёт (конкретные пробелы)
  - **Рекомендации** — измеримые действия (не общие фразы)
- `max_tokens=4096` — достаточно для развёрнутого анализа
- Anti-hallucination: **ТОЛЬКО факты из context**, никаких выдуманных цифр
- Возвращает markdown-текст → сохраняется в `data["analysis_text"]`

### Задача 2: LLM-анализ → в секции отчёта

**Файл:** `app/report_builder/adapter.py`

`build_data_dict` теперь принимает `analysis_text` (от Задачи 1):
- `PROFILE_interp.content` = Задача 1 секция «Позиция + Сильные» + форматированный профиль (врачи, соцсети, услуги)
- `REVIEWS_interp.content` = Задача 1 секция «Отзывы» + `neuro_summary` Яндекса + цитаты 2ГИС (топ-3)
- `OVERVIEW_interp.content` = Задача 1 секция «Точки роста + Рекомендации»

Сейчас `_extract_llm_section` использует **весь** `llm_text` только для PROFILE. После Задачи 1 у нас будет структурированный анализ с маркерами секций.

### Задача 3: Обогатить таблицу конкурентов

**Файл:** `app/report_builder/revenue_block.py`

Сейчас в HTML-таблице 4 колонки (#, имя, выручка, тренд). В чате — 8 колонок. Добавлю:
- **Прибыль** (`profit_year`) — колонка
- **Возраст** (`registration_date` → лет) — колонка
- **Instagram** (`instagram_followers` → 31K) — колонка
- **Врачи** (`surgeons_count`/`employee_count`) — колонка
- Клиентская строка «ВЫ» — если есть выручка клиента, показать его позицию в таблице

Это делает таблицу конкурентного сравнения **в 2 раза информативнее**.

### Задача 4: Цитаты отзывов + neuro_summary

**Файл:** `app/tools/run_review_platforms.py` + `app/report_builder/adapter.py`

**4a.** `run_review_platforms` — добавить `review_quotes` в return (топ-5 цитат из 2ГИС, до 200 символов каждая). Сейчас тексты выкидываются после `_extract_themes`.

**4b.** `adapter._format_reviews_markdown` — показывать:
- `neuro_summary` Яндекса (если есть) как выделенную цитату
- 3-5 цитат пациентов (с платформой-источником)
- Это даёт «живые голоса пациентов» вместо сухих «Персонал (298 упоминаний)»

## Что НЕ делаю (отдельная задача)
- Perplexity fallback для финансов — рискованно (галлюцинации выручки), лучше отдельная задача
- run_instagram_content / seo_audit в auto-pipeline — каждый +5-10 секунд к ответу, лучше по кнопке

## Оценка
- Задача 1 (analysis.py + промпт): 60 мин
- Задача 2 (adapter интеграция): 30 мин
- Задача 3 (обогащение таблицы): 30 мин
- Задача 4 (цитаты + neuro_summary): 40 мин
- Тесты: 40 мин
- **Итого: ~3.5 часа** код + тесты, затем регенерация отчёта и проверка

## Риск
- **+1 LLM-вызов** при публикации (~$0.01, glm-5.2 reasoning). Приемлемо — отчёт публикуется 1 раз на сессию.
- **Latency**: +10-15 секунд к публикации (LLM анализ). Публикация идёт ПОСЛЕ чат-ответа, пользователь не ждёт.
- **Галлюцинации**: промпт будет жёстко требовать «ТОЛЬКО факты из данных выше», без выдумывания. Контекст = проверенные данные (ФНС, Яндекс, скрапер), не Perplexity-оценки.

## Ожидаемый результат
Отчёт из «скелета таблиц» превращается в документ, где:
1. **Позиция на рынке** — реальный анализ с цифрами («выручка 121 млн, это 3-е место из 6, ближайший конкурент ЭСТЕТ 157 млн»)
2. **Сильные стороны** — конкретные («рейтинг 5.0★ при 564 отзывах vs средний 4.2★ у конкурентов, 3 врача-косметолога»)
3. **Отзывы** — живые цитаты пациентов + AI-резюме Яндекса, не сухая статистика
4. **Таблица конкурентов** — 8 колонок вместо 4 (прибыль, возраст, IG, врачи)
5. **Рекомендации** — измеримые («создать профиль на ПроДокторов: у 3 из 5 конкурентов он есть, у вас нет»)
