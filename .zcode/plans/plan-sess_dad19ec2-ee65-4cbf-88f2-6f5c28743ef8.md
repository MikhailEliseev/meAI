# План: Чат-ассистент в едином стиле дизайн-системы (чёрно-белый монохром, зависящий от темы)

## Корень проблемы (подтверждено расследованием)

Бэкенд Hermes шлёт в чат богатый контент через кастомные `:::`-блоки (`:::section-num`, `:::surface-block`, `:::stat-card`), которые фронтовый `parseMarkdown()` корректно превращает в `<div class="...">`. Но **стили этих блоков зашиты золотыми хардкодами** — `rgba(201, 165, 90, 0.08)` и фолбэки `#c9a55a` — вместо токенов дизайн-системы. Из-за этого `surface-block` светится золотом даже в светлой монохромной теме, и верстка «не нравится».

Остальные элементы (`h3`, `table`, `hr`, `blockquote`, `code`) уже корректно используют токены — их трогать не нужно.

## Правки — дизайн-системный блок `:::`-блоков (строки 869–929)

Подход минимальный: убираем только золотые хардкоды, заменяя на токены, которые автоматически подстраиваются под тему (`--accent` = чёрный в светлой, золото в тёмной по дизайн-системе). 6 точечных правок:

| Строка | Было (золото-хардкод) | Стало (токен) |
|--------|----------------------|---------------|
| **874** | `color: var(--accent, #c9a55a);` | `color: var(--accent);` |
| **888** | `background: var(--accent, #c9a55a);` | `background: var(--accent);` |
| **891** | `border-left: 3px solid var(--accent, #c9a55a);` | `border-left: 3px solid var(--accent);` |
| **892** | `background: rgba(201, 165, 90, 0.08);` | `background: color-mix(in srgb, var(--accent) 8%, transparent);` |
| **900** | `color: var(--accent, #c9a55a);` | `color: var(--accent);` |
| **917** | `color: var(--accent, #c9a55a);` | `color: var(--accent);` |

**Как это работает:** `var(--accent)` берётся из scoped-токенов чата (строки 20–44), которые уже заданы как `#1A1A1A` (светлая) и `#c9a96e` (тёмная) — в точности как дизайн-система сайта. `color-mix(... var(--accent) 8%, transparent)` даёт мягкий оттенок фона `surface-block`, инвертируясь вместе с темой.

**Fallback на случай отсутствия поддержки `color-mix()`:** добавлю перед строкой 890 запасное правило для старых браузеров:
```css
.message-bubble .surface-block { background: rgba(0,0,0,0.04); }  /* fallback */
[data-theme="dark"] .message-bubble .surface-block { background: rgba(255,255,255,0.05); }
.message-bubble .surface-block { background: color-mix(in srgb, var(--accent) 8%, transparent); }  /* современный */
```

## Что НЕ меняется

- Scoped-токены чата (строки 20–44) — оставляем, они корректны и совпадают с дизайн-системой.
- `parseMarkdown()` (строки 1056–1099) — работает правильно.
- Стили `h3/table/hr/blockquote/code` (строки 200–323) — уже используют токены.
- Базовая структура чата, хедер, инпут, кнопки — не трогаем.
