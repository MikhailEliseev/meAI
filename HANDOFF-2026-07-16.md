## Что чинить (приоритет)

### 1. ЛАНЦЕТЪ в конкурентах IPHK
**Проблема:** ООО "КЛИНИКА ЛК" (ИНН 2367011265) и АО "ИПХиК" (ИНН 7708698635) — разные юрлица, но дочерние компании. `_is_related_entity` не находит совпадений (нет общих слов в названиях).
**Решение:** Проверять ОГРН учредителя через bo.nalog `get_organization` → если тот же учредитель → фильтровать. Или хардкодить известные связи.

### 2. Время pipeline ~60-120с
**Проблема:** Brand resolver Level 2 (Firecrawl scrape) + SEO audit (3 Firecrawl) + competitors enrichment (5 scrape) = много запросов.
**Решение:** Кэшировать результаты scrape_website по URL (TTL 1 час). Запускать audit параллельно с enrichment.

### 3. Врачи клиента = None
**Проблема:** `scrape_doctors` ищет ссылки на главной → если сайт JS-heavy, markdown пустой.
**Решение:** Для клиента — использовать СЧЛ из ФНС (уже есть `client_employee_count`), показывать как "сотрудников". Врачей отдельно через Firecrawl с `waitFor: 8000`.

### 4. Яндекс.Карты рейтинг нестабилен
**Проблема:** Perplexity недетерминирован — иногда находит рейтинг, иногда нет.
**Решение:** Использовать Apify google-search-scraper (уже есть) для поиска "клиника X яндекс карты рейтинг".

### 5. Perplexity недетерминирован
**Проблема:** Каждый прогон — разные бренды конкурентов (3 промпта помогают, но не гарантируют).
**Решение:** Кэшировать результаты competitor search по специализации+городу (TTL 1 день).
