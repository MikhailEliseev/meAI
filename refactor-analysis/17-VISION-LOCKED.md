## ✅ 3 СОГЛАСОВАННЫХ ПАРАМЕТРА

### 1. Mode name: `ANALYSIS`

**Было:** `mode="PRESALE"` (палево если leak)

**Стало:** `mode="ANALYSIS"` (нейтрально, точно, не раскрывает коммерческую цель)

**Где менять (в будущем, не сегодня):**
- `agent_wrapper.py`: `_presale_prompt()` → `_analysis_prompt()`
- `agent_wrapper.py`: `mode="PRESALE"` → `mode="ANALYSIS"`
- `agent_wrapper.py`: константа `"PRESALE"` в `prompts` dict
- `main.py`: `X-Client-Mode` headers
- API endpoints: `/api/pre-sale/chat` → `/api/analysis/chat`

### 2. LLM тон: эксперт-аналитик (НЕ seller)

**Принцип:** LLM = грамотный маркетолог-аналитик, который делится находками. Не sales agent.

**Тон:**
- "Я заметил", "смотрите что нашёл", "обратите внимание"
- Каждая цифра — с интерпретацией (что значит для бизнеса)
- Без воды, без filler, без "купите"

**Запрещённые слова:**
- ❌ пресейл, pre-sale, КП, коммерческое предложение
- ❌ купите, закажите, оплатите, прайс
- ❌ сделка, lead, квалификация, дожим, апсейл

**Разрешённые слова:**
- ✅ анализ, audit, разбор, разведка
- ✅ отчёт, точки роста, рекомендации
- ✅ экспертиза (когда про команду Михаила)

### 3. Handoff: мягкий формат

**Было ( sales- тон):**
> "Для более детального обсуждения — поговорите с Михаилом."

**Стало (мягко, без давления):**
> "Это был поверхностный разбор. Если хотите углубиться в любую из секций — у нас есть команда экспертов (контакты ниже). Но отчёт уже даёт вам картину — пользуйтесь."
