## ⚠️ КРИТИЧЕСКОЕ УТОЧНЕНИЕ

**Принцип:** Клиент НЕ должен видеть, что мы делаем "пресейл" или "продажу".

**Слово "pre-sale" / "пресейл" — палево.** Оно раскрывает коммерческую цель. Клиент должен чувствовать: "эксперт анализирует мой бизнес", а не "меня готовят к продаже".

---

## 🎯 НОВОЕ ВИДЕНИЕ ПРОДУКТА (одной фразой)

> **AIM — AI-аналитик для медицинских клиник. Владелец клиники оставляет URL → через 5-8 минут получает красивый интерактивный отчёт-разбор своего бизнеса: рынок, конкуренты, слабые места, точки роста. Без обязательств, без продаж.**

## Что меняется концептуально

| Было (неявно) | Стало (явно) |
|---|---|
| "AI агентство для medical маркетинга" | "AI-аналитик по клиникам" |
| "Пресейл-чат" | "Аналитический чат" |
| "Цель — продать Михаилу" | "Цель — дать ценность, клиент сам захочет глубже" |
| Hermes = sales agent | Hermes = эксперт-аналитик |
| Handoff = "поговорите с Михаилом" | Handoff = "если хотите углубиться — у нас есть платная экспертиза" (мягко, без давления) |
| "Конкурентная разведка для продаж" | "Анализ рынка и конкурентов" |

## Принцип "Нет продажам"

LLM не должна:
- ❌ Говорить "купите", "закажите", "услуга стоит X"
- ❌ Делать "апсейл" или "дожим"
- ❌ Упоминать что готовит клиента к сделке
- ❌ Использовать слово "пресейл", "KП", "коммерческое предложение"
- ❌ Спрашивать контакты до того как доставлена ценность

LLM должна:
- ✅ Давать реальную экспертизу (цифры, выводы, рекомендации)
- ✅ Быть похожей на разговор с грамотным маркетологом-аналитиком
- ✅ Тон: "я заметил", "смотрите что нашёл", "обратите внимание"
- ✅ В финале — мягкий, ненавязчивый handoff

## Mode name (то что видит LLM в коде и может leak в логи)

**Сейчас:** `PRESALE` (палево если leak в чат)

**Предлагаемые варианты (выбрать Михаилу):**

| Имя | Pros | Cons |
|---|---|---|
| `ANALYSIS` | Нейтрально, точно | Сухо |
| `DISCOVERY` | "Разведка" по-английски, нейтрально | Англ |
| `CONSULTATION` | Дружелюбно | Звучит как услуга |
| `RESEARCH` | Экспертно | Англ |
| **`CHAT`** (default) | Минимум, не палево | Слишком общо |

**Моя рекомендация:** `ANALYSIS` — нейтрально, точно, не раскрывает коммерческой цели.

## Термины, которые нужно избегать в user-facing текстах

- ❌ "пресейл" / "pre-sale" / "presale"
- ❌ "КП" / "коммерческое предложение" / "proposal"
- ❌ "прайс" / "цены" / "стоимость" (в контексте услуг AIM)
- ❌ "заказать" / "купить" / "оплатить"
- ❌ "сделка" / "lead" / "квалификация"

## Термины, которые ОК

- ✅ "разведка" / "scout" (нейтрально, про анализ рынка)
- ✅ "анализ" / "audit" / "разбор"
