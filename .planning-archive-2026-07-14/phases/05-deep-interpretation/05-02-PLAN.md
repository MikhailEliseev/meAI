<objective>
Add HTML rendering layer for Phase 5 narrative quality rules. The Pass 3 prompt (Plan 05-01) instructs the LLM to generate `insight` (main strategic insight per section) and `gap_blocks` (strength + growth point list per section) as kwargs to `generate_html_report`. This plan adds the HTML helpers that render those kwargs, and extends all 10 Phase 4 `_build_*_section` functions to accept and render them.

**2 new helpers:**
1. `_render_gap_blocks(gap_blocks: list | None) -> str` — renders list of `{"type": "strength"|"growth", "title": str, "description": str}` dicts as design-system HTML `.gap` blocks with green border for strength, default border for growth
2. `_render_section_insight(insight: str | None) -> str` — renders string as `<blockquote class="section-insight">{escaped}</blockquote>` matching reference HTML pattern

**10 extended section builders** (all Phase 4 builders — each gains optional `insight` kwarg; some gain `gap_blocks` kwarg where the reference shows gap-blocks):
- LLM builders: strategy, offer, whitefields, experts, content_analysis
- Data builders: revenue_dynamics, clinic_metrics (insight only), media_urls, ratings, competitor_cards

**Wiring:**
- `_build_report_html` gains `section_insights: dict` and `section_gap_blocks: dict` kwargs
- Each section builder receives its slice: `insight=section_insights.get("strategy")` etc.
- `handle_generate_html_report` extracts the new kwargs from LLM call

Purpose: Plan 05-01 added the prompt rules; this plan adds the HTML rendering so the LLM's `insight` and `gap_blocks` kwargs actually appear in the final report.

Output: Modified `generate_html_report.py` (+~250 lines: 2 helpers + 10 extensions + wiring) + new test file `test_phase5_helpers.py` (~150 lines).
</objective>

```python
def _render_gap_blocks(gap_blocks: list | None) -> str:
    """Render a list of gap-block dicts as design-system HTML.

    Per Phase 5 D-07 — unified gap-block format across all sections.
    Matches reference `ИПХиК (2).html` `.gap` CSS class pattern.

    Each gap-block dict shape:
        {
            "type": "strength" | "growth",  # strength=green border, growth=default
            "title": str,                   # e.g., "Сильная сторона: масштаб"
            "description": str,             # 1-3 sentences with numbers
        }

    Args:
        gap_blocks: List of gap-block dicts from LLM (Pass 3 item 19 kwarg).

    Returns:
        HTML string with `.gap` divs. Empty string on None/empty list.
        List capped to 5 items max (DoS mitigation per T-05-02-D).
        All text XSS-escaped via _esc().
    """
    if not gap_blocks:
        return ""

    blocks = gap_blocks[:5]  # DoS cap — top 5 only
    parts = []
    for block in blocks:
        if not isinstance(block, dict):
            continue
        btype = str(block.get("type", "growth")).lower()
        title = _esc(str(block.get("title", "")))
        description = _esc(str(block.get("description", "")))
        if not title and not description:
            continue
        if btype == "strength":
            style = "border-left: 3px solid var(--green);"
        else:
            style = ""  # default .gap class border
        style_attr = f' style="{style}"' if style else ""
        parts.append(
            f'<div class="gap"{style_arr}>'
            f"<h4>{title}</h4>"
            f"<p>{description}</p>"
            f"</div>"
        )
    return "\n".join(parts)


def _render_section_insight(insight: str | None) -> str:
    """Render the main strategic insight as a section blockquote.

    Per Phase 5 D-09/D-10 — each section ends with a blockquote containing
    the 1-2 sentence main insight. Matches reference `ИПХиК (2).html`
    blockquote pattern (border-left 2px solid).

    Args:
        insight: 1-2 sentence strategic insight from LLM (Pass 3 item 20 kwarg).

    Returns:
        HTML string with `<blockquote class="section-insight">` element.
        Empty string on None/empty. Text XSS-escaped + truncated to 600 chars.
    """
    if not insight or not isinstance(insight, str):
        return ""

    text = insight.strip()
    if not text:
        return ""

    # DoS cap — 600 chars max (~80 tokens), enough for 2 Russian sentences
    if len(text) > 600:
        text = text[:597] + "..."

    return (
        f'<blockquote class="section-insight" '
        f'style="border-left: 2px solid var(--text); padding-left: 16px; '
        f'margin: 24px 0;">{_esc(text)}</blockquote>'
    )
```

CRITICAL Python 3.11 f-string note: The f-strings above contain NO backslash-escaped double quotes inside expression parts. The `{style_arr}` is a local variable, not a literal with backslash. This is Python 3.11-safe. The container runs Python 3.11 — backslash-escaped double quotes inside f-string expression parts cause SyntaxError (Plan 04-08 documented this gotcha for the 3rd time).
