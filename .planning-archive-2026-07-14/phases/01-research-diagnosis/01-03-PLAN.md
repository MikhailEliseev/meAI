<objective>
Using evidence from Plans 01 (coverage baselines), 02 (session logs), and 04 (Instagram tool test), confirm the root cause(s) of LLM tool-skipping. Test all 4 hypotheses against evidence and produce a final consolidated RESEARCH.md.

The 4 hypotheses (from CONTEXT.md):
- **Hypothesis A (prompt problem):** SOUL.md/SKILL.md give LLM too much freedom → LLM decides "не обязательно" and skips

- **Hypothesis C (pipeline constraint):** PipelineEngine rigidly limits phases → LLM can't call tools outside the 13-phase sequence (e.g., run_instagram_content not in _TOOL_HANDLERS)
- **Hypothesis D (combination):** Multiple causes compound

Purpose: Phase 2's design depends on this answer. If A → rewrite SOUL/SKILL. If B → chunk long phases. If C → add tools to _TOOL_HANDLERS or switch to orchestrator mode. If D → all of the above.

Output:
1. `evidence/root-cause-analysis.md` — per-hypothesis testing with evidence citations
2. `RESEARCH.md` — consolidated Phase 1 report with root cause, baselines, and Phase 2 recommendations
</objective>
