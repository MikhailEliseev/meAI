# Plan 09-01: Progress Streaming UI

**Phase:** 9 (Chat Pro — Website Chat UX Overhaul)
**Effort:** M
**Risk:** Low

## Objective

Create a real-time progress streaming UI component that displays Hermes' work stages as they happen, using the existing `tool-progress` SSE events from the backend. The component follows the Telegram floating-status pattern — a single message that updates in-place, showing stage → message → competitor hierarchy with visual indicators (spinner/checkmark).

**Purpose:** Transform the chat from a static Q&A interface into a live sales tool where prospects watch Hermes analyze their business in real-time.

**Output:** Frontend SSE handler + floating progress component + dual-theme styling

### Key Integration Points

Backend already sends SSE events in this format:
```javascript
{
  "type": "tool-progress",
  "stage": "competitors",      // tool name
  "message": "Analyzing...",   // human-readable status
  "competitor": "clinic.ru"    // optional context
}
```

Frontend must:
1. Listen for `tool-progress` events via EventSource
2. Update a single floating status component (not create new messages)
3. Map stage names to emoji (reuse backend emoji_map from main.py:126-133)
4. Show spinner during work, checkmark when complete

  <name>Task 2: Implement SSE tool-progress event handler</name>
  <files>/var/www/iamaim.ru/wp-content/themes/aim-theme/chat/chat.js</files>
  <action>
    SSH into server and edit chat.js. Locate the existing EventSource message handler (search for `eventSource.onmessage` or similar).

    Add a new event type handler for `tool-progress`:

    ```javascript
    // Emoji mapping (from AIM/hermes/app/main.py:126-133)
    const stageEmoji = {
      'quick_overview': '⚡',
      'competitors': '🗺️',
      'reviews': '⭐',
      'pagespeed': '🚀',
      'lighthouse': '🚀',
      'seo': '🔍',
      'content': '📝',
      'hh': '💼',
      'doctor': '👨‍⚕️',
      'perplexity': '🔍',
      'scrapy': '🕸️',
      'smi': '📰',
      'instagram': '📸',
      'gaps': '📊',
      'financials': '💰',
      'web_search': '🔎'
    };

    function updateProgress(stage, message, competitor) {
      const progressEl = document.getElementById('progress-status');
      const stageEl = progressEl.querySelector('.progress-stage');
      const messageEl = progressEl.querySelector('.progress-message');
      const competitorEl = progressEl.querySelector('.progress-competitor');
      const spinner = progressEl.querySelector('.spinner');
      const checkmark = progressEl.querySelector('.checkmark');

      // Show progress component
      progressEl.style.display = 'flex';

      // Update content with visual hierarchy (D-02)
      const emoji = stageEmoji[stage] || '⏳';
      stageEl.textContent = `${emoji} ${stage.replace(/_/g, ' ').toUpperCase()}`;
      messageEl.textContent = message;
      competitorEl.textContent = competitor ? `→ ${competitor}` : '';
      competitorEl.style.display = competitor ? 'block' : 'none';

      // Show spinner while working
      spinner.style.display = 'block';
      checkmark.style.display = 'none';
    }

    function completeProgress() {
      const progressEl = document.getElementById('progress-status');
      const spinner = progressEl.querySelector('.spinner');
      const checkmark = progressEl.querySelector('.checkmark');

      // Swap spinner for checkmark (D-05)
      spinner.style.display = 'none';
      checkmark.style.display = 'inline-block';

      // Hide after 3 seconds
      setTimeout(() => {
        progressEl.style.display = 'none';
      }, 3000);
    }
    ```

    In the EventSource message handler, add:
    ```javascript
    if (data.type === 'tool-progress') {
      updateProgress(data.stage, data.message, data.competitor || '');
    } else if (data.type === 'text-delta' || data.type === 'done') {
      // Existing handlers...
      if (data.type === 'done') {
        completeProgress(); // Mark progress complete when conversation ends
      }
    }
    ```

    This handles tool-progress SSE events per D-03 and updates the floating status per D-01.
  </action>
