<objective>
Extend the Pass 3 prompt (`_build_prompt` in `pass_fill_assemble.py`) with explicit generation rules for Phase 4's new sections.

The Pass 3 prompt is the LLM's instruction for the final report assembly. It currently (Phase 3) has 6 items: fill gaps, call generate_html_report, pass coverage_metadata, pass niche, pass instagram_data. Phase 4 adds generation rules for:

1. **Strategy section (09)** — LLM generates 5 directions from collected data (SEC-01, D-01..03)
2. **Offer section (10)** — LLM generates concrete steps + CTA (SEC-02, D-04)
3. **Whitefields matrix (07)** — LLM builds 4×4 matrix from collected data (SEC-03, D-05..07)
4. **Experts section (03) with регалии** — LLM merges site регалии + Instagram metrics (SEC-04, D-08..09)
5. **Content Analysis (04) with страхи** — LLM extracts top-5 patient fears from forum data (SEC-05, D-10..11)
6. **Revenue dynamics** — LLM formats 3-year table with YoY % (DAT-01, D-13..14)
7. **Clinic metrics (About section)** — LLM translates ОКВЭД to human language (DAT-04, D-21)
8. **Media section (05)** — LLM renders concrete URLs from run_media_urls (DAT-02, D-17)
9. **Ratings** — LLM renders ПроДокторов + Яндекс.Карты ratings (DAT-05, D-22)
10. **Competitor cards (06)** — LLM builds detailed cards from multi-source data (DAT-03, D-19..20)

Purpose: Without prompt-level generation rules, the LLM won't produce Strategy/Offer/Whitefields sections (they don't exist in current prompts). The prompt must tell the LLM exactly what data to use and what structure to generate for each new section.

Output: Modified `pass_fill_assemble.py` with an extended `_build_prompt` function.
</objective>
