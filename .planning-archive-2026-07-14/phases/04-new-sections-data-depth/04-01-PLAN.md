<objective>
Extend `find_company_financials` to produce two new structured data blocks in its JSON output:
1. **revenue_dynamics** — 3-year revenue trend with YoY % and summary text (DAT-01, D-12..14)
2. **clinic_metrics** — structured clinic metadata for the About section (DAT-04, D-21)

Purpose: The reference report `ИПХиК (2).html` shows "+79% за 3 года (2.4 млрд → 3.4 млрд → 4.3 млрд)" — current tool only returns the latest year. The AIM backend API already provides `revenue_by_year` (multi-year dict), but the Hermes tool doesn't format it into a dynamics block. This plan adds formatting helpers that the orchestrator LLM and HTML reporter consume.

Output: Modified `find_company_financials.py` with two new helper functions and two new fields in the JSON output.
</objective>
