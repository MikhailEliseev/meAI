# Контент Агент - Структура

## Архитектура

```
┌─────────────────────────────────────────────────────────┐
│                   Content Agent                         │
│                   (Execution Layer)                     │
└─────────────────────────────────────────────────────────┘
                           │
                           │ наследуется от
                           ▼
┌─────────────────────────────────────────────────────────┐
│                     Base Agent                          │
│  • execute_task()                                       │
│  • get_capabilities()                                   │
│  • receive_task()                                       │
│  • report_result()                                      │
└─────────────────────────────────────────────────────────┘
                           │
          ┌────────────────┼────────────────┐
          │                │                │
          ▼                ▼                ▼
    ┌─────────┐      ┌─────────┐    ┌──────────┐
    │Event Bus│      │Obsidian │    │ Database │
    │         │      │  Vault  │    │          │
    └─────────┘      └─────────┘    └──────────┘
```

## Основные функции

```
ContentAgent
├── generate_content()
│   ├── Генерация статей
│   ├── Создание описаний
│   └── Написание постов
│
├── edit_content()
│   ├── Редактура текста
│   ├── Проверка грамматики
│   └── Улучшение стиля
│
├── optimize_for_seo()
│   ├── Внедрение ключевых слов
│   ├── Оптимизация заголовков
│   └── Мета-теги
│
└── schedule_publications()
    ├── Планирование публикаций
    ├── Контент-календарь
    └── Автопостинг
```

## Поток данных

```
YOU/Architect
      │
      │ стратегическая задача
      ▼
   Operator
      │
      │ тактическая задача
      ▼
  Event Bus ──────► Content Agent
      │                   │
      │                   │ выполнение
      │                   ▼
      │              ┌─────────┐
      │              │Генерация│
      │              │Редактура│
      │              │SEO-опт. │
      │              │Планиров.│
      │              └─────────┘
      │                   │
      │                   │ результат
      ▼                   ▼
  Event Bus ◄────── Content Agent
      │
      │ агрегированный отчет
      ▼
   Operator
      │
      ▼
     YOU
```
