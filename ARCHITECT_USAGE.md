# 🏗️ Architect Usage Guide

**Прямой интерфейс к meAI Architect** — твой стратегический советник для AIM Agency.

---

## 🎯 Как использовать

### В Claude Code (этот чат)

Просто напиши:

```
/architect [твой вопрос]
```

**Примеры:**

```
/architect Какую нишу выбрать первой для AIM Agency?
/architect Создай SEO агента для стоматологии
/architect Запусти создание AIM Agency
/architect Какую цену ставить на SEO-аудит?
/architect С чего начать запуск агентства?
```

---

## 🔄 Что происходит

```
ТЫ
  ↓ /architect [вопрос]
ARCHITECT
  ↓ анализирует через Claude API
  ↓ генерирует альтернативы
  ↓ выбирает лучшее решение
  ↓ создаёт план реализации
  ↓ сохраняет в Obsidian
ТЫ
  ↓ "Да, реализуй" или "Нет, изменить"
CLAUDE CODE
  ↓ реализует план
  ↓ показывает результат
```

---

## 📊 Формат ответа

Architect вернёт:

```markdown
🎯 **Решение Architect**

**Действие:** Конкретное действие

**Обоснование:** Почему это лучший выбор

**Уверенность:** 85%

**Альтернативы:**
- Альтернатива 1
- Альтернатива 2

**Риски:**
- Риск 1
- Риск 2

**План реализации:**
1. Шаг 1
2. Шаг 2
3. Шаг 3

📁 Сохранено: obsidian/architect/decisions/2026-05-03-16-20-decision.md
```

---

## ✅ Подтверждение реализации

После получения решения, ты выбираешь:

- **"Да, реализуй"** — запускается автоматическая реализация плана
- **"Нет, изменить"** — уточняешь или меняешь план
- **"Только сохранить"** — сохраняет решение без реализации

## 💡 Типы вопросов

### ✅ Хорошие вопросы (стратегические):

- Какую нишу выбрать?
- С чего начать?
- Какой агент важнее?
- Какую цену ставить?
- Как найти первых клиентов?
- Стоит ли инвестировать в X?

### ❌ Плохие вопросы (тактические):

- Как написать код для X? (это для Claude Code)
- Где баг в коде? (это для отладки)
- Какой синтаксис использовать? (это технический вопрос)

## 📁 Где хранятся решения

Все решения Architect сохраняются в:

```
obsidian/architect/decisions/
├── 2026-05-03-16-20-niche-selection.md
├── 2026-05-03-17-30-pricing-strategy.md
└── 2026-05-03-18-45-agent-priority.md
```

Каждое решение включает:
- Timestamp
- Вопрос
- Решение с обоснованием
- План реализации
- Статус выполнения

## 🎯 Примеры использования

### Пример 1: Выбор ниши

```
/architect Какую нишу выбрать первой: стоматология или косметология?
```

**Ответ Architect:**
- Действие: Начать со стоматологии
- Обоснование: Высокий LTV, стабильный спрос
- Уверенность: 85%
- План: Создать SEO Magister → 4 субагента → пилотный аудит

### Пример 2: Создание агента

```
/architect Создай SEO агента для стоматологии
```

**Ответ Architect:**
- Действие: Создать SEO Magister с 4 субагентами
- План: Структура → код → тесты → интеграция
- Реализация: Автоматическая

### Пример 3: Ценообразование

```
/architect Какую цену ставить на SEO-аудит для стоматологии?
```

**Ответ Architect:**
- Действие: 15,000 руб за базовый аудит
- Обоснование: Рыночный анализ + ценность
- Альтернативы: 10k (лайт), 25k (премиум)
